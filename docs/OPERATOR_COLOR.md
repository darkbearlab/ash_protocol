# 幹員塗裝選色器（3.140.0）

幹員塗裝是蓋在灰色職業圖上的顏色，只影響地圖上的幹員與倒地圖像，不影響規則，也不進存檔。

- 3.48.2：部署時從七個色票選色，另有「原色」。
- 3.116.0：設定加入塗裝濃度滑桿。
- 3.139.1：設定拿掉塗裝濃度滑桿。
- 3.140.0：部署畫面改成色輪加明度滑桿，色票保留。

程式：`src/operator-color.js`（顏色、套色、HSV 換算、明度阻擋）、`src/color-picker.js`（選色器畫面）。

## 使用者的決定（2026-09-19）

- 「調整幹員顏色的功能能不能用色輪和可以調整彩度明度的那種介面來做」。
- 「在設定介面就先不要有那個調顏色的」：3.139.1 拿掉設定裡的塗裝濃度。
- 樣式：「哪一種對既有介面友善就用那種」。Claude 選「色輪（繞一圈是色相、越往外越鮮豔）＋下方明度滑桿」，理由：
  - 滑桿和遊戲裡其他滑桿一樣；
  - 明度阻擋放在一般滑桿上最自然；
  - 鍵盤與手把可以直接操作。
- 色票：「保留，會把選色器介面的游標也改指過去，才好微調自己喜歡的顏色」。
- 明度：「在 40% 那邊加一個阻擋，但再拉一次還是拉得過去」。

## 畫面（部署第 2 步「選擇幹員」）

由上到下：
1. 大預覽圖與色輪；
2. 明度滑桿，40% 處有一條標記；
3. 目前數值；
4. 八個色票；
5. 說明。

- **色輪**：
  - 以全亮度畫出，繞一圈是色相，越往外彩度越高；
  - 圓圈游標標出目前的色相與彩度，填上目前的顏色；
  - 可以點或拖曳；
  - 鍵盤：左右鍵色相 ±5°，上下鍵彩度 ±5%，按住 Shift 一次 15。
- **明度**：
  - 0～100%；
  - 滑桿底色從黑到目前色相、彩度的全亮度顏色。
- **數值**：顯示「色相 °、彩度 %、明度 %」；低於 40% 時另外提醒暗房裡可能看不清楚。
- **色票**：
  - 點一個色票，色輪游標和明度滑桿都移到那個顏色，可以接著微調；
  - 選「原色」時，游標留在原處，選色器變暗；再碰色輪或明度，就改用那個顏色。
- **色票亮起的規則**：色輪與滑桿的位置剛好對到某個色票時，那個色票會亮起；其他位置都是自訂顏色，沒有色票亮起。
- **預覽**：所有職業小圖和大預覽圖都即時換色，拖曳時每幀最多重畫一次。

## 明度阻擋

- **規則**：一次操作如果從 40% 以上開始，就不會降到 40% 以下，停在 40%。下一次操作從 40% 開始，就可以繼續往下。往上拉不受影響。
- **一次操作**的範圍：
  - 手指或滑鼠：從按下到放開；
  - 鍵盤：按一下算一次，按住不放的連續重複仍算同一次，所以按住也會停在 40%。
- **標記**：停下的那一刻，40% 標記會閃一下。
- **原因**：套色是把灰色圖對應成「深色陰影 → 選的顏色 → 亮部」，明度太低時幹員幾乎全黑，暗房裡會看不見。
- **程式**：`softStop(start, value)` 與 `BRIGHTNESS_STOP`（`src/operator-color.js`）。

## 儲存

- **存在哪裡**：本機設定 `ash-operator-color`，只在開始任務時寫入；和以前一樣，不進任務存檔。
- **值**：色票 ID（例如 `amber`）、`none`，或自訂顏色的小寫 `#rrggbb`。以前存的色票 ID 照常讀取。
- **塗裝濃度**：固定為 100%。以前存的 `ash-operator-tint` 不讀也不刪。
- **快取**：
  - 戰場的套色快取以顏色為鍵，每個顏色每張圖一份；
  - 選色時的預覽另外用一個只放當前顏色的小快取，拖曳色輪不會把戰場的快取塞滿。

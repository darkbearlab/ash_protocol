# 3.89.2 街機評語依分數分級、滿分警告與分數 v2 QA（Claude，2026-09-15）

- **使用者決定**：
  1. 街機依照評分，把評語改成「建議銷毀」「尚待評估」「建議直接投入實戰」三階段。
  2. 真的拿滿分（殲滅和時間都滿）時，評語是「受驗者過於強大，建議及早投入最危險的任務或就地銷毀」。
  3. 分數權重先前已交給 Claude 與 Codex 決定。
- **問題**：v1 的速度分要 0 回合才會拿滿，滿分 13000 實際上拿不到，第 2 項永遠不會出現。
- **做法**：改用標準回合數（分數 v2），讓滿分可以達成。

## 修改

- **`src/killhouse-ui.js`**：
  - **分數 v2**：`KILLHOUSE_SCORE` 新增 `parPerTarget: 2`。
    - 標準回合是肅清名單人數的 2 倍（`parTurns`）。
    - 速度分在標準回合內都是 3000，超過後每多一回合扣 30，扣到 0 為止。
    - `KILLHOUSE_MAX_SCORE` 是 13000。
  - **評語**：`ARCADE_VERDICTS` 與 `arcadeVerdict` 分成四級：13000 滿分警告（overpowered）、10000 以上 deploy、6000 以上 pending、其餘 dispose。
  - **結算區塊**：街機結算不再使用戰役的肅清評估區塊，改列單位與評語。
  - **匯入**：拿掉用不到的 `purgeReportMarkup` 匯入。
- **`expansion.css`**：
  - overpowered：金色邊線、深色底、金字。
  - deploy：橘色。
  - dispose：紅色。
  - pending：預設灰色。

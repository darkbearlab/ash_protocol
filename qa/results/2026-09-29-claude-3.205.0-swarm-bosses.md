# 3.205.0 — 蟲族頭目（鉤舌沿路鉤人加咬、巨獸衝鋒、母后產蟲巢）與火線官收槍可移動

## 需求

- 使用者（2026-09-29，docs/BOSSES.md 第 4 節）：蟲族頭目預告照舊，但被打中的代價很大。
  - **鉤舌**（兩隻）：照舊預告一回合、射程 5，沿預告的線打出去，鉤到路上的第一個單位（玩家、友軍、寵物、平民或別的蟲，敵我不分；鉤到自己的蟲也照樣咬），拉到旁邊並在同一個行動咬一口（巨獸 26、母后 30），像狂戰士的鉤鎖加一擊。路上沒人就撲空；牆與關著的門擋住，坑洞可以越過，落點一定是地板。
  - **巨獸衝鋒**（第 3 層）：預告一回合畫出直線車道（到牆、最多 8 格），下一回合沿車道衝。車道上每個單位（敵我不分）往旁邊撞開一格、受 15、失能 1 回合；旁邊沒有空地板就留在原地受 30、照樣失能；絕不撞進坑洞（坑洞當牆）。撞牆時巨獸停下、自己暈 1 回合，這回合打牠命中 +20。冷卻 3 回合。遊戲的第一個推擠規則，只給頭目；PITS.md、ALLIES.md 要寫明。兩側都空時用雜湊（不用戰鬥骰）選邊並寫進文件。
  - **母后產蟲巢**（第 6 層）：預告一回合，卵囊出現在離你 3～4 格、你看得到的地板；下一回合變成蟲巢。同時最多 2 個，照現有蟲巢規則但只生 3 隻；冷卻 6 回合；半血以下也會衝鋒。蟲巢血很多，不另加打巢的解法。
  - 台詞：審稿頁定稿的 intro.beast、intro.matriarch（白鷺、鷦鷯，表情照審稿頁），照 3.204.0 接 intro.loyal3／loyal6 的方式接進出場演出。
  - 預告的畫面：衝鋒車道與卵囊要像機槍扇形、雷射一樣清楚；鉤舌的線保持一致。
- 同一版追加（使用者 2026-09-29，主工作階段轉達）：火線官收槍的 2 回合「收槍的冷卻時間可以移動」：照一般走法移動（含避開危險格），但不開火、不標定、不再架槍。名字「標定官／Designator」「火線官／Gunline Officer」確定，拿掉「暫定」。

## 做法

- 卡片（`src/data.js`）：巨獸 `specials:['charge','tongue']`、母后 `specials:['nest','tongue','charge']` 加 `chargeBelow`（半血以下才衝）；`specials` 是每回合試的順序。兩隻各帶 `intro`（`introBeast`、`introMatriarch`）。SAVE 83。
- 數字（`src/swarm-tuning.js` 的 `SWARM_BOSS_TUNING`）：`charge`（車道 8、撞開 15、無處可退 30、失能 1、撞牆 +20、冷卻 3、半血 .5）、`nest`（3～4 格、最多 2 個、3 隻、冷卻 6）。
- 鉤舌（`src/swarm.js`）：`tongueLane` 用新的 `rayCells`（`src/line-move.js`，同 lineOfSight 的走法，延伸到射程）：牆、關著的門與隔板（子彈的邊）、實體物件擋住，坑洞可過。`tongueCatch` 找線上第一個活著的單位（你、友軍、所有敵人含平民）；`hookLanding` 選頭目旁邊的空地板（預告的落點還空著就用它）。拉過來後用行為樹的 `attack` 咬（`useTongueHooks`，同撲擊的接法）；鉤到敵人時用同樣的近戰數字與命中擲骰，傷害經 `g.hurt`。
- 衝鋒、產蟲巢與存檔（新模組 `src/swarm-bosses.js`，`sw.js` 與 `index.html` 的模組數 176）：
  - `swarmBossAction` 放在行為樹最上面（原本鉤舌的位置，在命令、生存模式、誘餌以外的所有步驟之前）：預告過的衝鋒與鉤舌先出手，然後照 `specials` 的順序開始新招。
  - 衝鋒：`chargeLane`（單位不擋；牆、坑洞、擋路的邊、實體物件擋住，不到 8 格就算撞牆）、`rush`（逐格撞開，`chargeSide` 是種子／樓層／回合／頭目／單位的 FNV 雜湊；`knockDown` 失能 1 回合；巨獸停在車道盡頭或留在原地的單位前面；撞牆設 `crashed`、`vaultExposed`、失能 1 回合）。`crashBonus` 加在 `Game.meleeAccuracy`，槍靠 `vaultExposed` 的 +20；`crashed` 和 `vaultExposed` 一起在牠下一次輪到時清掉（`Game.action` 的行動迴圈）。
  - 產蟲巢：`eggSpot`（離你 3～4 格、你看得到、沒有任何東西、不切斷你走得到的地板，選離她最近的，一樣近時雜湊）、`hatchEgg` 在 `Game.enemyAct` 開頭孵化（不算她的行動）。她的蟲巢是一般的 nest 物件，id 為 `<她的 id>-nest-<n>`，`validRuntime` 另外檢查（總數 3、血 45、不算進生成的那 1 個）；地面裝飾只看生成的蟲巢，讀檔不會變。
  - 打斷（`src/enemy-intents.js`）：衝鋒預告遇到死亡、失能、被移開、壓制到不能動就取消（`src/suppression.js` 施加壓制時就打斷），失去目標不取消；卵囊只在她死亡或失能時取消。都開始冷卻。`tickSwarmBosses` 在回合開始扣冷卻並丟掉失效的預告。
  - 誘餌不會搶走預告過的鉤舌或衝鋒（`src/field-gear.js`）；地雷的判斷與危險格的「先走下來」也跳過衝鋒預告（`src/hazard-paths.js`）。
  - 頭目咬死或撞死自己的蟲：`Game.hurt` 不算你的擊殺、經驗、廢料（同執法者處決），掉落照舊。
  - 存檔：`validSwarmBosses`（每個欄位的形狀與範圍，只准有那一招的卡片帶；她活著的蟲巢不超過 2）；`dropStaleSwarmIntents` 在讀檔時丟掉失效的衝鋒、鉤舌（頭目倒下、失能、壓制到不能動或不在原位）與卵囊（她倒下或失能），不拒收存檔。
- 火線官收槍（`src/loyalist-bosses.js` 的 `bossSpecial` 多一個 `walk`；`src/enemy-behavior.js` 的 `packWalk`）：收槍的 2 回合先照一般規則離開危險格，再照一般走法（有效距離）移動；清掉蓄勢，不標定、不架槍；貼著你時不動（走進看不到的你會變成盲射）。戰報改成「只會移動，不開火也不標定」。
- 畫面（`src/renderer.js`、`src/enemy-visuals.js`）：鉤舌畫出整條會飛過的線（淡粉紅格子加虛線，瞄準的格子與落點照舊）；衝鋒車道是鏽紅色格子加指向衝鋒方向的箭頭，會撞牆時盡頭一條紅槓；卵囊是地上會跳動的淡粉色囊。衝的時候沿路揚塵、撞牆處撞擊、被撞開的人一團灰，孵化時卵囊裂開。目標卡「衝鋒蓄勢」「產卵中」「撞牆暈眩 +20」。文字版工具標出鉤舌的線與衝鋒車道，預告行列出鉤舌、衝鋒與卵囊。
- 文字：中英兩張表各新增 23 條（出場台詞 4、戰報 16、目標卡 3），改 3 條（兩隻的說明、收槍戰報）；`COMMS_LINES`／`COMMS_EXPRESSIONS` 的 `introBeast`、`introMatriarch`。台詞逐字對照審稿頁的 final.json（中英都相同）。

## Claude 的判斷（都寫進 BOSSES.md 第 4 節）

| 項目 | 決定 |
| --- | --- |
| 鉤舌的線 | 從頭目穿過瞄準的格子延伸到射程 5：沿線往後退仍會被鉤到，要往旁邊離開 |
| 鉤舌擋不擋 | 牆、關著的門、隔板、實體物件（箱子、油桶、蟲巢）擋；矮隔板不擋；坑洞可過 |
| 鉤舌瞄準 | 頭目正在打的對象（你或你的單位），原本只拉你 |
| 鉤舌的落點 | 頭目旁邊的空地板，預告的落點還空著就用它；沒有空地板就不預告、出手時撲空；本來就在旁邊的直接咬 |
| 咬的數字 | 卡片近戰 26／30，和所有敵人的攻擊一樣隨樓層加（標準難度第 3 層 29、第 6 層 36），照一般近戰擲命中 |
| 衝鋒的開始 | 看得到對方、同一橫排或直排、相距 2～8 格、車道碰得到對方；貼身照舊咬 |
| 車道 | 牆、坑洞、關著的門、隔板、矮隔板、實體物件擋住；單位不擋 |
| 選邊 | 兩側都空時，種子、樓層、回合、頭目與那個單位的雜湊（`chargeSide`），不用戰鬥骰 |
| 失能 | 同震撼彈的 1 回合，但不看機械或生物；之前的震撼免疫擋不住；結束後照震撼規則有 2 次免疫；頭目也只 1 回合 |
| 撞擊的傷害 | 15／30 是撞擊前：護甲照扣、防禦待機減半、不算掩體；只在無盡的深層放大（不隨每層加） |
| 撞開的落點 | 地板（燃燒的地板也算）；不撞進坑洞、不撞過關著的門或隔板 |
| 留在原地的單位 | 巨獸從它身上衝過去；車道盡頭有人留著時，巨獸停在它前面最後一格空地 |
| 撞牆 | 車道不到 8 格被擋住就算；剛好 8 格後面才是牆不算；+20 對槍（翻越破綻）與近戰都算，到牠下一次輪到為止；牠站著不動，不算移動中的目標 |
| 冷卻 | 照鉤舌的算法：衝鋒後第 3 回合起才能再預告；產卵是孵化後第 6 回合起 |
| 招式順序 | 巨獸：衝鋒、鉤舌；母后：產卵、鉤舌、衝鋒（半血以下） |
| 卵囊的位置 | 離她最近的合格格子，一樣近時雜湊；格子上不能有單位、物件、物品、危險格、火、地雷、誘餌、起點或出口；不能切斷你走得到的地板 |
| 卵囊被擋 | 孵化時那格被佔住就壓破，冷卻照算；她被失能或擊倒時卵囊消失 |
| 孵化 | 在她輪到時一開始，不算她的行動 |
| 擊殺屋 | 不產卵（蟲巢在擊殺屋裡不動） |
| 自己的蟲 | 被頭目咬死或撞死不算你的擊殺、經驗與廢料；掉落照舊 |
| 詞條 | 蟲族頭目不擋任何詞條（快速只讓牠在你之前行動，預告與出手之間你一樣有一次行動） |

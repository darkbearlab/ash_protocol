# Kill house：模擬訓練教學與街機模式（規格，2026-09-15）

- **狀態**：規格，未實作。
- **分工**：
  - 規則、地圖配方、地圖美術資產與地圖風格重構、玩家檔案欄位交 Codex。
  - 房間提示、模擬程式的畫面色調、文字、街機分數權重交 Claude，在 Codex 之後做。
- **前置**：肅清績效由 Claude 先完成，見 [PURGE_REVIEW.md](PURGE_REVIEW.md)。教學的出口與街機模式的結算都用同一套肅清率。

## 1. 使用者決定（2026-09-15）

1. **新手教學做成虛擬的 kill house 模擬程式**。敵人都是人類。
2. **有一個專門的房間**提示「非戰鬥人員也會影響任務，不要手下留情」。
3. **第一次進入遊戲時強制教學，但可以跳過。**
4. **教學固定用士兵。**
5. **教學中陣亡**：直接顯示「銷毀此庫存」（玩家就是這份庫存）。
6. **同樣的素材之後做成可以反覆玩的 kill house 模式**。
7. **重玩只記最高分**，就是街機模式。
8. **短期合約否決**：六層不算長；想玩短的就去 kill house。
9. **街機模式可以選職業**；只有教學固定士兵。
10. **街機模式一開始是超小樓層**，地上就有完整的武器和彈藥；拿完後進下一層戰鬥。
11. **戰鬥層**：沒有升級、沒有資源掉落、沒有頭目；走進撤離點結算。
12. **績效包含肅清率和使用回合數**；之後可以用這些參數給權重配分。
13. **地圖美術資產由 Codex 重產**：每一種類一個，不用多樣化。這次重構當作之後區分地圖風格的基底。

## 2. 世界觀與呈現

- 新解凍的數字人先在模擬程式裡接受訓練。
- **地圖美術**：Codex 重產 kill house 專用的地圖素材，每一類一個（見第 5.1 節）。
- **角色與敵人**：沿用現有素材，套一層模擬程式的色調；敵人是全息人形（染色）。
- **文字語氣**：冷冰冰的程式訊息，不出現企業名稱（[STORY.md](STORY.md) 第 2 節）。
- **不給獎勵**：教學和街機模式都不給協定點數，也不影響永久進度與戰役存檔。

## 3. 教學關卡（固定配方）

- **地圖**：一層，固定配方，不隨種子改變。建議用 `maps/recipes/` 的 JSON 配方格式另做一份，房間依序排列。
- **敵人**：只用人類兵種卡，沒有詞條、沒有小菁英；沒有雜兵、蟲巢、蟲潮與撤退增援。
- **物資**：固定放置，確保每個房間要教的東西都拿得到，例如第 4 間前一定有手榴彈。
- **房間順序（草案，房間數與內容可由 Codex 依地圖調整）**：

  | 房間 | 教什麼 | 內容 |
  | --- | --- | --- |
  | 1 | 移動、掩體方向 | 沒有敵人；有掩體與提示 |
  | 2 | 開火、命中率 | 1 名人類敵人 |
  | 3 | 等待防禦、蓄勢「!」預告 | 1 名會蓄勢的敵人（例如狙擊手） |
  | 4 | 門、手榴彈 | 關著的門後 2 名敵人 |
  | 5 | **非戰鬥人員** | 2 名研究員人形與 1 名守衛；提示「非戰鬥人員同樣列入肅清評估，不要手下留情」 |
  | 6 | 綜合交戰 | 3–4 名人類敵人，之後是出口電梯 |

- **提示**：玩家第一次進入每個房間時跳出一次。規則層提供「進入房間」的判斷或事件即可，文字由 Claude 寫。
- **出口**：走進電梯後顯示肅清績效。研究員沒殺的話會拿到較低的評估，這是教學的收尾。
- **陣亡**：顯示「銷毀此庫存」，然後回到教學開頭（見第 6 節待決定）。
- **角色**：固定是士兵，使用固定配給。是否允許升級三選一，見第 6 節。

## 4. 街機模式（kill house 重玩）

- **入口**：主選單，例如「KILL HOUSE」；可以選職業。
- **流程**：
  1. **整備層**：超小樓層，沒有敵人，地上放完整的武器和彈藥。拿完後走進電梯。
  2. **戰鬥層**：
     - 一層，從 kill house 專用的配方池產生；敵人只有人類與研究員人形，沿用教學的素材。
     - 沒有升級：經驗不觸發三選一。
     - 沒有資源掉落：敵人、箱子與終端都不給物資。
     - 沒有頭目。
  3. **結算**：走進撤離點。
- **分數**：
  - 績效包含肅清率與使用回合數，只記最高分，存在玩家檔案裡。
  - 兩項的權重之後再配，初版由 Claude 定。
- **不影響戰役**：不給協定點數，不動戰役存檔與永久進度。

## 5. 規則需求（Codex）

- **任務類型**：新增 kill house 的任務類型或遊戲模式，分成教學與街機兩種。
- **地圖**：
  - 教學的固定配方。
  - 街機的整備層配方（超小、無敵人、固定放武器與彈藥）與戰鬥層配方池。
- **街機規則**：
  - 部署時可以選職業。
  - 戰鬥層關閉經驗三選一、所有資源掉落與頭目。
  - 撤離點結算時提供肅清率與戰鬥層使用的回合數。
- **模擬標記**：模擬中的敵人要帶可以辨識的標記（例如派系資料或局面欄位），讓介面能套色調；聲線照人類。
- **研究員人形**：沿用平民卡（`civilian`）的行為與規則。
- **肅清率**：沿用 Claude 做好的肅清統計（[PURGE_REVIEW.md](PURGE_REVIEW.md)），不另寫一套。
- **玩家檔案**：
  - 「已完成或已跳過教學」的旗標。
  - 街機最高分。
  - 玩家檔案版本從 5 升級，並同步完整備份的驗證。
- **存檔**：
  - 模擬局不能覆蓋或放棄進行中的戰役存檔。
  - 要另開存檔欄位還是不存中途進度，由 Codex 決定並寫明。
- **關閉的系統**：雜兵、蟲巢、蟲潮、撤退增援、協定點數發放。
- **不變條件**：`node qa/enemy-data-identity.mjs` 與基準一致，既有任務與派系的生成不變。

### 5.1 地圖美術資產與地圖風格（Codex）

- **重產 kill house 的地圖美術資產**：每一種類一個，不做變體。
  - **種類**：地板、牆面、牆頂、門（關閉、破損、門框、門頂這些門本來就要的狀態各一）、掩體，以及 kill house 配方用到的每一種擺設各一。
  - **現有分類參考**：
    - `assets/pixel/terrain-v1`：地板與擺設。
    - `walls-v1`：牆面與牆頂。
    - `doors-v1`：門。
    - `scenery-v1`：大型場景物件。
  - **美術方向**（Claude 建議，出圖後由使用者決定）：虛擬模擬程式裡的訓練場，乾淨的格線與單色面，沒有髒污與生活痕跡。
- **把地圖美術的選用重構成「地圖風格」**：
  - 現有設施的素材是預設風格，kill house 是第一個新風格。
  - `src/themes.js` 的房間主題（衛浴、門禁等）與 `src/materials.js` 的素材選用都放到風格底下。kill house 風格只有一套素材，所有房間主題都用同一張。
  - 之後依設施或派系區分地圖風格，就在這個基底上加新風格，不再改結構。
- **不變條件**：現有設施的畫面逐像素不變。
- **離線清單**：新素材要加進 `sw.js` 的離線快取。

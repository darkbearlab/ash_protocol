# 3.177.5 — 彈藥用盡時開火也說「沒彈藥了」

2026-09-25，Claude。規格：docs/REAL_MODE.md（幹員的對話框，台詞表）。

## 需求

- 使用者：「目前彈藥用盡還按下射擊或 Reload 的時候，我希望幹員統一顯示的語音是『沒彈藥了／no more ammo』，而不是 reload 時說沒彈藥，但按開火卻說要 reload。」

## 原因

- 3.163.0 的台詞表：彈匣空了還開火說「需要裝填」，沒有備彈還裝填說「沒彈藥了」。
- 開火那邊沒有看備彈。所以彈藥全部用光時，按開火叫你裝填，按裝填又說沒彈藥。

## 做法

- **`src/game.js`**：新增 `Game.emptyCue(weapon)`。這把武器對應的備彈用光時回 `no_ammo`，否則回 `reload_needed`。空彈匣或不夠一發的每個地方都改用它：
  - 開火檢查與執行；
  - 盲射（彈匣不足）；
  - 發射器（彈匣已空，兩處）；
  - 打出最後一發那一槍的提醒。
- **`src/controller.js`**：點選目標型武器在彈匣空時直接說的那句，也改用 `game.emptyCue()`。
- **語言表**：`callout-ui.player.no_ammo` 英文從 "Out of ammo" 改成 "No more ammo"（使用者的字），中文「沒彈藥了」不變。
- 拒絕訊息的文字本來就不會顯示（有台詞的拒絕只說出來、不寫紀錄），所以沒動。

## 驗證（Claude 自己跑的）

- **`tests/player-voice.test.mjs`（新增一項）**：沒有備彈時：
  - 空彈匣開火、裝填都說 `no_ammo`；
  - 打出最後一發說 `no_ammo`，不說 `reload_needed`；
  - 補回備彈後空彈匣開火說 `reload_needed`；
  - `emptyCue` 兩種情況都對。
- **原有的測試照舊通過**：還有備彈時打空彈匣、開火說「需要裝填」，霰彈不夠兩發也是。
- **完整檢查**：`npm test` 1303 通過、0 失敗；`npm run build` 成功（`/ash_protocol/` 相容）；英文掃描乾淨。
- **敵人資料身分檢查**：與基準一致（生成 780、任務 110、機器人 24）。喊話只是畫面效果，不影響規則。

# 文字版與操作紀錄（3.124.0）

使用者要求（2026-09-18）：做一個文字介面版，讓子代理實際玩遊戲；操作紀錄要能在文字版和正式版重現。

## 三個部分

| 部分 | 檔案 | 用途 |
| --- | --- | --- |
| 操作紀錄核心 | `src/replay.js` | 紀錄格式、套用一步、狀態雜湊、無畫面重播、在活的遊戲上記錄 |
| 文字版 | `tools/text-play.mjs` | 每次呼叫下一批指令，印出畫面上看得到的資訊，寫入操作紀錄 |
| 正式版重播 | `src/controller.js`（只在 `?test=1`） | 設定 →「測試：操作紀錄」：播放、快速播放、從現在開始記錄、下載 |

## 操作紀錄格式

```json
{"format":"ash-replay","version":1,"build":"3.124.0","save":56,
 "params":{"seed":4242,"character":"soldier","mission":"extraction","facilityFaction":"rebel","tool":"text-play"},
 "start":"<起始存檔字串>","startHash":"…",
 "ops":[{"op":"action","type":"move","arg":[1,0],"h":"…"},{"op":"target","id":"1-1-0","h":"…"},{"op":"perk","id":"damage","h":"…"}]}
```

- **起點是存檔，不是建構參數**：紀錄不依賴產生它的玩家檔案。兩邊都從 `Game.restore(start)` 開始。
- **步驟**只有四種，就是玩家能對規則層做的全部事：
  - `action`：`game.action(type, arg)`；
  - `target`：改鎖定；
  - `perk`：選強化；
  - `recover`：回收識別資料。
- **被拒絕的動作也記**，因為拒絕會在存檔裡寫一行戰鬥紀錄。
- **每一步都附上之後的狀態雜湊 `h`**：
  - 雜湊的是存檔內容，鍵名排序後再算，因為讀檔後欄位順序可能不同，但內容相同；
  - 播放時第一個不同的步驟會被指出來。
- 重播的任務**不連接玩家檔案**：不會解鎖、不寫任務紀錄。

## 文字版用法

```bash
node tools/text-play.mjs new runs/rebel-1.json --seed 4242 --faction rebel --class soldier --mission extraction
node tools/text-play.mjs runs/rebel-1.json "go case-1-3; open; e3"
node tools/text-play.mjs runs/rebel-1.json            # 不給指令 = look
node tools/text-play.mjs verify runs/rebel-1.json     # 從頭重播，逐步比對雜湊
```

### 呼叫方式

- 每次呼叫可以下多個指令，用 `;` 分隔。
- 遇到以下情況會停下，剩下的指令列在「未執行」：
  - 新敵人進入視野；
  - 受傷；
  - 動作被拒絕；
  - 出現新的攻擊預告；
  - 升級待選；
  - 換層或任務結束。
- 記錄檔旁邊有一個 `.cache` 快取，存最後的存檔，讓下一次呼叫不用從頭重播。快取和紀錄對不上時，會自動從頭重播。

### 公平原則

文字版只顯示正式版畫面上看得到的東西：

- 視野內或隊伍感測到的敵人；
- 已經看過的地圖；
- 目標卡上的命中率與掩體；
- 箱子開了才知道內容。
- 敵人圖鑑（`codex`）對應遊戲裡隨時可看的敵人圖鑑，不是當下的位置或狀態。

### 指令一覽

`help` 印出完整說明。

- **移動**
  - `n s e w`，可以加步數，例如 `n3`。
  - `go X,Y`、`go <id>`、`go exit`：只走已探索的格子，走進關著的門會開門。
- **戰鬥**
  - `t <敵人>` 鎖定；`f [敵人]` 開火。
  - `r` 裝填；`wait` 防禦待機；`swap [槽]` 換武器。
  - `g <落點>` 投擲；`launch <落點>` 對地發射；`flare <落點>` 照明彈；`decoy <落點>` 誘餌；`mine <落點>` 地雷（3 格內）；`blind <X,Y>`（或 `bf`）朝看不到的格子盲射（3.151.0：命中 −40，霰彈槍不受影響；只回「消耗 N 發，看不到結果」，結果要等看得到那格才知道）；地圖上的 `=` 是上鎖的保險室鐵門，撿到本層鑰匙卡後狀態列會寫「本層鑰匙卡」，走進鐵門就開（3.146.0）；`skill [落點]` 技能。
  - `cover <方向>` 架摺疊掩體；`use medkit|spray|adrenaline` 用道具。
  - `rope escape <落點>` 逃命繩索（不耗回合）；`rope redeploy <落點>` 重部署鉤索（耗 1 回合）。3.135.0。
  - `bump <背包槽|none>` 選撞擊時用哪一把近戰武器（不耗回合；none＝背包裡第一把）。`inv` 會列出目前的撞擊武器。3.136.0。
- **背包**
  - `prep <grenade|item|skill> <id|none>` 預備。
  - `take <地上槽>` 拾取；`salvage <背包槽>` 拆解背包裡的武器；`scrapgun <地上槽>` 就地拆解。
  - `replace <地上槽> <背包槽>` 交換武器。
- **互動**
  - `open [id]` 開箱；`door <id>` 開關門；`obj <id>` 回收機密。
  - `buy <品項> [抵價id=數量…]` 終端購買。
  - `down` 搭電梯；`perk <id>` 選強化；`recover` 回收識別資料；`learn <id>` 學習資料。
- **職業**（德魯伊、工程師）
  - `class`：獵獸的燃料與四條成長線、工坊的生產序列、藍圖、部署上限、可修理的機體。
  - `pet <X,Y|@>`：指揮獵獸，要先 `prep skill pet_command`；點自己＝召回。
  - `feed <飼料 id>` 或 `feed weapon <槽>`：餵獵獸，id 看 `class`。
  - `build <藍圖> [投擲物] [武器槽]`、`deploy <序列> <X,Y>`、`repair <機體 id>`。
- **資訊**：`look`、`map`（全圖）、`inv`、`term`、`class`、`enemy <敵人>`（附圖鑑）、`codex [兵種]`、`log [n]`。
- `act` 不帶參數會列出所有合法的動作名稱。
- **鎖定物件**：油桶、詭雷箱（有耐久的補給箱）、門、隔板都可以 `t <id>` 鎖定再 `f` 開火，和正式版點擊它們一樣；附近的油桶會列出 id。一般補給箱與保險室鐵門打不壞，不能鎖定（3.150.0 更正：以前這裡寫補給箱都可以射）。
- **連續指令**：平民、研究員進出視野不算「發現新敵人」，不會打斷；同一句紀錄連續出現（例如研究員每回合尖叫）只列一次並註明次數（3.150.0）。
- **特殊**：`act <type> <json>`，直接送出任何規則動作，給工程師工坊、德魯伊餵食這類沒有簡寫的操作。

### 敵人代號

- 敵人在地圖上用字母表示。
- 字母依視野內的順序排，敵人死亡或離開視野後會重排，所以連續指令裡請用 id。

### 地圖符號

地圖每格兩個字元：格子本身，加上它東側的邊線；格子列下方的邊線列是南側邊線。

- **角色**：`@` 你；`a-z` 敵人；`&` 友軍；`?` 感測到的位置。
- **設施**：
  - `>` 電梯；
  - `C` 補給箱，`c` 已開；
  - `T` 終端，`t` 額度用完；
  - `B` 油桶；`o` 掩體或障礙；`N` 巢穴；`M` 任務目標。
- **地上**：`W` 武器；`*` 物品；`X` 危險地形；`%` 煙霧（含孢子煙）；`~` 毒霧（3.134.0，看得穿）；`!` 即將爆炸的範圍。
- **地板**：`.` 視野內；`,` 記憶中；`:` 暗處（視野內）；`;` 暗處（記憶）。
- **邊線**：
  - `+` 關閉的門，`'` 開著的門；
  - `|` 或 `-` 隔板（擋視線）；
  - `!` 或 `_` 矮隔板（可翻越）。

## 在正式版重播

1. 用 `?test=1` 開遊戲。
2. 設定 →「測試：操作紀錄」→ 選擇「播放操作紀錄」（照常演出）或「快速播放」（跳過動畫），再選紀錄檔。
3. 播放規則：
   - 播放中不接受操作，左下角可以暫停或停止；停止後可以從那一步接手玩。
   - 每一步都和紀錄的雜湊比對，不同就暫停並顯示第幾步。
   - 播完顯示「N 步全部與紀錄相同」。
4. 主控台也可以操作：
   - `__ashReplay.load(紀錄, {from: 120, fast: true})`：從第 120 步開始播；
   - `__ashReplay.state` 查看進度與比對結果。

### 反方向：正式版記錄，文字版重現

1. 設定 →「從現在開始記錄」，然後照常玩。
2. 「下載操作紀錄」存成檔案。
3. `node tools/text-play.mjs verify <檔案>` 會逐步重現並比對，也可以接著用文字版玩下去。

## 驗證（3.124.0）

- **機器人紀錄的無畫面重播**：三局都逐步相同。
  - 叛軍士兵 186 步；
  - 蟲族偵查兵 414 步，含鉤舌拉扯；
  - 忠誠者工程師 67 步。
- **瀏覽器播放同兩份紀錄**：
  - 186 步快速播放全部相同；
  - 414 步先照常演出 64 步，再用 `from` 從第 64 步快速播放到結束，全部相同，最後雜湊等於紀錄。
- **瀏覽器記錄**：用方向鍵走 5 步，記錄出的紀錄重播後雜湊相同。
- **找到的存檔錯誤**（同版修正）：
  - 蟲族巨獸的鉤舌把玩家拉動多格，存下的移動量超過一格，讀檔驗證只接受一格，所以拉扯後的存檔讀不回來，重新整理頁面就會失去這局。
  - 現在接受棋盤內任何整數位移（側身判定只看方向）。

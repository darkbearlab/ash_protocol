# 小隊長、已就緒與交叉掩護推進（3.125.0–3.126.0）

使用者設計，2026-09-18。起因是九局代理實測的結論：敵人一個一個走進玩家的射線，中後段變成打靶（見 qa/results/2026-09-18-claude-agent-playtest.md）。

這是第一個「知道同伴存在」的敵人。

## 循環

```
識別＋部署 → 就位者壓制 → 全隊已就緒 → 齊射 → 小隊長重新下令
```

1. **識別＋部署**（同一個行動，不另外佔回合）
   - 小隊長讀取玩家**當下裝備的武器**，把半徑 7 格內最多 4 名持槍隊員派到能有效還擊那把武器的位置。
   - **這一輪全隊不開火**，因為還沒有人就位——這是玩家的空檔。
2. **壓制**（部署期間）
   - 已經就位的隊員對玩家壓制射擊：轉角已經暴露就直接打玩家，沒暴露就打玩家旁邊那一格（壓制範圍是半徑 1，所以打旁邊一樣壓到玩家）。
   - 每人冷卻 1 回合，單回合沒有人數上限，而且**只要小隊長還活著，每回合至少有一個人在壓制**。
   - 部署至少佔一回合（`deployMin`），所以就算全隊本來就站在好位置，玩家也一定拿得到這個窗口。
3. **已就緒**
   - 全隊到齊，或超過 3 回合（`deployTurns`，不等落單的人）後，小隊長花自己的行動下令。
   - 已就緒＝**玩家的防禦待機**：受到的直接傷害減半、被射擊命中 −15、下一次射擊命中 +15。同時把隊員設成已瞄準，所以不用再花一回合蓄勢。
4. **齊射**：隊員在自己的行動順位開火。
5. **重新下令**：已就緒只持續一輪，小隊長每回合都要再下一次令——**這就是殺小隊長的理由**。

## 玩家的反制

| 手段 | 效果 |
| --- | --- |
| 殺小隊長 | 壓制與已就緒同時停止，隊員恢復成一般行為 |
| 換武器 | 站位是針對你手上那把算的，換武器就作廢，小隊長必須重新識別（部署窗口重開） |
| 煙霧＋震撼小隊長，或關門 | 小隊長的紅外線看穿煙霧、夜視看穿黑暗，只有它也被弄瞎（或門擋住）整隊才真的看不到你 → 耐心值 |
| 真正甩掉他們 | 耐心用完、搜索到你最後的位置仍沒找到你 → 小隊解散，下次接觸是全新的識別窗口 |
| 煙霧、EMP、震撼、壓制射擊 | 打斷小隊長的下令或讓它失能 |
| 重裝兵 | 天生壓制抗性，每次 −1 層 |
| 機體與無人機 | 機械單位對壓制免疫 |

## 位置怎麼算

只看武器的形狀，不看誰拿著它：

| 玩家武器 | 小隊的答案 |
| --- | --- |
| 近戰 | 保持 3 格以上，絕不站你旁邊 |
| 錐形（霰彈） | 保持距離並拉開彼此間距（3 格），不排成一條線 |
| 範圍（榴彈、對地發射） | 保持距離並拉開間距（2 格） |
| 射程 ≥ 8（精準步槍） | **逼近到 5 格內**，不跟你對狙 |
| 其他 | 在自己的射程內找有掩體的位置 |

所有位置都必須：在自己的射程內、對玩家有視線與射線、沒有被別人預定；有掩體的位置優先。

3.127.2（使用者決定：每個隊員都要讓你在它自己的射程內）：房間找不到符合武器帶的位置時，先放寬武器帶的距離與間距規則；還是沒有視線時，至少走到**射程內、走得到**的格子，之後由交叉掩護推進找視線。原本找不到就原地不動，Opus 試玩裡三名隊員因此停在 9～10 格外的黑暗中，一槍都沒開。

## 數值

`SQUAD_TUNING`（`src/squad.js`）：半徑 7、最多 4 名隊員、壓制冷卻 1、已就緒 2 回合（下令當輪加下一輪＝一整輪）、部署最少 1 輪、部署期限 3 輪、搜尋半徑 8、保持距離 3、逼近 5、間距 2；3.126.0 起加上耐心值 6、報位射擊 −40、推進快速 2 回合。

卡片（`ENEMY_TYPES.squad_leader`）：生命 34、傷害 12、射程 6、裝甲 1、經驗 2、壓制抗性 1 階、夜視與紅外線（3.126.0）、**每層最多一名**（`maxPerFloor`）。只在**忠誠者**名冊裡。小隊長有小隊時自己不開火。

## 實作

- `src/squad.js`：狀態機與全部規則。
- `src/enemy-behavior.js`：小隊長走自己的行為樹（`before`），隊員走一個永遠成立的分支，排在蓄勢與攻擊之前。
- `src/traits.js`：`ready` 特性（目標卡會顯示「已就緒」），傷害減半走既有的 `reduceDirectDamage`。
- `src/combat.js`：命中公式的 `focus`／`evasive` 兩項改成「旗標或已就緒特性」，所以用的是防禦待機本來的數字。
- 存檔 SAVE 58：小隊長存 `{weapon,state,since,suppressTurn,set,patience,last,blind}`（`state` 為 deploy／ready／patience／search），隊員存 `{leader,goal,set,suppressed,role,lastMove}`，讀檔時驗證（`validSquad`）。3.125.0 的 `at` 仍然接受，但不再使用。
- 3.126.0：`src/combat.js` 的命中公式多一個 `blindShot`：報位射擊時以它取代暗區懲罰。攻擊本身沿用卡片自己的 `attack`，由 `enemy-behavior.js` 透過 `useSquadAttack` 交給小隊模組，避免兩個檔案互相匯入。

## 為什麼不影響既有內容

- 卡片只加進**忠誠者**名冊，legacy 名冊一字未動，所以地圖生成與機器人基準線完全不變。
- identity 只有 7 個項目變動，全部是**無盡任務抽到忠誠者的樓層**；證明見驗證報告。
- 地圖繪圖紀錄只有忠誠者那組場景變動：把該場景移除後，新舊程式的雜湊完全相同。

## 交叉掩護推進（3.126.0）

使用者設計，2026-09-18 討論定案。起因：3.125.0 的「你移動 4 格就重新識別」讓玩家可以一直跑來重開窗口（風箏）。新的模型是：**部署不是一次性的階段，而是一個一直改變形狀的狀態**——每回合重新判斷每個隊員該掩護還是推進。

### 使用者的決定

- 你離開僵持點時，小隊長調整周圍的士兵，讓他們**咬住你但陣形可以移動**。
- **看不到你的隊員優先被指派推進**；這是部署的延伸，不是另一套行為。
- **近戰單位**在掩護部署的階段就直接衝上來，被消耗掉也無妨。
- **換武器**仍然重開識別窗口。
- **全員看不到你時有耐心值 6 回合**（煙霧彈持續 5 回合，剛好散完再多等一輪）。
- **小隊長有夜視與紅外線**，能報位：即使你丟了煙霧，隊員也會改以較低的命中率打你**當下所在的那一格**。報位射擊的懲罰是 **−40**。
- 耐心值用完、而你已經離開原位且在視線外時，小隊長派人**交叉掩護推進到你最後出現的位置**重新索敵——**這才是玩家的機會**。
- **耐心期間保持已就緒**。
- 搜索時**只有一半的人移動**。
- **推進者是快速，而且抵達後的下一回合仍然是快速**：你讓敵人搶進門口，牠會在你出手之前開槍。否則你只要貼近時稍微退出轉角、再用正常回合打追上來的人，整套邏輯就被 game 掉了。
- 如果小隊正**守在通往電梯的唯一路徑上**，就不會推進，也不會搜索：耐心值不減，他們守在路口直到你來。

### 狀態

| 狀態 | 條件 | 小隊行為 |
| --- | --- | --- |
| 部署 | 初次接觸，或你換了武器 | 識別那一輪全隊不開火；之後就位者壓制（3.125.0 規則照舊） |
| 交戰 | 至少一名隊員看得到你 | 看得到、射得到的人**掩護**（壓制或齊射）；看不到或射不到的人**推進**，同時推進的最多半隊，其餘保持已就緒；近戰隊員直接衝鋒 |
| 報位射擊 | 隊員看不到你，但小隊長感知得到你 | 隊員對**你當下那一格**開火，命中 −40（取代暗區懲罰，不疊加）；壓制也可以打那一格 |
| 耐心 | 隊員與小隊長都感知不到你 | 原地等待，保持已就緒；耐心值 6 回合倒數 |
| 搜索 | 耐心值歸零 | 交叉掩護推進到你最後出現的位置：一半移動、一半保持就緒，然後交換 |
| 解散 | 搜索抵達最後位置後仍無接觸 | 小隊命令清除，隊員回到一般敵人行為；下次接觸是全新的識別窗口 |
| 死守 | 小隊佔據你前往電梯的唯一路徑 | 不推進、不搜索、耐心值不減；看得到你就照打 |

### 規則細節

- **誰推進**：沒有視線的人優先，其次是射不到（超出射程或不在武器帶內）的人。同時推進的人數上限是隊員數的一半（無條件捨去，至少 1）。只剩一人時它自己推進。
- **推進者**：小隊長依你**當下**的位置與武器重新指派射擊位置（沿用 3.125.0 的武器帶）；推進那一輪不開火；獲得快速 2 回合（移動那一輪＋抵達那一輪），而且保留蓄勢，所以抵達後的第一個行動就能開火，排在你之前。
- **近戰隊員**：不分配射擊位置、不參與壓制與已就緒，直接朝你衝。
- **小隊長的感知**：卡片加上夜視與紅外線特性。紅外線看穿煙霧，但被牆與關著的門擋住；夜視忽略暗區。**震撼彈會讓有夜視／紅外線的單位失能**（現有規則），所以「煙霧＋震撼小隊長」或「關門」才會讓整隊真的瞎掉。
- **耐心值**：只在隊員與小隊長都感知不到你時倒數；有任何一人重新看到你就重設。死守時不倒數。
- **最後出現的位置**：最後一次有人（含小隊長）感知到你的格子。搜索的目標是那一格。
- **死守的判定**：把小隊所有存活成員的位置與射擊位置當成牆，從你的位置找得到通往電梯的路嗎？找不到就是死守。每回合重新判定——你繞到他們後面、電梯路線不再經過他們，死守就解除。

### 移除

- 3.125.0 的「你移動 4 格以上 → 重新識別」（`regroup`）。移動不再重開窗口，只會讓看不到你的人推進。重開窗口的方法只剩換武器、殺小隊長、以及真正甩掉他們（解散）。

### 數值

耐心值 6、報位射擊 −40、推進上限半隊、推進快速 2 回合、搜索時半隊移動。

### 預期的影響

- 小隊長卡片加上夜視與紅外線，會讓無盡抽到忠誠者的 7 個 identity 項目再變一次（特性存在敵人物件裡）；legacy 與機器人不受影響。
- 存檔 SAVE 58：小隊長的 `squad` 加上模式、耐心值、最後出現位置；隊員加上角色（掩護／推進／衝鋒）。

### 搶位不給退路（使用者決定）

- 快速推進者搶走你正要走的那一格時，你的移動作廢，這條**保留**。使用者：持槍的雙方實務上不會撞在一起，「局勢已改變」多半是快速蟲群淹沒後路的局面，那是玩家要學會處理的。
- 數據支持這個判斷：五份代理紀錄裡的 83 次搶位作廢，81 次是快速的蟲群幼體、1 次雜兵、1 次軍犬，**持槍敵人 0 次**，叛軍與忠誠者的局都是 0 次。

### 實測（受控場景）

- **煙霧**：開闊地丟煙霧，隊員看不到你，小隊長用紅外線報位；半隊朝你那格開火（第一發 57%，已含 −40），另一半推進。
- **部分遮蔽**：牆只擋住一名隊員，只有它推進；推進與抵達那一輪都是快速，抵達時已就緒並直接開火，其他人全程持續射擊。
- **全員失去視線**：原地就緒 6 回合，接著半隊交叉掩護到最後位置；找不到就解散。
- **死守**：小隊長站在一格寬的缺口上，失去視線 10 回合後耐心仍是 6，沒有人出來搜索。
- **小隊長被震撼**：它無法報位，隊員不會朝你那格盲射（修掉一個上一輪報位殘留的漏洞）。

## 待觀察（實測後再調）

- 小隊長每回合都能補狀態，等於已就緒的小隊**每回合都能開火**（一般敵人是蓄勢一回合、開火一回合）。實測三人小隊對防禦待機中的玩家是每回合 −20。如果太兇，最小的旋鈕是讓補狀態兩回合一次。
- 單回合壓制沒有人數上限：三個人同時壓制就會把玩家釘住（3 層）。這是使用者的決定（「沒留道具處理特定情境是玩家的 skill issue」）。
- 目前只有忠誠者有小隊長。叛軍若要有，建議做成詞條版而不是同一張卡。

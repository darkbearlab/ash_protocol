# 格間障礙物與門：設計方向

狀態：2026-09-09 使用者將門的底層方向進一步明確為「格子之間的障礙物」，用於不占整格地板的小隔間。尚未實作，遊戲仍 3.15.0；本文件記錄方向，並非本輪開始開發。

## 共用基礎

現有整格牆保留。新增障礙物位於上下或左右相鄰兩格的共用邊界：兩邊地板都能站人，能否跨越、互相看見或攻擊由中間的障礙物決定。玩家不會站在邊界上，因此不需要「站在門格時能否關門」的特殊例外。

同一邊界只保存一份障礙物狀態，從任一側查詢或互動都指向同一物件。隔板與門的方向由該邊界決定，不因接近方向產生兩扇不同的門。相鄰多條邊界可圍成廁所隔間、櫃檯後室或哨站，留一條邊界作入口。

門是格間障礙物的一種，增加可開關與開關狀態；固定隔板使用同一位置與幾何基礎，只是不可開關。可破壞與否、耐久、通行阻擋、視線阻擋、射擊／爆炸阻擋與方向性掩體應保留獨立定義，避免未來每增加一種隔間都重寫判定。不可開關不等於不可破壞。

第一批建議只實作固定隔板與門；玻璃、柵欄、低隔板等只預留表示能力，不自動加入此次範圍。

## 必須一起處理的規則

- 玩家四方向移動與敵人尋路均查跨越的邊界，不能穿過關門或隔板。
- 視線與射擊沿途查跨過的邊界；既有牆角探身的起點／終點偏移也必須檢查，不能藉探身穿過關門或封閉隔板。
- 掩體依攻擊方向和邊界狀態決定；開門後不能仍把整個門洞當關門掩體。
- 爆炸、煙霧範圍與控制投擲物納入對應邊界判定，避免視線已阻擋、範圍效果卻意外穿牆。具體材質差異留待設計。
- 門／可破壞隔板要能選取、顯示耐久與受擊；開關和破壞立即影響敵我同一套判定。
- 互動沿用右下統一入口，不能追加會推高戰場的面板；相鄰多個可互動物需有清楚的選擇方式。
- 地圖生成確保房間可達，並檢查多面隔板交會處；保存同一邊界的唯一狀態。舊局補空的格間障礙物集合，保留原牆、地圖與玩家進度。

## 使用者已提出的門行為

朝門方向移動可開門，亦能使用互動開關；門和牆一樣能提供掩體，和障礙物一樣可被破壞。底層使用格間障礙物，支持小型封閉隔間。

尚未確認的細節：開門是否消耗一回合且人留原地（目前 Codex 建議）；開關後門框如何提供掩體；門／隔板的耐久；哪些敵人開門、哪些破門。設計此基礎不代表這些數值已定案。

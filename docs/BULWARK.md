# Bulwark · 重裝兵（3.14.0）

使用者要求參考重型動力裝甲兵的玩法：重裝、慢、大，輕機槍與裝甲內建近戰。此角色是原創 Bulwark，未採用 40k 名稱、標誌或設定。第三名免費起始角色，於新任務選擇；不在既有 run 中改角色。

## 初版數值

| 項目 | 規則 |
| --- | --- |
| 生命 | 200，原角色為 100 |
| 固定裝甲 | 6，每次直接傷害先扣除；可由原模組繼續增加 |
| 起始護甲板 | 30，仍是可耗盡的吸收池，上限 30 |
| 重裝防護 | 獨立 `heavy_armor`：固定裝甲後直接傷害 ×0.75，向上取整，最少 1 |
| 大型 | 獨立 `large`：被射擊命中 +15，依原規則上限 99% |
| 笨拙 | 獨立 `clumsy`：移動命中懲罰僅 −9 |
| 緩速 | 獨立 `slow`：普通敵人在玩家之前結算；仍每回合一格，快速可抵銷緩速 |

沒有附帶 `no_cover`，仍可利用方向正確的掩體。防護順序：掩體（非爆炸）→固定裝甲→重裝防護→等待→護甲板。例：19 傷害、無掩體、沒有等待／護甲板時為 `ceil((19−6)×0.75)=10`。等待後為 5；再由護甲板吸收 2，生命損失 3。環境及中毒沿原規則繞過以上防護，不是對所有傷害免疫。

`heavy_armor` 可獨立掛敵人，普通命中／爆炸在 `hurt` 之前減傷；環境及自爆死亡不走此減傷。原角色沒有默認獲得此被動。固定裝甲升級仍沿原機制，這組數值只做初版，不能把自動場景通過當作自然難度已平衡。

## 輕機槍與動力拳

| 武器 | 基礎傷害 | 射程 | 彈藥 | 其他 |
| --- | --- | --- | --- | --- |
| 堡壘輕機槍 `lmg`，base 6 | 18–22／發，三連發 | 7 | 步槍彈，彈匣 30 | 餘彈不足只射現有彈數，原目標倒下即停止後續實彈；不自動換人 |
| 震擊動力拳 `powerfist`，base 7 | 70–90／次 | 1（曼哈頓） | 無限使用，儲存彈匣為 0 | 99% 命中、無視掩體，穿透 50% 固定裝甲；可 +3，每級 +5 傷害 |

本批兩把新武器由重裝兵起始持有，未擴充隨機掉落池。LMG 可拆解／交換，支持現有詞條。動力拳是固定裝備，占三格背包的一格，不能拆解或與地面武器交換，不能套詞條；可以選擇它攻擊、改裝升級。介面與引擎兩處阻擋移除。

使用者補充：動力拳鑲嵌裝甲，**切進與切出都不耗回合**。`weaponSwitchTurns(destination,current)` 依 `integrated` 決定雙向免費；槍械直接互換仍 1 回合（未來手槍原接口照舊）。允許先切拳再切另一把槍，全程不耗回合，符合內建武器自由切換的授權；沒有額外切換次數限制。

免費切換不動敵人／毒／地形／轟炸／暫時被動期限，不清等待、移動或連射狀態。真正揮拳消耗一個回合，並中斷射擊連射記憶；不增加子彈射擊數，不裝填、不消耗或生成備彈。傷害共用武器增幅模組。顯示 ∞、近戰時停用裝填，原開火按鈕改為「揮拳」。

近戰命中固定 99%，不受射擊專用的移動／大小／側身／掩體／等待／架槍／著彈修正影響。斜角距離 2 不可打，不能穿牆；初始無效行動不推回合。有效揮拳承諾原 ID，敵人先離開範圍／死亡／不可見後仍揮空且耗回合，不改打別人。玩家先被殺則原攻擊取消。動畫用短促揮擊→衝擊→倒下→結果／升級，不射出子彈。LMG 每個實彈有短促彈道，連發之間縮短停頓。

## 保存與介面

單局 v11 接受 v1–v10；第一次本機讀取 v10 保留原件。新武器只追加 base ID，不重排現有武器實例；舊角色／HP／彈藥／裝備／RNG 保留，不補新武器或重裝防護。Bulwark 存檔必須仍持有恰一把動力拳，近戰彈匣必須 0、不能有詞條，地面不可存固定武器。profile v4／完整備份 v1 不變。

選角統一顯示各角色起始生命與裝甲，不再硬寫 100。背包顯示固定裝備、禁用拆解、比較頁不提供換掉動力拳；仍能用空格收地面槍或比較其他武器。所有傷害、回合成本和彈匣以實際武器定義顯示。

使用者認可的第二輪 16 張頭像已採用，保留前四個舊 ID，其餘追加 portrait-05–16。v1–v9 頭像遷移固定使用原四 ID 雜湊，避免擴大池後讓舊原件重匯換臉。地圖上玩家／屍體精靈仍共用。重建正式池：`python tools/pixelize_portrait_atlas.py --install`；第一輪處理腳本只輸出 art/portraits/cells-v1，避免覆蓋新版。

## 雷鳴爆彈槍：追加的拾取武器

使用者追加要求連發榴彈武器並更名，採原創「雷鳴爆彈槍」`thunder`，base 8，weaponClass burst_launcher。使用榴彈彈藥，彈匣 9、射程 6、每發 24–30，三連發，各發獨立判定命中；命中後半徑 1 爆炸、相鄰每格原傷 −10，無視掩體與固定裝甲，仍受重裝防護減傷。可自傷、連鎖引爆油桶；未命中或承諾後失去原目標不在戰場內爆炸，照常耗彈。

只有拾取：不在任何角色起始裝備、終端武器商品或角色選擇中。第 3 層起每層軍械位置有 20% 機率額外一把（與保證軍械同格，不替換原保證品；背包可分別比較）。同時第 3 層起鐵殼破壞者 10%、封鎖官 15% 額外掉落，封鎖官原有保證電漿仍保留。可以正常換裝、拆解、+3 改裝，會有現有詞條，但不生成對爆炸無意義的穿甲詞條。

剩餘不足三發只射現有彈；原目標死亡或玩家被第一發爆炸殺死時，立刻停止後續實彈，不向其他目標補發。每個實彈都有短促爆彈飛行→爆炸與衝擊，沿用結果／升級延後的演出順序。原發射器仍是一發 54–64、彈匣 2；雷鳴以較多耗彈換取連發，不保證每次都能射滿三發。

新增軍械使自動通關 bot 暴露原補給策略缺陷：想存兩匣（18）卻超過榴彈攜帶上限（12），反覆撿滿額補給。只修 tools/balance.mjs 的補給／終端目標為 min(兩匣,容量)，未提高遊戲容量；原 12 個種子的全通關／終止檢查通過。

## 待處理的偵察兵

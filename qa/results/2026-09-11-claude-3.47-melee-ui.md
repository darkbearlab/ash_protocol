### 問題：伏擊「目標看不到你」在近戰距離不會成立

近戰只能打上下左右相鄰的格子，而相鄰的兩個單位一定互相看得到：戰術視線在距離 1 時會忽略煙霧。

實測（`ambushReady` 與「目標看得到忍者」）：

| 情況 | 目標看得到忍者 | 伏擊 |
| --- | --- | --- |
| 相鄰，兩人都在煙霧裡 | 是 | 否 |
| 相鄰，只有目標在煙霧裡 | 是 | 否 |
| 相鄰，目標還沒發現你 | 是 | 否 |
| 斜角（距離 2，砍不到），兩人都在煙霧裡 | 否 | 是 |
| 隔兩格，中間有煙霧 | 否 | 是 |

所以三個條件實際上只剩「暗處」與「目標失能」兩個。使用者原本的描述是「一方在煙霧中」；我寫規格時用了「沿用現有視線判定」，沒發現這個落差，是規格的疏漏，不是 Codex 做錯。

介面上的副作用：目標還隔著煙霧、離你幾格時，狀態列與目標卡會顯示「伏擊 ×1.5」，走到旁邊就消失。介面讀的就是規則函式，規則改好後會自動正確。

建議改法（屬規則層，交 Codex）：

1. 伏擊條件改為「目標失能、目標或忍者站在煙霧格內、忍者站在暗處」。
2. 可選：再加「目標尚未發現你」（偷襲），讓先手也算伏擊。

兩者都不影響存檔格式。請使用者決定要不要改、改成哪一種。

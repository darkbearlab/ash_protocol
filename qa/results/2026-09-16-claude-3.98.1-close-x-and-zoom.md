# 3.98.1 移除右上角的 ×、禁止縮放、標題與結算改回整頁（Claude，2026-09-16）

## 範圍

- 使用者回報一：背包右上的 × 佔掉右邊一整欄，而返回已經有拇指可達的按鈕。
- 使用者回報二：也要不允許縮放。
- 使用者回報三：從主選單按「新任務」時，上半部會露出剛結束那一局的畫面（之前只是被蓋住，沒有清掉）；任務結算視窗的高度也要回到之前的位置。
- 移除 `#modal-close` 與 `.modal-close` 樣式，以及 `modal()` 的 `closable` 判斷；另外禁止雙指與雙擊縮放。
- 只改介面（index.html、style.css、controller），規則與存檔不變。

## 為什麼變成一整欄

- `.modal-close` 是 `float:right` 的 44×44 方塊，左邊還有 10px 外距。
- 3.97.2 把有分頁的選單改成填滿高度後，`#modal-content` 變成 flex 欄。flex 容器自成一個格式化脈絡，整塊都會避開浮動元素，不像一般文字只繞過前幾行。
- 實測（375×635、背包武器分頁）：把同樣的浮動方塊放回去，`#modal-content` 從 **343 → 295**，整條高度都少 48px；拿掉後回到 343。

## 禁止縮放

三層一起做，因為沒有任何一層在 iOS Safari 上單獨可靠：

| 層 | 內容 | 實測 |
| --- | --- | --- |
| viewport | `maximum-scale=1,user-scalable=no` | meta 已生效（iOS Safari 會忽略，留給其他瀏覽器） |
| CSS | `html{touch-action:pan-x pan-y}` | `getComputedStyle(html).touchAction` = `pan-x pan-y`；touch-action 沿祖先鏈取交集，等於整頁禁止雙指縮放與雙擊放大 |
| JS | 擋 `gesturestart`／`gesturechange`／`gestureend` | 對 body 派送可取消的 `gesturestart`，`defaultPrevented` 為 true |

- **捲動不受影響**：設定選單 `scrollHeight>clientHeight`，`scrollTop=200` 設得進去。
- **滑桿不受影響**：白線不透明度滑桿仍是 `touch-action:pan-y`（與 `pan-x pan-y` 取交集後不變），水平拖曳仍歸滑桿處理。
- **戰場**：`#battle` 仍是 `touch-action:none`。
- **取捨**：頁面層級的縮放完全關掉，字太小時只能靠系統層級的放大鏡。使用者要的是實體遊戲機手感（3.97.0 起的方向），這裡照辦。

## 標題流程改回整頁

- `modal()` 依 `titleFlow` 加上 `standalone`，樣式沿用標題畫面：整頁、不透明 `#0d1211`、`::backdrop` 同色。
- `titleFlow` 為真的三個入口：`showIntro()`、`showResult()`、以及在非進行中的局按下部署（結算的「重新部署」）。`#modal` 的 `close` 事件一律設回 false。

| 畫面 | 版面 | 實測（375×812） |
| --- | --- | --- |
| 主選單 → 新任務 | 整頁 | `standalone wide`，0..812，底部列 732..812 |
| 任務結算 | 整頁 | `standalone`，0..812，底部列 732..812（原本是 280..812 的抽屜） |
| 結算 → 重新部署 | 整頁 | `standalone wide`，0..812 |
| 局內設定（戰鬥中） | 底部抽屜 | class 為空，維持 3.97.2 行為 |

- 背景實測是 `rgb(13, 18, 17)`（`#0d1211`），後面那一局完全看不到。
- 結算是用「放棄本局」觸發的，和死亡走同一個 `showResult()`。
- 寬螢幕（900×800）：整頁不透明，但內容欄限寬並置中（`.wide` 為 650，量到 125..775），不會拉成一整排。
- 回程確認：結算 →「重新部署」→ 返回主選單，標題畫面仍是 `title`；局內選單仍是空 class。

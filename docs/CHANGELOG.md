## 3.1.1 手機回饋修正（2026-09-09）

- 原下樓鍵統一負責拾取／終端／電梯／投擲確認；同時存在多種互動則開選單選擇。E 同步支援。沒有動態增加的互動提示列。
- 手榴彈按鈕切換至瞄準後成為「取消投擲」，右下互動鍵為「確認投擲」。移除自傷警告列，爆炸仍會自傷。
- 戰術訊息固定單行 28px，超長省略；鎖定區與武器列固定 44px，避免文字換行改變戰場尺寸。
- 使用者允許生命、等級、縮放與復位覆蓋地圖角落：現為半透明小 HUD；復位重設縮放為 1。正方形戰場與角色／目標自動取景保留。
- 停用選字與戰場長按選單；輸入欄仍可編輯／選字。
- 屍體用原生解析度 canvas 預先處理成 30% 彩度、80% 亮度，保留原色；攻擊特效與活人不變。不依賴手機 Canvas filter 支援。
- 320×568 Chromium 實測：手榴彈瞄準前後戰場均 262×262，控制區位置／高度不變，沒有橫向溢出，body user-select:none。
- 掃描資訊區搬移與防禦／等待重設計留待下次討論，見願望清單。完成發布後暫停。

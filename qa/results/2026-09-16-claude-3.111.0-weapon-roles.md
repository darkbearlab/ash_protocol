# 3.111.0 精準步槍要瞄準、榴彈發射器改打地板 — 驗證報告（Claude，2026-09-16）

## 使用者定案

看完 [武器統計](2026-09-16-claude-weapon-statistics.md) 後：

- 精準步槍「不用跳過回合來瞄準的話精準度要大幅下降才行」。
- 榴彈發射器「要像投擲物的榴彈一樣命中一個點以及周遭區域 不是敵人本體」；「榴彈不設最短距離 玩家要打到自己是自己的事」。
- 霰彈槍（射程 6、錐形、每人各自判定、要距離衰減、會打到友軍）「等前兩個驗證過後再來做」。規格記在 docs/WEAPONS.md。

## 規則層

**SR-07**：`WEAPONS` 卡片加 `aimPenalty:40`。`shotChance` 在攻擊者是玩家、武器有 `aimPenalty`、且 `attacker.focus` 為假時扣掉它。`focus` 是既有機制：等待成功就設為真並給 +15，任何其他行動結束時清掉。所以「瞄準」就是原本的等待，沒有新狀態、沒有新存檔欄位。友軍與敵人沒有等待瞄準的方式，因此只對玩家生效。

**GL-03**：卡片加 `pointTarget:true`，新行動 `launch`：

- `launchReason(g,pos)` 是唯一的拒絕來源，驗證、結算、介面、機器人共用：武器不是點目標／彈匣空／不是地板／超出射程或看不見。
- `Game.launch(pos)`：扣 1 發、記轉角暴露與彈殼、擲一次傷害、在落點 `explode(pos,1,…)`，**不擲命中**。
- `action('fire')` 遇到點目標武器時，轉成對鎖定目標那一格（隔板則取朝向玩家那一面）的 `launch`。鍵盤、機器人與任何送出 `fire` 的地方都不用改。
- 追擊（免費攻擊）清單加入 `launch`。
- 沒有最短射程：`explode` 本來就會傷到半徑內的玩家。

## 介面

- 開火鍵：點目標武器時改為進入 `renderer.mode='launch'`，預設落點是鎖定目標或射程內最近的可見敵人，地圖上以半徑 1 標出爆炸範圍。方向鍵與點地圖移動落點（`setAim` 改成依模式取射程），右下「確認發射」，開火鍵變成「取消發射」。發射失敗不退出選點。
- 瞄準卡：點目標武器顯示「落點必定爆炸」；精準步槍未瞄準時列出「未瞄準 −40」。
- 狀態列：精準步槍未瞄準時顯示「未瞄準 · 命中 −40」；瞄準後由既有的「瞄準 +15」表示。

## 量測：士兵機器人整局只用一把槍（12 seed）

機器人同步學會新打法：精準步槍在 2 格內沒有敵人時先等待；發射器選「炸到最多敵人、距離自己至少 2 格」的格子。

| | 平均層數 | 通關 | 平均擊殺 |
| --- | ---: | ---: | ---: |
| AR-09（對照組） | 2.50 → 2.50 | 0 → 0 | 42.8 → 42.8 |
| SR-07 | 4.33 → 4.42 | 3 → **0** | 87.3 → 91.0 |
| GL-03 | 1.00 → 1.50 | 0 → 0 | 10.2 → 15.1 |
| GL-03，彈藥無限 | 1.58 → **3.08** | 0 → 0 | 20.1 → **60.3** |

- 對照組逐 seed 完全相同，改動沒有外溢到其他武器。
- **SR-07**：打得一樣深（6 局到第 6 層），但通關從 3 局變 0 局。從「見佛殺佛」降成「仍然最能深入、但不再保證贏」。
- **GL-03 的規則改動本身有效**：把彈藥拿掉後，擊殺變成三倍、平均層數接近翻倍，比突擊步槍更深。
- **一般補給下它仍然被彈藥卡住**：清一層需要 34–42 發，每層只拿到 4–5 發（第 1、2 層是 0，這是 3.110.x 的補給削減造成的）。單槍測試從第 1 層就只帶發射器，比實際遊玩嚴苛；實戰中 GL-03 在第 4 層才出現。

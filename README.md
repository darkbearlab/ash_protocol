# ASH PROTOCOL / 灰燼協定 3.8.0

原創科幻回合制射擊 roguelike，為手機瀏覽器設計。**↑ ↓ ← → 直接對應畫面上下左右**。每次有效行動，敵人也行動一次。

[直接遊玩](https://darkbearlab.github.io/ash_protocol/) · [GitHub 原始碼](https://github.com/darkbearlab/ash_protocol)

每次完成更新都整合至 main，GitHub Actions 自動測試及部署。

## 開始

需要 Node.js 20+，不用安裝套件。

```sh
npm start
```

電腦開啟 http://localhost:5173 。手機與電腦連上同一 Wi-Fi 後，輸入 `http://電腦的區域網路IP:5173`，必要時允許伺服器的防火牆提示。手機的 localhost 指向手機自己。

## 內容

- 六層隨機設施、中途頭目、核心守衛與完整撤離結局。
- 六種武器、六種詞條、五種備彈、三格武器背包、比較交換、拆解與改裝。
- 牆角探身互射、可破壞掩體、油桶連鎖、手榴彈範圍預覽與自傷。
- 敵我共用命中率：暴露靜止 97%、移動 −22%、箱體 −35%、牆角 −42%。
- 低耐久槍兵、連續射擊及交叉火力；暴露在多條射線下會迅速陣亡。
- 十類敵人、預警射線、狙擊瞄準、無人機、頭目轟炸及增援。
- 毒液 / 高熱、中毒、防禦、八種升級模組、補給終端。
- 資料片段、敵人圖鑑、任務歷史、存檔匯出 / 匯入。
- GPT Image 原創素材經轉換為真 32×32、4-bit、16 色點陣精靈；保留製程與原圖。

## 操作

| 操作 | 觸控 / 鍵盤 |
| --- | --- |
| 移動 | 十字方向鈕 / 相鄰格 / 滑動 / WASD 或方向鍵 |
| 鎖定 | 點敵人、掩體或油桶；目標鈕 / Tab 切換敵人 |
| 開火 | 開火 / Space |
| 裝填 | 裝填 / R |
| 手榴彈 | G 或手榴彈 → 點落點或方向鈕選位置 → 右下互動鍵確認；手榴彈鍵取消 |
| 醫療 | H |
| 背包 | B 或背包按鈕 |
| 瞄準顯示開關 | Q 或瞄準鈕，不耗回合 |
| 換槍 | 背包直接選武器，耗 1 回合 |
| 等待 | 十字鍵中央 / 句點；本回合閃避 +15、下次行動射擊命中 +15 |
| 互動 | 右下互動鍵 / E：拾取、終端、下樓或確認投擲 |
| 設定 | 右上選單 / Escape |

查看背包、瞄準和圖鑑不耗回合。換槍、改裝、拆解、補給與使用物品耗費一回合。站在掩體背面減少射擊傷害；爆炸會傷害自己。第三層與第六層須擊敗頭目才能離開。

## 存檔和離線

每步存於本機瀏覽器。舊版存檔會備份並自動遷移；既有樓層不重置。設定可匯出 JSON，換瀏覽器後再匯入。死亡會結束該任務。協定點數存在目前瀏覽器的全局紀錄；設定的「完整備份／還原備份」包含錢包、解鎖、歷史與目前任務。原本的「匯出任務」仍僅包含單局。還原會以快照替換，並先保存可下載的還原前備份。

Service Worker 需 HTTPS 或 localhost；區域網路 HTTP 可遊玩、存檔，但不能安裝離線快取。首次完整載入後核心資產可離線；Google Fonts 失聯時使用備用字型。

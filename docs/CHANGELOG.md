# 更新紀錄

## 3.10.1 — 2026-09-09

- 依使用者更正，承諾射擊後目標先逃出視線／射程或死亡也照常耗彈；向最後確認位置射擊落空，不改打其他敵人。仍可射擊時繼續追蹤原目標新位置。
- SMG 遵守連發／殘彈數；玩家先被擊殺則取消尚未執行的攻擊。更新自動測試、指南與驗證紙條，存檔格式不變。

## 3.10.0 — 2026-09-09

- 加入獨立被動來源、期限與反向抵銷：大型／小型、敏捷／笨拙、快速／緩速，以及無法利用掩體。敵我共用公式。
- 快速 → 普通 → 緩速，同速玩家優先，每輪每單位一次；有效指令承諾後追蹤原目標，若先失去射線／射程則耗回合並耗彈。
- 無人機不獲得掩體、鐵殼破壞者更易被命中、第 4 層起裂隙獵犬快速行動；浮卡、圖鑑與指南顯示規則和順序。
- 等待／移動狀態維持至自己的下次行動，回合末統一處理轟炸與環境；可見先手移動加入演出，擊殺及升級仍按先後呈現。
- 單局 v7 保留 traits，舊檔原地遷移與 v6 原件備份；新增規則測試、六份 QA 場景與 TRAITS.md。玩家角色、重生／堅毅及更多 AI 留待後續。

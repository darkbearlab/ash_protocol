# 壓制、學習道具與未識別貨櫃內容池（規格，2026-09-14）

- 狀態：**3.74.0 規則與內容已實作；Claude 接介面。實作現況與交接見第 11、12 節。**
- 數值：每層命中懲罰、技能消耗發數與給予層數、連射的命中懲罰、彈藥回收各階機率等**數字交 Codex 決定**。
- 範圍：統一的壓制核心規則、主動技能「壓制射擊」、被動「連射」、技能與被動學習道具、未識別貨櫃內容池、彈藥回收升級、寵物砲台壓制節點改走新規則。

## 1. 壓制核心規則

全遊戲只有一套壓制規則。每一次施加壓制照以下順序計算：

1. **來源給層數**，分三種：
   - **武器被動**：一次攻擊行動打出**至少 3 發**、**而且命中**目標，給 1 層。每次攻擊行動最多 1 層；沒命中不給。
   - **技能類**：範圍內的敵人**不論命中與否，保底至少 1 層**；技能可以給更多。
   - **寵物砲台（德魯伊砲台線 ◆2「壓制」）**：歸技能類。命中率、傷害照舊，每次射擊行動給目標**保底 1 層**。
2. **頭目：最終結果 −1**。保底的 1 層同樣會被扣成 0。
3. **機械單位：完全不受壓制**，直接歸 0，沒有任何懲罰。
4. 疊加，**上限 5 層**。
5. **3 層以上不能移動**，仍可攻擊與進行其他行動。將來「無所畏懼」這類高士氣標籤仍吃層數的命中懲罰，但不會被釘住。
6. **單位自己的回合結束時層數減半，取整向下**（3→1、2→1、1→0），敵我相同（3.145.0，使用者 2026-09-19 決定）。
   - 以前是每回合結束時統一減半。玩家在敵人階段吃到的層數，會在自己行動前就先減半，所以玩家實際上從來不會被釘住（5 層也只剩 2）。
   - 失能、被跳過的回合也算「回合結束」；錨定的兩次攻擊在第二次之後才減半。

- 每一層降低射擊與近戰命中，數值交 Codex。
- 規則雙向適用：將來敵人也能壓制玩家與友軍，目前沒有敵方來源。（3.145.0 註：這句已過時。現在敵人連射命中 3 發以上、小隊的壓制射擊、外骨骼損毀都會壓制玩家；新規則下這些層數會完整作用在玩家的下一次行動。）

### 1.1 已知的疊加性質

以自己回合結束時減半計算（3.145.0 前是回合末），每回合吃到的層數與穩定後目標行動時的層數：

| 每回合吃到 | 穩定時層數 | 3 層不能移動 |
| ---: | ---: | --- |
| 1 | 1 | 動得了 |
| 2 | 3 | 每回合都不能移動 |
| 3 | 5 | 每回合都不能移動 |

- 單一來源每回合 1 層永遠疊不起來；**兩個來源每回合各給 1 層，就能讓目標持續不能移動**。
- 例：德魯伊砲台保底 1 層，加上玩家輕機槍命中 1 層，會形成鎖定流派。使用者已確認門檻暫定 3 層。
- **將來敵人取得標籤攻擊時要重新檢查**：兩名帶標籤的敵人即可讓玩家持續不能移動。

### 1.2 取代的舊機制

- 移除寵物的 `petSuppressed`（−15、目標下一次行動用掉）：寫入在 `pet-growth.js:186`，扣命中在 `actor-stats.js:7`，清除在 `game.js:584` 與 `game.js:283`，驗證在 `traits.js:76`，並隨樓層封存。
- 舊存檔中的 `petSuppressed` 需要遷移或清除，由 Codex 決定並升存檔版本。
- 目標卡原本的「壓制 −15」改為顯示層數（介面由 Claude 接）。

### 1.3 目前能觸發武器被動的武器

依武器資料，每次攻擊打出至少 3 發的只有：**堡壘輕機槍**（3 發、彈匣 30）與**雷鳴爆彈槍**（3 發、彈匣 9）。蜂群衝鋒槍每次 2 發，要靠壓制射擊或「連射」被動才觸發。

## 2. 主動技能「壓制射擊」

- **取得**：未識別貨櫃掉出的學習道具（第 4、5 節）。
- **預備**：與職業技能**共用唯一的技能預備欄**（使用者決定不開第二格）。
- **使用**：消耗目前武器彈匣中的**固定發數，至少 3 發**。彈匣不足時不能使用。
- **射擊**：打出的每一發照常判定命中與傷害，但**命中下降**；範圍內敵人依第 1 節「技能類」取得層數（保底 1 層，技能可給更多，並有技能自己的加成）。
- **不設冷卻**：彈匣與換彈就是自然冷卻（使用者決定）。
- 預設視為攻擊行動，花 1 回合。
- **目標形式：區域**（使用者決定）。選一個看得見的格子，該格與相鄰一圈為範圍；形狀與判定交 Codex，建議沿用投擲物的範圍計算。瞄準沿用投擲物「點地板、右下確認」的流程。
- **射擊分配**：打出的子彈射向範圍內可射擊的敵人，分配方式交 Codex（建議輪流或平均）。
- **轉角後的敵人：吃層數、不受傷害**（使用者決定）。能不能被子彈打中照轉角規則判定；壓制層數照樣施加。
- **同時觸發武器被動**（使用者決定）：技能打出的發數同樣算一次攻擊行動。若該次行動打出至少 3 發，被至少一發命中的敵人另得武器被動 1 層（每名敵人每次行動最多 1 層），與技能給的層數相加。
- 同一次行動對同一名敵人的層數合計後，再套用頭目最終 −1（建議只扣一次，Codex 可調）與機械免疫。

**依彈匣大小，換彈前可使用的次數**（以每次 3 發計）：

| 武器 | 彈匣 | 次數 |
| --- | ---: | --- |
| 日蝕榴彈發射器 | 2 | 不能使用 |
| 寂靜精準步槍 | 3 | 1 |
| 破門者霰彈槍 | 4 | 1 |
| 極光電漿步槍 | 6 | 2 |
| 餘燼突擊步槍 | 8 | 2 |
| 雷鳴爆彈槍 | 9 | 3 |
| 蜂群衝鋒槍 | 18 | 6 |
| 堡壘輕機槍 | 30 | 10 |

小彈匣武器的冷卻明顯；衝鋒槍與輕機槍實際上只受備彈總量限制。

## 3. 被動「連射」

- **取得**：未識別貨櫃掉出的學習道具；學會後直接生效，不佔預備欄。
- **效果**：使用槍械的每次攻擊行動**多打 1 發**，該次攻擊的**每一發**命中下降。彈藥照發數消耗；彈匣不足時打到剩餘發數為止（沿用現行規則）。
- **不排除榴彈發射器**（使用者決定：發射器彈藥取得已經很少）。近戰不受影響。
- 連帶效果：
  - 衝鋒槍 2→3 發，**自動達到武器被動壓制的 3 發門檻**；偵察兵延伸點射 5 格內 2→3 發同樣觸發。
  - 輕機槍、雷鳴爆彈槍 3→4 發。
  - 單發武器每次攻擊耗彈 +100%，衝鋒槍 +50%，輕機槍 +33%。

## 4. 學習道具

- **流程**：從未識別貨櫃取得學習道具 → 在**道具分頁**使用 → 技能或被動出現。主動技能進技能分頁、可預備；被動直接生效，列入「目前被動規則」。
- **使用不花回合**（使用者決定）。
- 學習道具**不走道具預備欄**，避免佔掉醫療包的預備位置；道具分頁為學習道具提供直接的「使用」按鈕。
- **所有學習道具都有「拆解成廢料」的按鈕**（使用者決定），廢料數交 Codex；建議與使用一樣不花回合。
- **存檔**：
  - 需要新增「持有的學習道具」欄位。
  - 學會主動技能時，同時把技能加入 `skills` 並初始化 `skillState`（`validSkillState` 要求兩者一致）。
  - 學會被動時，以新的被動來源（source）加入；請確認存檔的被動驗證接受這個來源。
- 經查，**存檔驗證沒有把技能綁在職業上**；程式中 `character===` 的判斷只出現在舊存檔遷移、重裝兵動力拳驗證（`game.js:869`）、重裝兵基礎數值（`perks.js:67–68`）與開局建立友軍（`allies.js:108–109`）。被動效果都以被動本身判定，其他職業學會後照常生效。

## 5. 未識別貨櫃內容池

> **3.113.0 更新（使用者要求）**：8 種職業主動技能學習資料已移出內容池（工坊／僚機、伴生指揮、亡者集結、預警、下錨、訊號斷層、鉤鎖、光學迷彩），當初加入只是為了驗證技能可以單獨掛載。主動技能只剩**壓制射擊**；被動學習資料未動。使用者決定（2026-09-17）：**被動暫時保留**，等之後內容更多再刪，暫且當作等級滿了之後的成長來源之一。內容池現為 20 種。下方表格與 5.2 節保留為歷史紀錄。

- 3.65.0 起每層生成 0～2 個未識別貨櫃（`map-slots.js:88`），目前內容為空。本規格讓每個貨櫃裝 **1 項**，由地圖種子決定。
- **這一輪全部開放**；將來綁進解鎖（每項預留 `unlockId`，目前忽略）。目前所有武器都沒有 `unlockId`。

| 類別 | 內容 |
| --- | --- |
| 武器 | 堡壘輕機槍；狂戰斧（拾獲版）；忍刀（拾獲版） |
| 主動技能學習道具 | 僚機（`drone_follow`＋`drone_sentry` 一組）、伴生指揮、亡者集結、預警、下錨、訊號斷層、鉤鎖、光學迷彩，以及新的**壓制射擊** |
| 被動學習道具 | 架槍、著彈修正、側身、快速裝填、夜視、紅外線、延伸點射、戰術配給、嗜血、戰意、刃藏、重裝防護、伏擊、單挑，以及新的**連射** |

- **不入池**：缺點類被動（大型、笨拙、緩速、難以治療）與身體標籤（生物、機械）。職業數值與配給（例如忍者投擲容量 +2）不是被動，也不在池內。

### 5.1 拾獲版近戰武器

- 狂戰斧、忍刀、動力拳在武器資料上寫死 `locked:true`、`integrated:true`（`data.js:20–23`），`canSalvageOwned` 會拒絕拆解；重裝兵另有「必須恰好一把動力拳」的驗證（`game.js:869`）。
- 貨櫃掉出的斧頭與刀必須是**不綁定的版本**：可以拆解、交換，而且不能影響狂戰士與忍者原本綁定武器的驗證。
- **拾獲的近戰武器必須能用於撞擊近戰**：`bumpMeleeSlot` 要求切換進出都不耗回合，否則撿到也無法撞擊攻擊。
- 狂戰士「刃藏」依攜帶的近戰武器數量加成，拾獲版應一併計入（沿用現行判定）。

### 5.2 原生技能給其他職業

- **伴生指揮**：比照德魯伊開局建立寵物（`allies.js:109`：以 `addAlly` 建立 `pet_command` 來源的寵物後 `placePet`）；羈絆資料會在 `addAlly` 時自動建立（`allies.js:66`）。德魯伊職業升級仍只限德魯伊。
- **僚機**：比照工程師開局加入收納中的機體（`allies.js:108`），兩個僚機技能一起學會。
- **亡者集結**：`tickSummons` 只檢查是否學會 `raise_dead`，學會即自動起身。
- **下錨、鉤鎖、光學迷彩、預警、訊號斷層**：請 Codex 確認沒有只寫給原職業的假設（例如下錨與重裝兵的笨拙、重武器；近戰職業的 `MELEE_TUNING`）；鉤鎖的追擊可用全職業徒手近戰。

### 5.3 原生被動給其他職業（平衡提醒）

使用者決定本輪全部開放，以下是將來綁解鎖時分級的參考：

- **重裝防護**（直接傷害 −25%）原本由重裝兵的大型、笨拙、緩速、難以治療換來，單獨學會沒有代價。
- **夜視＋紅外線**是偵察兵的核心，也和德魯伊裝甲線 ◆6「看穿」重疊。
- **嗜血、戰意、刃藏、伏擊**主要服務近戰；搭配全職業徒手近戰與拾獲版斧頭、刀才有明顯效果。
- **延伸點射**只對衝鋒槍有效；**快速裝填**只對使用手槍彈的武器有效。

### 5.4 已學會、已持有或原生就有時

使用者決定：**照樣收入道具**，不重抽、不自動轉換。玩家可以用每個學習道具都有的「拆解成廢料」按鈕自行處理。已學會的學習道具不能再使用（或使用時提示已學會），由 Codex 定。

## 6. 通用三選一「彈藥回收」

- 三階，提高一般敵人擊殺時的彈藥掉落機率（現行 35%）；各階數值交 Codex。
- 雜兵、巢穴子代、撤退增援照舊不掉落（`game.js:483`），巢穴不會變成彈藥農場。
- 模式比照 3.51「裝甲回收」的 `plateDrop`。
- **掉落位置**：擊殺位置已經有物品時，改放在相鄰的可站立地板上；沒有空位才留在原地。**適用於所有敵人掉落**（武器、彈藥、護甲板），不只這個升級。

## 7. 彈藥經濟量測（2026-09-14）

報告：[qa/results/2026-09-14-claude-ammo-baseline.md](../qa/results/2026-09-14-claude-ammo-baseline.md)；腳本 `node qa/ammo-usage.mjs`。

- **總量充裕**：消耗最多的重裝兵每層約 19～28（終端價格換算），全清供給每層約 118～158。
- **真正的限制是各彈種的攜帶上限**：步槍彈使用者（士兵、德魯伊、重裝兵）每層結束時多在上限 72 的六到十成，重裝兵幾乎是滿的。新的彈藥消耗會先吃掉這個 72 發的緩衝。
- **最緊的是手槍彈**：偵察兵第 6 層平均剩 48/120，三分之一的局低於四分之一上限。衝鋒槍加上「連射」會最先感受到壓力。
- **建議**：暫不提高基礎供給；彈藥回收升級針對高消耗 build；壓制射擊與連射實作後，用同一支腳本重測；若仍不足，優先考慮攜帶上限而不是總供給。

### 11.1 數值與時序

| 項目 | 本版數值／語意 |
| --- | --- |
| 壓制 | 0～5；每層射擊與近戰命中 −8；3 層以上禁止主動移位 |
| 武器來源 | 實際射出至少 3 發且命中，每個受擊敵人 +1；不是每發 +1 |
| 壓制射擊 | 基礎 3 發、每發命中 −20；區域內 +1，命中者另有武器來源 +1 |
| 區域 | 武器射程內可見地板為中心；中心＋上下左右一圈（最多 5 格），沿用投擲物的爆炸通路檢查，不穿實牆／關門 |
| 子彈分配 | 存活且可射擊者按 ID 排序輪流射擊；每發重查，沒有可射擊者仍向固定區域開火並耗彈 |
| 連射 | 每次槍械攻擊額外 1 發，每發命中 −10；壓制射擊變 4 發（只有 3 發則射 3 發）；兩種榴彈武器也適用 |
| 彈藥回收 | 35%／50%／65%／80%，上限三階；單次掉落數量與原有排除旗標不變 |
| 學習資料拆解 | 每份 15 廢料，免費；學習同樣免費 |

（3.145.0 起改成各單位自己的回合結束時減半，見第 1 節第 6 條；下面是當時的紀錄。）壓制在整個付費世界回合結束時統一減半，不在敵人自身機會清除。失能跳過行動仍會走回合末衰減；預備、學習、拆解、免費裝填、追擊免費攻擊不衰減。兩來源各 +1 的鎖定性質保留：目標行動時依次為 2、3、3…層。先行的快速敵人會在新壓制施加前活動，沒有改先後手。

不能移動包含走路、翻越、換位、影步與主動鉤鎖衝刺；原地射擊、撞擊近戰、裝填、等待、使用道具仍可用。受鉤鎖強迫拉動不是自己的移動行動。換層會移動玩家，壓制時同樣拒絕。友軍使用共用層數判定，禁止繞路／換位，但仍可從原位攻擊。原生敵人目前沒有新增壓制來源。

頭目減一只在一次攻擊的所有來源合計後套用一次，再套機械免疫；目前核心守衛與封鎖官都是機械，所以完全免疫。測試另用非機械頭目側寫驗證減一，不修改正式頭目身體標籤。

區域射擊允許轉角隱藏敵人吃保底層數，不給子彈傷害；榴彈與油桶連鎖也維持此限制。正常射擊／手榴彈爆炸規則沒有跟著改。技能使區域敵人得知開火位置，照常記錄轉角暴露。追擊可支付壓制射擊的回合成本；下錨使它在普通與緩速各執行一次，兩次分別支付彈藥，第二次不足 3 發即失敗且不扣殘彈。學習到的下錨同樣適用。

### 11.2 內容與跨職業確認

內容池共 **27 項、等權**：3 武器、9 主動技能資料（僚機兩技能合一份）、15 被動資料。`UNKNOWN_LOOT[].unlockId` 現為 null、不過濾。以 seed／floor／貨櫃 ID 的獨立雜湊抽選，不消耗戰鬥亂數，不受開箱順序或背包內容影響；抽到的內容存進 `container.contents`。武器開箱時才註冊單局 slot，詞條沿用既有獨立雜湊流程。原生已有／學過／持有的資料照收，使用時拒絕已學會且不消耗，可自行拆解。

- 武器 base 11 `loot_axe`、12 `loot_katana` 追加在原清單尾端。保留 integrated（雙向切換免費），移除 locked／boundCharacter；可撞擊、交換、改裝、拆解及餵寵物。原本 base 9／10 綁定驗證不變。
- 僚機：同時新增 `drone_follow`／`drone_sentry`，建立一台收納機體；重複學習不再建機。
- 伴生指揮：建立 arriving 寵物與 petBond，再嘗試放在身邊；沒有空格就等待落點。餵食、重生與換層同行照舊，並不取得德魯伊專屬三選一。
- 亡者集結：原本就按 skills 判斷，自動起身照常。
- 鉤鎖：移除綁定斧頭要求，使用 `bumpMeleeSlot()`，無合格武器時用徒手。大型／頭目仍是自己衝，其他拉來；下錨或壓制時不能自己衝。
- 下錨、光學迷彩、預警、訊號斷層：均按技能狀態生效，無新增職業限制。職業三選一仍按原職業限定，沒有跟技能一起贈送。
- 拾獲近戰使「所有可拆解武器都有彈藥」的舊假設不再成立；背包拆解、地面拆解與餵食已跳過近戰彈匣退款。

掉落位置一律先用擊殺格；已有物品則依既有四方向順序找無物品、無單位、可站立且能跨越的相鄰格，找不到才疊回原格。武器、彈藥、醫療包、護甲板均使用同一入口。

## 12. Claude 介面交接

不要讓 UI 直接修改數量、traits、skills、skillState 或 suppression。以下公開查詢可從 `src/engine.js` 匯入（內部分模組亦可）。使用中的畫面應讀 presentation 當下的 game，避免提前顯示命中結果。

### 12.1 學習資料

`learningInventory(game)` 回傳僅持有項目的陣列：

```js
{ id:'trait_rapid_fire', count:2, name:'連射學習資料', trait:'rapid_fire',
  unlockId:null, scrap:15, useReason:'', dismantleReason:'' }
// 技能資料改為 skills:['drone_follow','drone_sentry']，沒有 trait。
```

空 reason 表示可用；已學會時 useReason 有說明，拆解仍可用。`LEARNING_ITEMS` 是完整資料目錄。道具分頁直接呼叫：

```js
game.action('learn', learningId);
game.action('dismantleLearning', learningId);
```

兩者都不花回合，也不改目前預備欄；成功後照現有 UI 流程存檔／重畫。新技能仍要去技能頁預備。被動列表沿用 traits；請不要只列 character: 來源。地面新物品是 `{type:'learning',learningId,x,y}`，走上去自動收入；請替 renderer 與掃描清單加入資料圖示／名稱，不能假設所有非武器物品都有 amount 或 resource。

### 12.2 壓制狀態

`suppressionState(actor)`：

```js
{stacks:3,max:5,accuracyPenalty:24,immobile:true,immune:false}
```

目標卡移除舊 `petSuppressed` 分支，改層數；不能移動與命中下降是兩個不同結果。回合末減半後通常只留 0～2 層，所以「釘住」常見於敵人結算前的演出快照，不能只看最終輸入狀態推斷沒生效。寵物 turret ◆2 的節點文字已由 `petNodes` 回傳新規則。

### 12.3 壓制射擊區域瞄準

`SKILLS.suppressive_fire.action === 'suppressiveFire'`、`target === 'area'`。沿用投擲物的點格／確認操作，但預備分類是 skill，射程讀武器，不能硬寫 5。

```js
suppressivePreview(game,{x,y});
// {range,minimumRounds:3,rounds,accuracyPenalty:20,reason,cells:[{x,y},...]}
// rounds 含連射、受剩餘彈匣限制；reason 非空不得確認。
game.action('usePrepared',{category:'skill',target:{x,y}});
// 或 game.action('suppressiveFire',{x,y})，同樣驗證已預備技能。
```

`accuracyPenalty` 是技能額外懲罰；連射的 −10 已包含在 `game.weapon.accuracyBonus`，勿再扣。每發有 shot 演出，規則結算沿用 presentStep。不支援 `action('skill','suppressive_fire')`，因為缺少落點；不可用 activateSkill 取代區域動作。預覽只提供格子，不洩漏區域內尚未觀察到的敵人 ID。

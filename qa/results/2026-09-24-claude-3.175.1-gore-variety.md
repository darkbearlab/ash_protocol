# 3.175.1 — 擊殺血光：每次不同、依彈種與威力、暗房變暗

2026-09-24，Claude。規格：docs/KILL_GORE.md（每次都不一樣、暗房）。

## 需求

使用者：「控制敵人血霧效果的看起來是常數？大家血霧效果都一樣的樣子，該有的效果也沒有個體偏差，這些數值可以變成隨機變數嗎？當然如果可以對應彈種和或單發威力去調整效果可能會更好」「敵人撒出的東西似乎沒有跟著暗房調整暗度」。

## 做法

- `src/gore.js`：`makeBurst` 多了 `cone`、`reach`、`mistSize`、`aim`（預設值讓陣亡演出與以前完全相同）。`GORE_STYLES` 六種彈種；`goreForce` 從那一步的效果找出致命一擊的彈種（散彈槍→霰彈、狙擊槍→精準、電漿或能量→電漿、近戰武器或爪擊→近戰、榴彈或爆炸→爆炸，其餘一般子彈）與落在那格的傷害總和；`goreForceScale` = √(傷害/24)，0.7～1.6。`enemyBurst` 用第二條亂數替每次噴濺抽血肉量、噴射角、距離、霧、光與方向偏移。`WEAPONS` 是陣列，照 id 找。
- `src/presentation.js`：敵人倒下事件多帶 `force`。`src/renderer.js` 把彈種與傷害交給 `enemyBurst`。
- 暗房：`src/gore-art.js` 的 `drawBurstAir` 多了 `shade(dx,dy)`，血滴與血霧依所在格子調暗，光在暗處保留七成；`Splatter` 記下有血的格子，逐格依亮暗畫（暗格 0.55，與角色在暗處相同）；`src/kia-art.js` 陣亡演出的噴濺與血泊也一樣。

## 驗證（Claude 自己跑的）

- `tests/gore.test.mjs`：60 個種子統計——平均量仍為陣亡的一半、菁英較多、量／噴射角／距離／方向都會變；霰彈比子彈寬、子彈比狙擊寬、爆炸最寬、近戰最短、狙擊最遠、電漿液體少光多、近戰光很少；傷害 60 比 8 噴得多且遠；各武器的彈種判斷與傷害加總。原本寫死「剛好 23 滴」的一條改成統計檢查。
- 完整 `npm test`：1289 通過、0 失敗。`npm run build` 通過；英文掃描乾淨。這次只改畫面，沒有跑兩項 identity。

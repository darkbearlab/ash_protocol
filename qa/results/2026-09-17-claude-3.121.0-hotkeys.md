# 3.121.0 鍵盤熱鍵設定與按鈕熱鍵提示 — 驗證報告（Claude，2026-09-17）

## 依據

使用者：「鍵盤熱鍵設定，以及在幾個主要按鈕左上顯示對應熱鍵的開關（像行動遊戲模擬器會覆蓋熱鍵提示那樣）。」

## 改動

- **`src/hotkeys.js`（新，純函式）**
  - 18 個指令，分三組：
    - 移動：上下左右、等待；
    - 行動：開火、裝填、投擲、道具、技能、互動；
    - 目標與畫面：切換目標、瞄準資訊開關、背包、樓層地圖、鏡頭復位、放大、縮小。
  - 每個指令兩格按鍵。
- **預設按鍵**
  - 保留原本所有按鍵：WASD／方向鍵、F 與 . 等待、Space 開火、R、G、H、E、Tab、Q、B。
  - 新增原本沒有鍵盤按鍵的五個：技能 V、樓層地圖 M、鏡頭復位 C、放大 =、縮小 -。
- **按鍵規則**
  - 字母不分大小寫（Shift、Caps Lock 不影響）。
  - Esc 固定是選單與取消，不能指定，所以設錯了一定能退回。
  - Shift、Ctrl、Alt、輸入法組字中的按鍵不能指定。
  - 指定一個已被其他指令使用的按鍵時，會從那個指令移過來並告知。
- **存檔讀取**：存在 `ash-hotkeys`。讀取時逐項檢查，壞掉的項目用預設；同一個按鍵出現兩次時，留給清單前面的指令。
- **`src/controller.js`**
  - 鍵盤處理改成查使用者的按鍵表。每個指令呼叫和按鈕相同的函式；放大、縮小、鏡頭復位從按鈕的程式抽成共用函式。
  - 技能鍵在技能按鈕停用時不動作。
  - 「演出中按指令直接執行」仍只由指令按鍵觸發，按住不放的自動重複不會跳過。
- **設定新增「鍵盤」段**
  - 「按鈕上顯示熱鍵」開關，存在 `ash-hotkey-hints`，預設關閉。
  - 「熱鍵設定」畫面：點一格後按新按鍵，Backspace 清掉、Esc 取消；另有「恢復預設」。等待按鍵時點任何其他按鈕都會結束等待。
- **熱鍵提示**
  - 每顆主要按鈕帶 `data-hotkey` 屬性，開關打開時由 CSS 在左上角畫一個小標籤。用屬性而不是插入元素，所以遊戲改寫按鈕文字（例如開火變「確認發射」）時標籤不會消失。
  - 標上的按鈕：方向鍵四顆、等待、開火、裝填、投擲、道具、技能、互動、目標、瞄準、背包、鏡頭復位、縮小、放大、樓層地圖；右上選單鈕固定顯示 Esc。
  - 格狀排版搬動按鈕位置後，標籤跟著按鈕走。
- 操作手冊補一句：手冊寫的是預設按鍵，可在設定更改。

## 驗證

### 自動測試（新增 `tests/hotkeys.test.mjs` 5 個）

- 預設按鍵涵蓋所有舊按鍵，新增的五個不互相衝突。
- 字母正規化；Esc、修飾鍵、空字串不能指定；按鍵標籤。
- 指定已被使用的按鍵會移過來，同一指令另一格的同一按鍵也會移走；清除；原本的按鍵表不被就地修改。
- 讀取存檔：壞 JSON、錯誤型別、同一按鍵重複。
- 接線：每個指令都有對應函式、按鈕與按鍵共用縮放與復位、提示屬性與 CSS、每個提示選擇器都是頁面上真的按鈕。

## 最新交付：3.82.0–3.82.1 — 平民與研究員（3.82.0 Codex 規則與精靈圖，3.82.1 Claude 台詞與標籤）

- **怎麼看到**：部署時選忠誠者，或依種子抽到忠誠者。起點房以外，每層有 3–5 名淺色衣服的研究員。
- **規則（3.82.0）**：
  - 看見玩家就一直逃，會開門逃跑。
  - 尖叫會讓附近的守衛警戒，5 個付費回合後可以再叫。
  - 可以手動瞄準與射擊；打倒不給經驗、不計擊殺。
  - 存檔版本 save42。
- **介面（3.82.1）**：
  - 研究員有自己的台詞：尖叫、逃跑（大約每 3 回合一次）、受傷、重傷、被壓制；牆後聽到的也是研究員的聲線。
  - 目標卡的標籤行為「忠誠者 · 非戰鬥人員 · 生物」。
  - 修正：研究員的圖原本比其他角色暗，現在亮度一致；尖叫紀錄改為「滯留研究員尖叫，附近的守衛警戒了。」
- **可以檢查**：
  - 研究員看到你時尖叫，附近守衛是否因此趕過來。
  - 逃跑台詞；五回合後再次尖叫。
  - 牆後聽到的喊話；打倒後的倒地圖；存讀檔。

## 瀏覽器（本機 dev server，`?test=1`）

1. 主選單出現 KILL HOUSE；沒有戰役時 CONTINUE 停用。
2. NEW GAME 跳出「進入模擬訓練？」。
3. 進入模擬訓練：
   - 第 1 區卡片正常顯示。
   - 走 10 步後，頂端是「KILL HOUSE · 模擬訓練」，步槍兵是青色全息，浮卡正常。
4. 模擬中的設定：
   - 有「模擬說明」與「結束模擬」。
   - 還原、單局匯出入與重置都隱藏，並顯示「模擬不保存中途進度」。
5. 結束模擬後，主選單恢復一般選項。
6. 開一局戰役：
   - 再按 NEW GAME 仍會詢問（沒完成也沒跳過），選跳過後玩家檔案記 `skipped: true`。
   - QUICK GAME 開局（重裝兵、定點清除、回合 2），存下存檔快照。
7. 重新整理後進街機：
   - 選 KILL HOUSE，出現八個職業的選單，選偵察兵。
   - 頂端是「KILL HOUSE · 整備區」，地上有武器與彈藥，並跳出提示。
   - 走 4 步進電梯，頂端變成「KILL HOUSE · 訓練場」，跳出計分開始提示。
8. 結束模擬：
   - CONTINUE 顯示重裝兵第 1 層；進入後是「01 / 定點清除」、回合 002。
   - 戰役存檔與快照逐字相同。
9. **發現並修正**：
   - 本機 dev server 的素材白名單沒有 `killhouse-v1`，圖集回應 404，所以第 3 步看到的其實是退回的程序繪圖。
   - 補上後重啟：圖集回應 200，教學畫面換成新的面板牆與地板。
   - 線上 Pages 的圖集本來就是 200。

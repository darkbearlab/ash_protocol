# 3.199.0 — 初次公開版：職業 500 點、加密提示改成終端機風、itch.io 打包

2026-09-28，Claude。

## 需求

使用者：

- 「把職業解鎖改為 500 點，讓玩家農一下。」
- 「設施紀錄的 decryption in progress 變成終端機風。」
- 「以改完的版本為初次公開的凍結版本。」
- 「最後壓縮打包的版本就可以丟到 itch.io 了對嗎？」

## 做法

- **職業價格**：`CHARACTER_PRICE` 100 → 500。
  - 一局完整撤離的戰役：6 層各 4 點，資料物件各 3 點，頭目 8～12 點，撤離 16 點，大約 70～90 點。所以一個職業大約要成功撤離 6～7 局。
  - 無盡模式的職業屍體照舊免費解鎖。
  - 已經擁有的職業不受影響；設施紀錄維持 100 點。
- **加密提示**：
  - 原本斜蓋的橡皮章換成終端機讀數框，用主選單的等寬字、字距、橘色 `>`，以及開啟畫面讀取條的軌道。
  - 讀數框的內容：小標題、「> DECRYPTION IN PROGRESS」加閃爍方塊游標、來回的掃描條、狀態行。
  - 沿用原本的 sticky 位置，捲動時跟著走。
  - 系統設定減少動態時，游標和掃描條都不動。
  - 這是裝飾用的終端機文字，跟原本的橡皮章一樣不翻譯。
- **itch.io 打包**：新增 `tools/itch-package.mjs` 與 `npm run itch`。
  - 只用 Node 內建的 zlib（deflate、crc32），不加套件。
  - 檔案排序、時間戳固定，同一份程式每次打出來的 zip 完全相同。
  - 會檢查 itch.io 的上限（1000 個檔案、解壓後 500 MB）。
- **Service Worker**：
  - 模擬 itch.io 時發現：安裝離線快取時要抓資料夾網址 `./`，主機不把它回應成 index.html 的話，整個安裝會失敗（沒有錯誤訊息，只是沒有離線快取與快速再開）。
  - 現在這一項單獨抓，失敗也沒關係；頁面載入本來就會退回快取的 index.html。

## 驗證（Claude 自己跑的）

- **截圖**：無頭 Chrome 在手機 390 寬與 320 寬截了設施紀錄頁。讀數框一行排得下（390：內容 257／可用 257 px；320：241／241 px），游標是方塊。
- **zip**：
  - Python `zipfile.testzip()` 沒有錯誤。
  - 437 個檔案，index.html 在根目錄。
  - 解壓後 13.2 MB，壓縮後 11.6 MB。
  - 打包兩次的 SHA-1 相同。
- **模擬 itch.io**：把 zip 解壓到另一個網域的 `/html/123456/` 底下，另開一個網域用 iframe 嵌入。
  - 直接開啟：
    - 開啟畫面結束、版本 3.199.0、主選單七項；
    - localStorage 可以寫；
    - 開新遊戲會打開模擬訓練的提示；
    - 沒有程式錯誤。
  - 修正前，主機不回應資料夾網址時，Service Worker 註冊不起來；修正後，同樣情況下會啟用（activated）。
  - iframe 內主選單正常顯示。
- **測試**：

  - 價格相關的斷言改成 500；

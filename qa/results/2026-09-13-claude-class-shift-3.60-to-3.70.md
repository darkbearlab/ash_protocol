# 各職業在 3.60 → 3.68 → 3.70 的表現變化（機器人量測）

- 日期：2026-09-13
- 方法：`tools/balance.mjs` 的無畫面機器人，每個版本用**自己那版**的機器人與引擎，種子 1～40 配對比較，八個職業各 40 場。
- 三個切點：**3.60.0**（舊地圖）、**3.68.0**（新地圖六階段＋偵察兵補償，轉角前）、**3.70.0**（轉角暴露＋繞路＋執行期批次）。
- 量測前先修掉工具的當機（見文末）。三個版本都套同一行修補，比較才對等。

## 判讀

1. **新地圖讓幾乎所有職業變弱，唯一的例外是被補償過的偵察兵。** 士兵 −0.70、德魯伊 −0.72、重裝兵 −0.48。偵察兵的 +0.58 是含 3.67 延伸點射與 3.68 戰術配給之後的淨值，不代表新地圖對它友善。
2. **重裝兵的勝場崩了：21/40 → 7/40**，而且兩個批次各扣一段，平均層數一路 5.78 → 5.30 → 4.92。它仍然是最強的職業，但受傷最重的也是它。
3. **轉角批次本身對各職業大致中性**（±0.15 以內），唯二的例外是德魯伊與死靈，而那兩個是**卡關消失**造成的假性提升：德魯伊平均回合 79.6 → 226.9、擊殺 12 → 39，它們不是變強，是終於開始真的交戰。3.70 的分流繞路解掉了機器人原本的僵局。
4. **士兵是唯一沒有拿到任何補償的職業**：偵察兵有延伸點射與戰術配給、近戰職業有徒手與追擊、友軍職業有繞路，士兵什麼都沒有，而且 120 場沒有贏過一場。

## 這個量測測不到的東西

- **機器人不會主動探身**。它沒有「貼轉角、開一槍、退回」的行為，所以轉角規則對主動利用掩體者的好處它量不到；使用者手測偵察兵生存率顯著上升，這個工具在結構上會低估那個效果。反向也成立：敵人躲轉角變難打的部分也被抹平。
- **狂戰士與忍者完全測不到**。兩者在所有版本都是第 1 層陣亡、擊殺 0、只活 20～27 回合，機器人拿著近戰武器仍用射擊邏輯決策，從未真正交戰。**這個工具從來沒有有效覆蓋過這兩個職業。**
- 40 場的樣本下，±0.15 層以內視為雜訊。平衡與手機體感仍需人工。

## 順帶修掉的工具缺陷

`tools/balance.mjs` 在 `TERMINAL_AMMO[g.weapon.ammoType].cost` 會當機：手持綁定近戰武器（`ammoType: null`）又走到終端旁時就丟例外。狂戰士種子 27、忍者種子 29 可重現。**3.60.0 的同一行就有，不是 3.70 的回歸**，但它代表那兩個職業的回歸量測長期是斷的。已加上 `offer &&` 守衛。

## 重跑方式

```
node tools/balance.mjs 40 berserker      # 單一職業
```
八職業對照用的驅動腳本是臨時檔，沒有提交；需要時照本檔方法重建即可。

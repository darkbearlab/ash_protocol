# 使用者手修（2026-10-04）

- `units-v2-edit-2026-10-04.png`：使用者在這張 256×192 的圖上清理了 Codex v1 的輪廓。
  - 每格 32×32，沒有間隔；每列四個單位，各是「站姿、屍體」兩格。位置寫在 `layout.json`。
  - 相似的單位排在同一列，方便對照：忠誠方綠色系、加甲與被感染、噴火兵與叛軍、蟲族、其他，最後一列是機械。
- 44 格改了 41 格。巢穴巨獸站姿、母后屍體、幼蟲站姿沒動。
- 使用者補輪廓用的是純黑 `(0,0,0)`。`pack.py` 把它換成外框色 `(12,14,18)`，不然很多格會變成 16 個不透明色，超過上限。兩者差不到 18 個色階，遊戲尺寸下看不出來。
- 自爆機器人是使用者刻意縮小的：從 28×27 縮到 21×17。
- 有幾格的內容寬或高到 29～30，比規格的 28 大，正式圖集裡原本就有同樣大小的格子，所以照留。焚線官的屍體有 2 個像素貼到格子邊緣，無害。
- 重做的方法見 [docs/PIXEL_ART.md](../../../docs/PIXEL_ART.md)「3.223.0」：`python art/units-v2/manual/pack.py`，然後 `python tools/append_units_v2.py`。

# 3.225.0 排名每日為主；代號在送出報告時輸入（Claude，2026-10-14）

使用者看過 GitHub 上的 3.224.0 之後：「daily先藏起來 以ranked daily為主 然後輸入call sign的地方改到遊戲結束提交報告後才輸入」。

## 做了什麼

- **離線每日藏起來**：`src/ranked-ui.js` 的 `OFFLINE_DAILY = false`。新任務選單不顯示「DAILY GAME」，連不上排行榜的畫面也不提供它；`deployDaily` 和文字都還在，改成 `true` 就回來。
- **身分**：打開排名每日時只產生 key（`rankedKey()`），不問名字。`ranked-profile.js` 的身分可以只有 key；`rankedIdentity` 保留 key、丟掉壞掉的代號（代號壞掉不會換掉玩家）。
- **報告**：
  - 局結束時，紀錄照舊打包進佇列，狀態是 `unsent`，不會送出。
  - 結算畫面在戰果數字下方顯示代號欄（填好上次的代號）與「送出報告」。
  - `submitRankedReport(runId, 文字)` 把代號存進那一局和個人紀錄，佇列只送有代號的局。
- **沒送出的報告**：
  - 打開排名每日時先顯示「還有報告沒送出」，可以送出或「稍後再送」。稍後只在這次進選單有效。
  - 榜單畫面顯示「還有 N 局的報告沒送出」和送出鍵。
  - 過了送分期限的照舊作廢（`expired`）。
- 榜單上的「修改代號」與 3.224.0 的開局前代號畫面拿掉了。
- 結算的 RANKED DAILY 區塊從紀錄下方移到戰果數字下方：送出報告是排名局結算的主要動作，手機上第一個畫面就看得到。

## 檢查（Claude 自己跑的）

- `tests/ranked-client.test.mjs` 7 項，改成新流程：
  - 只有 key 的身分在個人紀錄與完整備份來回；壞掉的代號只丟代號。
  - 局結束後不送，等報告；錯的代號、找不到的局會被拒；送出報告後才帶著代號送出。
  - 沒有代號的局過期作廢。
  - 結算畫面的報告欄與送出鍵、送出後欄位消失。
  - 離線每日藏起來。
- 瀏覽器實測（內建瀏覽器，375×812，`?test=1`，本機 `wrangler dev`，中文；只動 `qa-` 鍵）：

  - 打完（測試模式直接設成陣亡）時，佇列裡是沒有代號的那局，沒有送出任何東西。

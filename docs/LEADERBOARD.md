# 每日排行榜（排名每日）

使用者 2026-10-13 的決定。後端在 `workers/ash-scores/`（操作見那裡的 README），共用規則在 `src/ranked-daily.js`，遊戲端（3.224.0）見最後一節。

## 規則

- **一天**：台灣時間 0 點到 24 點（不換夏令時間）。
- **當天的設定（spec）由伺服器決定**：種子與設施派系從伺服器密鑰的 HMAC 算出，明天的猜不到；任務是撤離、難度 普通（`hard`）、**強制真實模式**。第一次有人要當天設定時存進資料庫，之後改程式也不會改到已經開始的那天。
- **條件一致**：排名每日的局用全新存檔的解鎖狀態開局（`createRankedDailyGame`），個人進度不影響地圖；武器目前沒有解鎖制度。
- **職業自選**，榜上顯示用了哪個職業。
- **名字**：三個字（A–Z、0–9），像街機。
- **分榜**：一個榜是（日期、變體、遊戲版本）。現在只有 `standard` 變體；`days.modifiers`、`runs.extra` 留給之後的變體。
- **排名順序**：撤離成功優先，再來樓層深、回合少、擊殺多；完全相同時先送的在前。每個玩家每天每個榜只留最好的一筆。
- **玩家身分**：遊戲第一次上線時在存檔裡產生一把隨機的 `playerKey`，伺服器只存它的雜湊。不需要帳號；清掉存檔就是新玩家。

## 防作弊

| 層級 | 做法 | 擋得住 |
| --- | --- | --- |
| 伺服器定種子 | HMAC(密鑰, 日期) | 預先算好明天的地圖 |
| 出擊票 | 每局一張簽章票（玩家、日期、開局時間），只能送一次 | 重複送同一局、冒用別人 |
| 完整重播 | 伺服器用**該版本、該語言**的遊戲引擎，從依當天設定**重建**的開局把整份操作紀錄重跑一遍：開局雜湊、最後狀態雜湊都要對上，局要打完（撤離或陣亡），成績由重播算出，不採信客戶端回報 | 改數字、改開局、改步驟、拼接紀錄、沒打完的局 |
| 速度下限 | 從拿票到送分的時間至少是 步數 × `MIN_MS_PER_OP`（預設 150 毫秒） | 機器人瞬間刷完 |
| 頻率限制 | 每個玩家每天 30 張票；送分每 30 秒 1 次、每天 20 次；每個 IP（只存當日加鹽雜湊）每分鐘 60 次 | 灌分、洗版 |

**擋不住的**：
- 照規則實際去玩的機器人（例如通關機器人）。
- 用改過的客戶端，在已知種子下反覆試同一步再挑最好結果（工具輔助）。遊戲是決定性的，這類做法沒辦法從紀錄看出來，只能靠速度下限讓它變慢。

**成本**：完整重播一局 6 層約 2,000～2,300 步，Node 和本機 workerd 上都是 8～12 秒 CPU（需要 Workers 付費方案，`wrangler.toml` 的 `cpu_ms`）。

## 資料

- D1 表：`days`、`players`、`tickets`、`runs`（含 gzip 的操作紀錄，30 天後清掉紀錄本體）、`best`、`rate`（`workers/ash-scores/migrations/`）。
- 每天台灣時間 03:30 的排程：清掉舊的頻率計數、沒用掉的舊票、30 天前的操作紀錄。
- 不存原始 IP，不存 `playerKey` 本身。

## 引擎與版本

- 遊戲的文字表在模組載入時就決定語言，戰鬥紀錄文字又在狀態雜湊裡，所以伺服器替每個版本打包中、英兩份引擎，依送分時的語言選一份重播（`workers/ash-scores/scripts/engines.mjs`）。
- `engines.json` 列出要收的版本與它們的 git tag。新版本上線前要加進去並重新部署，否則那一版的送分會被拒（`version`）。
- **排名每日進行中不能切換語言**：切換後紀錄的文字會混兩種語言，重播對不上。遊戲端在排名局中鎖住語言切換。

## 遊戲端（3.224.0）

- **入口**：新任務選單的「RANKED DAILY」（排名每日）與「LEADERBOARD」（榜單）。原本的「DAILY GAME」照舊是離線每日（本機日期種子，不計分）；連不上排行榜時，失敗畫面也提供它。
- **代號**：第一次參加時輸入三個字（英文字母或數字，輸入時自動轉大寫、去掉其他字元），同時產生 `playerKey`，兩者存在個人紀錄的 `ranked`（`src/ranked-profile.js`；完整備份會帶走，備份驗證會擋壞掉的值）。榜單畫面可以改代號；新代號從下一局起使用，已經上榜的成績保留原本的代號（名字跟著那一局存）。
- **出擊票**：打開排名每日時向伺服器拿票與當天設定（`src/ranked-client.js` `fetchTicket`）。沒用掉的票當天留著，退回選單再進來不會多花一張。選職業的畫面列出固定條件（日期、任務、設施、難度、真實模式）與規則；只能選已解鎖的職業。
- **開局**：`startRankedCampaign` 用 `createRankedDailyGame` 開局（管制員照常輪值），操作紀錄的 params 用 `rankedParams`。進行中的局記在 `ash-ranked-run`（票、設定、語言）。
- **不接個人紀錄的解鎖**：排名局的遊戲不綁定個人紀錄（`storage.connectUnlocks` 跳過），所以讀檔接續時，撿到的故事一樣從開局的狀態挑，和伺服器的重播相同。故事、點數等獎勵照常在結算時入帳。
- **語言鎖**：排名局進行中，設定裡的語言按鈕停用並說明原因。
- **送分**：局結束（撤離或陣亡）時，整份操作紀錄 gzip 後放進佇列（`ash-ranked-queue`），再送出；一局完整六層約 30 KB。佇列在局結束、遊戲載入、瀏覽器恢復連線時送；伺服器要求等待（429）時 31 秒後再送。沒網路、伺服器錯誤、伺服器還不認得這個版本時留在佇列，直到送分期限（隔天台灣時間 6 點）。被拒（`rejected`、`too-fast`）或過期的局移出佇列並記下原因；`ticket-used` 表示之前送過了。
- **結算畫面**：紀錄下方多一行「RANKED DAILY」：整理中、等待送出、已上榜第幾名（今天最好的一局時註明）、沒被採用（原因）、過期、紀錄不完整、放棄不計；伺服器回覆後原地更新。「再派一名幹員」在排名局之後是再拿一張票的排名每日。
- **榜單**：今天、昨天；預設這個版本，當天有其他版本的榜時列出來可以切換。自己那一列標亮，不在前 50 名時接在最後；同名的玩家用玩家 ID 前四碼區分。
- **伺服器位址**：正式版 `https://ash-scores.darkbearlab.workers.dev`。測試模式（`?test=1`）預設連本機的 `http://localhost:8787`（`workers/ash-scores` 的 `npm run dev`），`?scores=live` 改連正式伺服器，`?scores=off` 在任何模式關掉排行榜。`sw.js` 不攔截跨網域的請求。
- **itch 版**要重新打包上傳才有排行榜；部署後用 `/v1/health` 在兩個版本各確認一次實際的 Origin。

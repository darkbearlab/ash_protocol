# 手工批准素材

開啟 [線上素材審核頁](https://darkbearlab.github.io/ash_protocol/material-review.html)，或啟動專案後開啟 http://localhost:5173/material-review.html。

1. 每張圖有固定編號：T01–T04 是原地板；W01–W08 是原立面；W09–W16 是原頂板。
2. 勾選允許的「地板／立面／頂板」用途，可跨類別、可一圖多用。全部取消代表停用。每種用途至少留一張。
3. 左上組合示意可選搭配；圖卡可切換原始圖與用途調色。選用目前只存在此頁記憶體，不會修改任務或網站正式設定。
4. 按「下載選用設定」，把 selection.json 交給 Codex，或覆蓋本目錄的 selection.json。
5. 自行整合時執行 `npm run materials`，再 `npm test`、`npm run build`；將設定與生成的 src/material-selection.js 一起提交。build 也會檢查並編譯設定。網頁不會直接寫入本機專案或推 GitHub。

不用改程式也可以直接留言，例如：「地板只留 W03；立面只留 W01、W06；頂板只留 T01。」由 Codex 更新後發布。若只說「批准 W03」，請同時註明用途。

這是**允許清單**：原有主題／房間先用其偏好圖，偏好遭停用時改用該用途清單第一張。勾選某張不保證每個房間都出現；想確定某用途只出現指定圖，就只保留該圖。新增勾選會接在清單最後；JSON 可調整順序。當前設定沿用舊素材作為待審初稿，不代表使用者已批准全部。

來源圖不移動、不改檔名、不重新生成。換用途會套用新用途的色調；原始 PNG 留作比較。所有效果只影響外觀，存檔／命中／掩體不改。

# 聲音方向（2026-09-17 使用者決定，未實作）

## 現況

- 遊戲沒有任何音效檔，也沒有音樂。`src/audio.js` 即時合成開火、命中、落空、擊殺、裝填、治療、移動幾種提示音，用的是正弦波、平滑滑音與濾波雜訊，偏現代合成器的聲音。

## 使用者決定

- 既然是像素加 VHS 風格，聲音要是**紅白機或更早世代**的音質。
- **音樂只在出擊前的選單**（標題、部署、設定、解鎖與紀錄）。戰場裡不放音樂，用環境音。
- 主選單音樂由使用者交給 GPT 製作，規格見 [MENU_MUSIC.md](MENU_MUSIC.md)。

## 音效樣本（第一輪，未接進遊戲）

Claude 寫了一個照紅白機 2A03 音源規則運作的離線合成器，產生 16 個 WAV 樣本，傳到使用者的 Telegram 試聽。檔案與程式都在工作階段暫存區，沒有放進倉庫。

合成器依照的規則：
- 兩個方波（佔空比 12.5／25／50／75%）、32 階三角波、15 位元 LFSR 噪音（NTSC 週期表、一般與短循環兩種模式）。
- 音量 4 位元（0–15）；暫存器只在每秒 60 次的影格邊界改變。
- 2A03 的非線性混音公式；紅白機輸出端的濾波（高通 90 Hz、440 Hz，低通 14 kHz）。
- 每個音效是一串「每影格暫存器狀態」，將來可以直接改成遊戲裡的即時合成，不需要音效檔。

| # | 音效 | 做法 |
| --- | --- | --- |
| 01 | 突擊步槍 A | 噪音爆發，音高逐格降低，加方波低音砰 |
| 02 | 突擊步槍 B | 短循環（金屬感）噪音，再接一般噪音尾巴 |
| 03 | 衝鋒槍 | 三次短噪音爆發，每發加一點方波 |
| 04 | 霰彈槍 | 較長的低音噪音衰減，加三角波下滑重擊 |
| 05 | 精準步槍 | 12.5% 方波高音爆裂下滑，加長噪音迴音尾巴 |
| 06 | 電漿步槍 | 兩個方波錯開一格的高到低下滑，加一點金屬噪音 |
| 07 | 命中 | 噪音點擊加三角波下沉 |
| 08 | 落空 | 25% 方波短促下滑 |
| 09 | 擊殺 | 方波 E4→C4→A3 下行，加三角波 A2 與噪音 |
| 10 | 裝填 | 兩下短循環噪音「喀、嚓」，第二下加一點高音 |
| 11 | 爆炸 | 低音噪音約 0.8 秒階梯衰減，加三角波隆隆聲 |
| 12 | 腳步 | 兩格很輕的低噪音 |
| 13 | 治療 | 方波 C5→E5→G5→C6 上行，第二個方波延遲兩格做回聲 |
| 14 | 升級通訊 | 12.5% 方波快速跳動的資料嗶聲，接 A5→E5 兩音警示 |
| 15 | 選單確認 | B5→E6 兩聲短嗶 |
| 16 | 開門 | 中低噪音加 75% 方波的低音嘎吱 |

全部用同一個增益輸出（最大峰值 −1 dBFS），所以彼此的相對音量就是設計時的比例：腳步與落空最小聲，霰彈槍與精準步槍最大聲。

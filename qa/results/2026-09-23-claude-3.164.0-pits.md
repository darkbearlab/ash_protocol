# 3.164.0 坑洞（天井） — 驗證報告（使用者決定，Claude 實作，2026-09-23）

## 使用者的話

- 「當初在做所謂的陽台地形時，我其實是想做那種其實是鏤空的地形格以及對應的邊緣磚，例如有個巨大的天井，邊緣可能有半掩體可能沒有，機制上是不擋視線的牆那樣。」
- 機制照 Claude 的建議：不能走、視線與射擊穿過、投擲物不能落進去、爆炸越過；欄杆就是矮隔板；繩索可橫越；無人機可懸在上面。
- 畫法：「坑洞邊緣可以看到紅黑警告線圍住邊緣，用之前隨機裝飾物的邏輯但不隨機換位置和更動大小，然後才加上半掩體，所以視覺上半掩體可能遮住水平向的坑洞上緣的警告線，但破壞掉還是會顯現」；「坑洞本身就是直接不畫任何地磚」。
- 生成：「和可以插入的生活模組等相同方式插入，坑洞大小 2x2 到 5x5 應該都可以，端看房間類型和大小。」
- 「如果沒問題就直接做，做完就推上去。」

## 改動

- `src/data.js`：`VOID`（2）與 `seeThrough`；**SAVE 70**。
- `src/pits.js`（新）：`placePit`、`takenTiles`、`pitsOf`、`PIT_TUNING`（每層 50%、2～5、邊長減 3、每側 50% 欄杆）。
- `src/world.js`：`lineOfSight` 讓坑洞透明；`generate()` 在研究員之前挖洞。
- `src/game.js`：`passable` 讓會飛的單位過坑洞；`enemyDropPoint` 從坑洞中央找最近的地板；煙霧只存地板格；存檔的掃描點接受坑洞。
- `src/combat.js`（坑洞不是牆）、`src/walls.js`（牆壁美術不把坑洞當牆）、`src/barriers.js`（欄杆可一邊是坑洞）、`src/retreat.js`（封存樓層接受坑洞）、`src/movement-boundaries.js`（坑洞邊的欄杆仍畫邊界）、`src/pet-growth.js` 與 `src/swarm-fields.js`（雲團只在地板）。
- `src/renderer.js`：坑洞不畫；`pitRim` 在邊緣地板畫紅黑警告線（16×3 的像素條放大，在地板之後、陰影與物件之前）；樓層地圖上的坑洞。
- `sw.js`：快取 `pits.js`。

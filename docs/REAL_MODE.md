# 真實模式、喊話與音效（規格，2026-09-14）

- 狀態：**使用者決定的設計，尚未實作。** 第 6 節有待決定項。
- 依賴：喊話的呼叫點與敵人名稱查詢來自 [ENEMY_AFFIXES.md](ENEMY_AFFIXES.md)。真實模式的顯示過濾、點數加成與音效可以先做。
- 數值：聽得到的半徑、受創喊話門檻交 Codex；泡泡顯示秒數交 Claude。

## 1. 真實模式

- **部署時選擇並鎖定**，整局不能切換（使用者決定）。存於單局存檔，結算畫面與紀錄要標示。
- **協定點數 +10%**（暫定）。使用者說明：加成很少，所以幾乎是純挑戰。
- 瞄準只顯示**名稱與距離**。名稱包含已顯現的詞條片段與「？」。

**隱藏**：

- 目標卡的生命、命中率、掩體與所有狀態標籤（轉角暴露、壓制、近射加成等）。
- 地圖上的敵人血條與壓制層數點。
- 戰鬥紀錄裡的傷害數字。紀錄文字目前由規則層直接寫入數字，需要改成可依模式輸出，或改用結構化資料讓介面決定怎麼顯示（交 Codex）。
- 其他任何顯示命中率的地方。

**保留**：

- 所有預告：蓄勢「!」、狙擊手倒數、延遲轟炸與擲彈兵的標記。原則是**不隱藏意圖**。
- 喊話（第 2 節）。
- 玩家自己的生命、彈藥、掩護等資訊。

## 2. 喊話（核心規則，兩種模式都有）

使用者決定把喊話扶正為核心規則，標準模式也有；真實模式照樣保留。

### 2.1 架構

1. **行為樹發出**：在狀態轉換、開始預告、跨過受傷門檻時呼叫喊話，只帶台詞種類，不帶文字。
2. **規則層接住**：
   - 檢查台詞種類是否在白名單。
   - 判斷玩家看得到、只聽得到（半徑內），或兩者皆否。
   - 看不到時只附**大致位置**（所在房間或方向），不附精確座標。
   - 同步寫一行戰鬥紀錄。
   - 結果放進當下這一步的演出事件，與射擊演出同一機制。

   **藏什麼本身是規則**，所以由規則層決定，兩種模式共用。
3. **介面顯示**：依種類查台詞文字（每種敵人可以有數句變化，用固定規則挑選，不動戰鬥亂數），處理優先度、節流與讀秒。

喊話是一次性的演出事件，不改存檔格式；戰鬥紀錄本來就會存檔。

### 2.2 白名單

只允許粗略狀態，**永遠不含數字**。

| 類別 | 例子 | 優先度 |
| --- | --- | --- |
| 危險預告 | 投彈、衝上去、瞄準中 | 最高 |
| 詞條顯現 | 各詞條的專屬台詞 | 最高 |
| 戰術狀態 | 推進、找掩護、堅守射擊、換彈、包抄 | 中 |
| 受創 | 中彈、傷勢加重、重傷求援、被壓制、動不了 | 中 |
| 感知 | 發現目標、追丟了、搜索中 | 低 |

受創喊話是真實模式下的**粗略血量回饋**（使用者同意）。門檻交 Codex，例如第一次受傷、生命一半以下、四分之一以下。

### 2.3 看得到與看不到

- **看得到**：泡泡在單位上方，清楚，顯示時間較長。
- **看不到、但在聽得到的半徑內**：泡泡半透明，顯示時間較短，**標在大致位置**（房間範圍或畫面邊緣的方向）。不標精確格子，以免變成隔牆透視，削弱轉角規則與士兵預警的價值。
- **半徑外**：不顯示，也不寫戰鬥紀錄（交 Codex 確認）。

### 2.4 節流與讀秒

- 每個單位同時只有一個泡泡；同屏數量有上限；同類台詞有冷卻；重複的合併顯示（例如「追擊 ×3」）。
- **讀秒消失**（使用者堅持，讓畫面在一小段時間後恢復乾淨）。
  - 計時從**演出播到那一步**才開始，不是從規則結算時開始。
  - 渲染時間在分頁切到背景時會暫停，泡泡不會在玩家沒看時過期。
  - 預設：一般台詞 2.5 秒；危險預告與詞條顯現 4 秒（Claude 可調）。
- 所有喊話同步寫進戰鬥紀錄，錯過了可以回頭看。

### 2.5 誰會喊

- **敵人**：會。
- **有行動樹的友軍**（召喚物、寵物、機體）：可以喊，**台詞內容擱置**。
- **玩家**：不喊。

## 3. 音效

- 擊中、落空、擊殺使用可以分辨的音效，沿用 `audio.js` 的播放機制。
- 受傷外觀、命中特效等其他演出：使用者判斷成本過高，**不做**。

## 4. 不變條件

1. 真實模式在部署後不能切換，存讀檔後維持。
2. 真實模式下，目標卡、地圖與戰鬥紀錄不出現生命、命中率、壓制層數與傷害數字。
3. 預告標記在兩種模式都顯示。
4. 看不到的單位，喊話不包含精確座標。
5. 喊話不消耗戰鬥亂數，不改變存檔格式。
6. 協定點數加成只在真實模式的局結算時套用一次。

## 5. 分工與順序

- **Codex**：真實模式的存檔欄位與點數加成、戰鬥紀錄依模式輸出、喊話接收（白名單、看得到與聽得到的判斷、大致位置、紀錄同步）、受創門檻與喊話呼叫點。
- **Claude**：部署畫面的模式選擇、所有顯示過濾、泡泡繪製、節流與讀秒、台詞表、音效。
- **順序**：真實模式的顯示過濾、點數加成與音效可以先做。喊話的呼叫點依賴 ENEMY_AFFIXES.md 的行為樹骨架；也可以先接在現有的決策點上，之後隨行為樹一起搬移（交 Codex 判斷）。

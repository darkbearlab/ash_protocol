# 3.80.1 小菁英屍體外框變暗 QA（Claude，2026-09-14）

使用者試玩標準叛軍後要求：小菁英的金框在變成屍體時要跟著變暗。

## 修改

- `ELITE_VISUAL` 新增 `corpseOutline: '#8f7438'`，亮度約為活著時 `#f2c45a` 的六成。
- `renderer.corpse()` 畫小菁英屍體外框時改用這個顏色。外框快取本來就以顏色區分，活著與屍體各自一張。
- 倒下時 140 毫秒的位移，外框照舊跟著屍體移動。

## 自動測試

- `npm test` 775/775 通過；build 通過。
- 繪製紀錄：一般敵人與一般屍體 2529 次畫布呼叫，雜湊 `1f415fe7fcda0dac`，與 3.79.1、3.80.0 相同。

## 瀏覽器檢查

環境：Chromium 內嵌瀏覽器，本機伺服器，`?test=1`。

**測試場景**：叛軍設施，在玩家旁邊放兩具步槍兵屍體（一具是小菁英、一具不是），以及一隻活著的小菁英突擊兵。

像素計數：每格周圍 38×38 CSS 像素，顏色容差約 ±16。

| 位置 | 亮金 `#f2c45a` | 暗金 `#8f7438` |
| --- | --- | --- |
| 小菁英步槍兵屍體 | 0 | 106 |
| 一般步槍兵屍體（同一張屍體圖） | 0 | 0 |
| 活著的小菁英突擊兵 | 117 | 0 |

- 兩具屍體用同一張圖，所以暗金像素來自外框，不是屍體圖本身。
- 瞄準小菁英突擊兵時，目標卡標籤行為「叛軍 · 精英 · 生物」。這是 3.80.0 報告裡「沒有實際瞄準」的那一項，現在補驗了叛軍的派系標籤。

## 過程中的量測陷阱

- **服務工作者快取**：第一次量測時，頁面由服務工作者從快取載入舊的 `renderer.js`（資源傳輸量 0）。取消註冊並清除本機開發快取後重新載入，才拿到新程式。
- **截圖座標**：截圖座標是縮放過的（視窗寬度 ÷ 800 ≈ 1.216）。第一次沒有換算，量到的其實是活著的小菁英。換算成 CSS 像素後才得到上表。

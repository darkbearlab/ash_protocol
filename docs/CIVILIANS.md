## 1. 使用者構想與決定

**構想**：

- 忠誠者設施裡多一種不戰鬥的「敵人」：科學家、平民等。
- 他們會往玩家的反方向跑。
- 語音是投降、勸玩家不要傷害大家之類的內容；一部分背景故事從他們身上堆砌出來。

**決定（2026-09-14）**：

1. **傷害平民**：打傷或殺死平民沒有懲罰，也不給經驗、不算擊殺。
2. **逃跑**：一直逃。永遠往遠離玩家的方向移動，不會停下，也不會投降。
3. **尖叫**：看到玩家時會尖叫，讓附近的守衛警戒。

**追加決定（2026-09-14，第二次）**：

4. **尖叫有冷卻**：不是一生一次。冷卻結束後再看到玩家，會再尖叫。
5. **不佔威脅額度**：平民不能擠掉戰鬥敵人的名額，但每層都要有數名平民。
6. **通用化**：放置平民的機制不綁忠誠者，之後其他派系也能用。現有架構放不下時，Codex 可以提出新機制。
7. **擊殺研究員永遠沒有代價**（2026-09-15，確定不再改）。
   - 理由：玩家是被洗腦的複製人戰士，任務是肅清設施。
   - 之後如果要討論代價，對象是「沒有擊殺、仍然活著的非友軍」。

**Claude 提醒**：殺平民沒有代價，平民又會叫醒守衛，玩家可能會養成先殺平民的習慣。這只是試玩時要觀察的點，不是要改決定。

## 4. 規則（Codex）

### 4.1 身分：仍是敵人，但排除戰鬥系統

平民放在 `g.enemies` 裡：可以被瞄準、射擊、被爆炸波及，存檔沿用敵人欄位。帶 `noncombatant` 標籤時，以下系統要排除：

- **攻擊**：不攻擊、不蓄勢、不投擲、不呼叫增援。
- **詞條與小菁英**：不抽詞條，也不會成為小菁英。
- **經驗與統計**：擊殺經驗為 0，不計入擊殺數與結算。
- **任務**：不會被選為獵殺目標，不影響頭目與撤離條件。
- **自動鎖定**：自動選目標時跳過平民；手動切換目標仍然選得到。
- **敵人數上限**：不佔 `RUNTIME_TUNING.liveLimit`（使用者決定，見第 4.5 節）。
- **威脅提示**：控制器的「射程內威脅」清單排除平民。
- **控制效果**：壓制、失能、震撼照常生效；失能期間不能移動。

### 4.2 行為：一直逃

- **發現玩家之前**：和一般敵人一樣待機。
- **發現玩家之後**（沿用每回合的視線判定，進入警戒）：
  - 每次行動移動一格，選相鄰可通行格裡「離玩家最遠」的一格。距離算法（路徑或曼哈頓）由 Codex 決定；平手時用固定順序，不新增亂數。
  - 沒有更遠的格就原地不動（被逼到角落），下回合繼續嘗試。
  - 永遠不解除逃跑；看不到玩家時，改為遠離最後已知位置。
- **速度**：與一般敵人相同。
- **門**：沿用一般敵人的移動規則；能不能開門逃跑由 Codex 依現況決定，並寫進實作紀錄。

### 4.3 尖叫

- **時機**：平民看得到玩家、而且尖叫冷卻為 0 時尖叫。第一次發現玩家的那一刻一定符合。
- **冷卻**：
  - 尖叫後進入冷卻，暫定 5 回合。要有冷卻是使用者決定，長度之後由 Claude 調。
  - 3.127.2（使用者決定）：改成**真的 5 回合**。冷卻在回合的最後才倒數（在最後一次看見之後），所以不論在你移動時、敵人回合或回合結尾尖叫，下一次都在 5 回合後；原本在你移動時尖叫的只隔 4 回合。讀檔時不會觸發新的尖叫。
  - 冷卻存在敵人身上，需要保存欄位，例如 `screamCooldown`（0 以上的整數）。
  - 建議把數值集中成 `CIVILIAN_TUNING`，例如 `{screamCooldown:5, screamRadius:8, fleeCalloutEvery:3}`。
- **效果**：
  - 同樓層、距離平民 8 格內（與喊話的「聽到」半徑相同）、活著的戰鬥單位進入警戒，`lastKnown` 設為玩家當下的位置。
  - 每次尖叫都重新套用，所以守衛會追著玩家最新的位置。
- **判定**：以距離判定，不需要視線，因為是聲音。是否要求路徑距離由 Codex 決定。
- **紀錄**：尖叫是規則效果，寫一行戰鬥紀錄，例如「研究員尖叫，附近的守衛警戒了。」這和喊話泡泡不同：喊話是演出，不寫紀錄。

### 4.4 喊話事件

- **新 cue `scream`**：危險類、高優先，每次尖叫時發出。平民不發 `spotted`。
- **新 cue `flee`**：逃跑中每隔幾回合發一次（建議 3 回合），UI 冷卻會再節流。這是故事台詞的主要出口。
- **沿用**：`hit`、`wounded`、`critical`、`suppressed`、`pinned`。
- **牆後**：牆後只聽得到的喊話目前只帶派系。平民的事件請多帶 `voice:'civilian'`，否則會被當成忠誠者士兵的聲線。仍然不帶兵種、身分或精確位置。

### 4.5 出生：不佔威脅額度的通用機制（Codex 研究並提案）

**需求**（使用者決定）：

- **數量**：每層都有數名平民，暫定每層 3–5 名，之後由 Claude 調。
- **不佔威脅額度**：
  - 不放進戰鬥出生池，不計入 `allocateThreat` 的預算，也不佔房間的戰鬥容量。
  - 不計入每層敵人上限，也不佔 `RUNTIME_TUNING.liveLimit` 與 `expendableLimit`。
  - 同一個種子加入平民前後，戰鬥敵人的種類、數量與位置都要完全相同。
- **通用**：
  - 不綁忠誠者，也不綁平民這張卡。任何派系都能用資料宣告自己的非戰鬥人口。
  - 例如派系欄位 `noncombatants: { roster: [['civilian', 1]], perFloor: { min: 3, max: 5 } }`；欄位名稱與形狀由 Codex 決定。
- **不出現**在撤退增援、偵察兵與頭目生成裡。

**Codex 要研究並寫進報告**：

- **生成階段**：建議在戰鬥敵人配置完成之後另外放置。
- **亂數**：建議用獨立雜湊，不消耗地圖、戰鬥與詞條亂數，legacy 與叛軍的基準才會不變。
- **位置**：起點房之外、可到達的格子；不堵走廊與出口，不佔任務目標的位置。
- **平民放在哪個清單**：
  - 留在 `g.enemies`：沿用第 4.1 節的標籤排除。
  - 改成獨立的非戰鬥單位清單：瞄準、射擊、爆炸波及、存檔與喊話的效果，要和第 4.1 節描述的一樣。
  - 兩種都可以，但要在報告說明理由。
- **空間不夠時**：少放幾名即可，不能讓生成失敗，也不能擠掉戰鬥敵人。
- **擴充方式**：以後其他派系要用時，只需要改哪些資料。

### 4.6 存檔與驗收

- **存檔**：新增的狀態欄位（例如 `screamCooldown`）要加入保存驗證；存檔版本由 Codex 決定。
- **測試**：
  - 平民不攻擊。
  - 發現玩家後，每次行動與玩家的距離不減少（無路可走時除外）。
  - 看到玩家而且冷卻為 0 時尖叫，讓 8 格內的戰鬥單位警戒；冷卻中不尖叫；冷卻結束後再看到玩家，會再尖叫。
  - 殺死平民不給經驗、不計擊殺。
  - 不會有詞條、不會成為小菁英、不會被選為任務目標、不會被自動鎖定。
  - 忠誠者每層都有第 4.5 節範圍內的平民；同一個種子加入平民前後，戰鬥敵人的種類、數量與位置完全相同。
  - 用一個測試派系宣告非戰鬥人口，證明機制不綁忠誠者。
  - 存讀檔後保留尖叫冷卻與逃跑狀態。
- **基準**：現行混合與叛軍的行為一致性基準不變。

### 4.7 精靈圖（Codex，使用者要求）

- 站姿與倒地各一張，沿用現有敵人精靈的製程與規格。
- 外觀：設施研究員或職員，淺色工作服，**手上沒有武器**，一眼能和士兵分開。
- 現有圖格的順序與內容不變，一般敵人的畫面要和現在逐項相同。

## 7. 實作現況（3.82.0，Codex）

### 通用非戰鬥人口

- `src/civilians.js` 提供 `addNoncombatants(map,seed,floor,faction)`。正式 `generate()` 完成戰鬥人口、物資、普通詞條與小菁英之後才呼叫，不動 `allocateThreat`、房間戰鬥容量或原出生亂數。
- 派系宣告採本規格的形狀：`noncombatants:{roster:[['civilian',1]],perFloor:{min:3,max:5}}`。目前僅 loyalist 設定。其他派系只須新增此資料；不同職員則新增帶 `noncombatant` 標籤、`behavior:'civilian'` 的兵種卡，放進此 roster。不要加到戰鬥池、斥候、頭目或增援表。
- 亂數使用 `birthRandom(seed,floor,'population','noncombatants-v1')` 的獨立雜湊流。先抽總數，候選格以獨立亂數排序，再按 roster 權重抽兵種；不取用地圖、戰鬥或詞條亂數。
- 起點房外，只放可達的房間內格；避開所有敵人／物資／物件／危害／槽位（包含任務目標預留）、連接口及其相鄰格，距出口與起點大於 2。四鄰必須在同房、為地板、無占用，且中間沒有關閉的門或隔板，避免卡住內部狹口。不放走廊或附屬區。候選不足即少放，完全沒有候選則 0，不替換戰鬥敵人、不讓生成失敗。
- 保留在 `g.enemies`，以 `isNoncombatant(e)` 查詢標籤。這樣手動瞄準、射擊、爆炸、屍體、喊話、樓層封存與備份都可沿用既有管線；不需建立第二套可攻擊物件清單。
- `enemyRoom`／`expendableRoom`、任務目標、自動鎖定、友軍自動選敵與死靈召喚池排除非戰鬥人員。手動目標仍保留，射程內威脅提示亦排除。詞條與小菁英出生直接跳過。傷害可記入既有傷害統計；死亡不計擊殺、不給經驗、廢料、物資或協定獎勵，也沒有懲罰。
- 實際放入人口才加世代12 `{version:12,recipeId:'noncombatants-v12',base:原10或11描述}`。legacy／rebel 未啟用這個人口層，保持原生成結果；舊樓層不補生。

### 逃跑、尖叫與冷卻

- 行為樹 `civilian` 在普通攻擊／詞條分支之前消耗行動，永不攻擊或蓄勢。一般速度。
- 初次看到玩家時進入 `alert`，永遠不清除。可見時以玩家當下位置為準；失去視線後遠離 `lastKnown`。距離採**曼哈頓**，只選嚴格更遠的可通行空格；平手依上、右、下、左，沒有候選就原地再等下一次。不用路徑距離、不新增亂數。
- **可以開門**：往較遠的候選格遇到關門，該行動只開門，下次才移動。不能穿牆、破牆；矮隔板可依既有規則翻越並帶翻越破綻。
- `CIVILIAN_TUNING={screamCooldown:5,screamRadius:8,fleeCalloutEvery:3}`。尖叫初見即觸發；每個付費回合開始，活著平民的冷卻減 1，包含失能期間；免費行動不減。冷卻歸零且再看見玩家可再尖叫。
- 尖叫範圍以平民為中心的**曼哈頓距離 8**，**不要求視線或可行路徑**。本層活著的戰鬥敵人警戒，lastKnown 更新為玩家當下位置；不叫醒其他平民或友軍。每次尖叫寫一行規則紀錄，不耗亂數。
- 失能禁止行動與尖叫；壓制禁止移動，但不禁止尖叫。`flee` 於逃跑行動且 `g.turn % 3 === 0` 時發出；被困仍算逃跑中，不需新增計時欄位。

# 3.186.0 — 結算畫面附上操作紀錄

2026-09-26，Claude。規格：docs/TEXT_PLAY.md「反方向：正式版記錄，文字版重現」。

## 需求

使用者用偵察兵打贏蟲族，衝鋒槍不再缺彈；機器人重現不出這個手感，所以想把自己的對局匯出給 Claude 重現：「直接扶正這個功能到遊戲勝利或敗北的結算畫面，包含模式、種子和操作 log」。

## 做法

- `src/run-log.js`（新）：每一局的操作紀錄（沿用 3.124.0 的 `src/replay.js` 格式），另外帶 `runId`、`params`（種子、任務、職業、難度、真實模式、設施）、`partial`（從第幾回合開始，完整則 false）與結束後的 `result`。
  - `trackRun(game)`：控制器的 `update()` 在「不是模擬、不是重播、這局進行中」時呼叫；同一局重複呼叫不做事。讀檔後若存下的紀錄屬於同一局、同一版本、最後一步的狀態雜湊等於讀進來的存檔，就接著記，否則從當下重開一份。
  - `persistRunLog(game)`：每次存檔後寫入（`persist()` 與 `pagehide`），並補上尚未記下的鎖定目標；這局結束時寫入結果。
  - 寫入走 `storage.js` 新的 `readExtra`／`writeExtra`／`removeExtra`：失敗不改 `storage.available`，所以不會跳「未存檔」；寫不進去就刪掉紀錄、這局不再嘗試，存檔照常。
- 結算畫面：「紀錄：任務 · 難度（· 真實模式）· 設施 · 種子 · 版本」一行，下面「下載操作紀錄」；紀錄不是從頭開始時註明從第幾回合開始，沒有紀錄時寫「這一局沒有操作紀錄」。
- 設定 → 一般：「下載操作紀錄」（進行中的這局，或上一局直到下一局開始記錄）。
- 測試模式的「從現在開始記錄」「下載操作紀錄」拿掉，改成自動；「播放操作紀錄」保留，可以直接播下載的檔案。
- `src/replay.js`：重播的遊戲改接一份「這局開始時的解鎖」副本，無盡模式回收識別資料的步驟也能重現；副本不寫回玩家檔案。
- 中英文字 6 條（`controller.result.record`、`recordReal`、`controller.runLog.*`）；`.result-record` 小字樣式；`sw.js` 加入新模組。

## 人工驗證（交給使用者）

1. 新開一局玩幾步，重新整理後繼續玩幾步，然後打完或放棄。
2. 結算畫面：有「紀錄：…」一行與「下載操作紀錄」；下載的檔案可以直接傳給 Claude。
3. 設定 → 一般也能下載同一份紀錄。

## 限制

- 重現要用紀錄上的版本；一局跨了遊戲更新時，更新後的部分會是另一份從當下開始的紀錄（結算畫面會寫從第幾回合開始）。
- 這個版本以前已經在進行中的局，只會記錄更新之後的部分。

# 異界來源與增援備忘

2026-09-10 使用者要求先記錄，本批不實作、不加入正式關鍵字 catalog。

- 未來可加入「地獄」「亞空間」「異空間」等非現實世界來源／性質關鍵字，確切名稱、ID 與效果待定。它們不必取代生物／機械，也不應暗中綁定大型、速度或掩體能力；仍沿用可掛多條獨立規則的方向。
- 增援至少有兩種出場方式：傳送、從地底鑽出。地獄來源也屬於傳送，但演出要與一般科技傳送不同。
- 後續設計可把「怎麼進場」與「出場視覺」分開，例如 arrival=teleport 加不同外觀；emerge 是地底出場。這是管線建議，不是已實作資料格式。
- 預告多久、被占格怎麼辦、是否能中斷、何時可行動、增援的掉落／點數都尚未定案。未新增敵人、額外增援波次或異界地圖；現有頭目低血召喚維持原規則。

目前 3.20 的房間主題接口只替換外觀，不能藉換素材取得上述關鍵字或增援能力。

# 3.51.0 局內升級「裝甲回收」（Claude）

- 日期：2026-09-12
- 作者：Claude（Opus 5）
- 基底：main `2999e03`（3.50.2）。
- 使用者決定（2026-09-12）：
  - 有裝甲的敵人掉落機率顯著上升，一般敵人也有低機率掉落。
  - 「護甲板還有剩時額外減傷」是重裝兵專屬，但先擱置，只留文件。
  - 兩項都是三階。

## 一、既有鉤子的檢查結果

| 需求 | 現況 |
| --- | --- |
| 敵人掉落護甲板 | 有，但很窄：`game.js` 死亡結算只讓「裝甲 > 0」的敵人以 20% 掉 10 點。機率與數量寫死。 |
| 百分比減傷 | 有唯一通道：`traits.js` 的 `reduceDirectDamage`，目前只認得重裝防護 ×0.75。 |
| 職業限定升級 | 已經支援：`eligiblePerks` 讀 `characters` 與 `eligible(g)`，程式註解本來就寫是留給未來內容。 |
| 存檔 | 兩項都能從已存檔的 `player.perks` 次數推導，不必新增欄位，也不必升版。 |
| 缺的 | `applyPerk` 遇到未知效果會丟錯，要加一個分支；掉落那行要改成讀次數。 |

## 二、實作（裝甲回收 `plating`）

- 判定集中在 `perks.js` 的 `plateDrop(player, armoured)`，常數 `PLATE_DROP`：
  - 有裝甲的敵人：20% + 15%×階 → 滿階 65%，一次 10 點。
  - 其他敵人：6%×階 → 滿階 18%，一次 5 點。
- **機率 0 就不擲骰**：沒選這項的局，擊殺一般敵人消耗的亂數與改版前完全相同，後續結果不會偏移。
- 選到當下立刻 +10 護甲板，並用 `plateCapacity` 夾住。
- 升級項目附加在 PERKS 清單尾端；效果由 `player.perks.plating` 推導，存檔格式不變（save v30）。
- 增援的敵人照舊不掉任何東西。

## 三、擱置的那項

護甲板減傷（重裝兵專屬）只寫進 docs/PERKS.md，包含：要用的三個現成鉤子、受傷計算順序中該插入的位置，以及和重裝防護、裝甲板吸收疊起來的平衡試算（滿階時 100 點攻擊實際掉 25 血、耗 24 片，沒有這項則掉 32 血、耗 32 片）。

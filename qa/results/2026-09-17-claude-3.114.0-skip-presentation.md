# 3.114.0 追加：演出中按指令直接執行 — 驗證報告（Claude，2026-09-17）

使用者要求：「如果使用者在演出中就按下下一個指令了 能讓他跳過演出直接執行下一回合的功能？且可以在設定開關」，並決定**不升版號，放在 3.114.0 裡**。

## 行為

- 上一回合的動畫還沒播完就按下一個指令，動畫立刻結束到最後狀態，接著執行這個指令。
- **預設開啟**。設定「顯示」段新增「演出中按指令直接執行：開啟／關閉」，關閉時回到原本的行為（動畫播完前的輸入全部忽略）。設定存在本機（`ash-skip-presentation`），和移動邊界白線一樣。
- 會觸發跳過的輸入：操作區與畫面上所有按鈕、戰場滑動與點擊、長按開背包分頁、鍵盤的指令鍵（方向鍵／WASD、空白、R、H、E、F、句點、Q、Tab、G、B、Escape）。
- **不會跳過的情況**：
  - 這一回合讓任務結束（陣亡、撤離、放棄）：一定播完，死亡動畫不會被結算畫面蓋掉。播放時按鈕照舊停用。
  - 鍵盤按住不放的連發：避免按住方向鍵就閉著眼睛一路走好幾回合。
  - 原本的 120 毫秒防重複輸入鎖仍然有效。
- 跳過時，剩下的演出事件一次送完：喊話泡泡與最後的畫面狀態都保留，只是省略中間的動畫格與這段演出的音效。如果跳過後立刻跳出升級或房間提示，這次按鍵只算跳過，不會再去開別的選單。

## 實作

- `src/presentation.js`：`Playback.finish()` 依序送出剩下的事件並標記 `skipping`，送完設為完成；已完成時再呼叫不做任何事。
- `src/controller.js`：`skipPlayback()` 是唯一的入口（條件：有演出、設定開啟、`game.status==='playing'`、未被直向提示擋住、已進入戰場、超過防重複鎖）；`endPlayback()` 由正常播完與跳過共用。演出事件回呼在 `skipping` 時只更新畫面狀態與特效，不逐次重畫介面、不播音效。操作區按鈕在可以跳過的演出期間不再停用。

## 瀏覽器實測（375×812，`?test=1`）

瀏覽器面板在背景時畫面不逐格更新，演出不會自己播完，所以用截圖推進畫格。場景：玩家生命 5000，三名步槍兵在 4 格外持續開火。

| 檢查 | 結果 |
| --- | --- |
| 開啟時，演出播放中按等待 | 訊息列從舊內容換成上一回合的戰報，回合 012 → 013，第二個指令立刻執行 |
| 跳過後的下一段演出 | 照常播放：子彈飛行、MISS／−10、生命 4860 → 4850，最後與存檔一致 |
| 連發（`repeat:true`）的按鍵 | 回合不變 |
| 關閉時 | 演出播放中按鍵全部被忽略、按鈕停用（原本行為） |
| 設定開關 | 切換後重新整理仍保留；說明文字在手機寬度正常換行 |
| 本回合陣亡 | 播放中等待鈕停用；再按按鈕與 F 都不會提前出現結算；推進畫格後依序出現中彈、紅色低血量畫面，最後才是「UNIT EXPENDED」結算 |

測陣亡時的結算標題顯示「高威脅個體已消耗。」，是測試場景造成的：換掉整層敵人後，肅清帳本裡原本的敵人編號都找不到，被當成全部清除。正常遊戲不會這樣，與本功能無關。

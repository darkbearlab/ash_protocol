## 給教學重做的備註（這版沒動）

- **出口規則不一致**：擊殺屋要走進電梯格才離開（`src/killhouse.js` 的 `descend`，站在旁邊按鈕會被拒絕：`killhouse.stepIn`）；戰役則是站在電梯旁按電梯鈕（`manual.exit`）。agent 建議教學改教按鈕，但那樣在擊殺屋是錯的；重做時要先決定兩邊統一成哪一種。
- **其他建議**：
  - 教學全亮，但戰役第 1 層就有停電房，可以考慮放一間暗房並教手電筒與螢光棒。
  - 士兵的預警技能沒教。
  - 六張卡關掉後無法重看。
  - 教學中陣亡會從第 1 區重來。
  - 擊殺屋不記錄操作紀錄。
- **不建議塞進教學的**：壓制、詞條、終端、彈種、生存規則。改在第一局簡報或作戰指南最上面放「第一局要知道的 5 件事」。

## 還要使用者決定的（agent 盤點的其餘項目）

- **凍結方式**：目前沒有 git tag，推上 main 就換掉線上版，操作紀錄只能同版重播。可以打 tag 並在試玩期間暫停推 main，或把凍結版放到 itch.io 或另一個路徑。
- **試玩說明頁**（網址、要測什麼、回報時附版本與紀錄、進度只存在瀏覽器、已知問題、暴力與血腥提示和血光開關）：凍結方式決定後由 Claude 擬稿。
- **真機測試**：iPhone Safari、Android Chrome 各跑一遍，包括教學、撤離光束、結算下載紀錄、生存、切換英文。
- **試玩者能玩的職業**：新手要幾局才解鎖第一個（agent 推算 4～7 局）。可以試玩版全開或降價。
- **Google Fonts**：改成自帶字型檔，需要下載字型檔並加進專案（OFL 授權允許）。
- **效能與打包（可以之後）**：音樂先抓 FLAC（8.1 MB，m4a 只要 2.6 MB）；觸控裝置預設 60 FPS；service worker 每次都重新向伺服器確認；manifest 只有 SVG 圖示（iOS 不支援）。
- **已知**：英文還沒校對；故事草稿在公開 repo 的歷史紀錄裡（知道就好）。

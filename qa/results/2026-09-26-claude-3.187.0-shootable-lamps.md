# 3.187.0 — 可以打爆的鹵素燈

2026-09-26，Claude。規格：docs/LIGHTING.md「可以打爆的鹵素燈」。

## 需求

使用者：「那我們把可摧毀的光源做起來吧，鹵素燈我方可以瞄準。」光照決策頁 C6 的答案是「可以，第二步再做：打爆後那一片變黑，敵我都能打」。

## 做法

- 資料：每盞壁燈多一個 `hp`（1 亮、0 碎），生成時為 1；`validLamps` 要求四個欄位、`hp` 只能是 0 或 1。SAVE 76，舊存檔（含往返保存的樓層）的燈補 1。
- 規則（`src/game.js`、`src/lighting.js`）：
  - `Game.targeted` 的候選加上燈，所以鎖定、開火、射程與射線檢查都沿用可破壞物的流程；
  - `hitTarget` 打中燈就 `breakLamp`：`hp` 歸零、推一個撞擊效果、寫紀錄、重算視野；
  - `fireChance`：可破壞物的算法再 −25（`LIGHT_TUNING.lampHitPenalty`）；
  - `explode`：波及範圍內、照爆炸的視線規則沒被擋的燈一起碎；
  - 光源計算跳過碎掉的燈，快取的鍵改看亮著的燈數。
- 畫面與操作：`renderer.lampPoint` 算燈畫在牆邊的位置，`hitLamp` 用它做點選（在門的點選之後、其他目標之前），鎖定框縮小畫在燈上；碎掉的燈畫成暗色燈座。目標卡：名稱「鹵素燈」、「耐久 1 / 1」。
- 文字：戰鬥紀錄一句、目標卡名稱、作戰指南「光線」補一句（中英）。

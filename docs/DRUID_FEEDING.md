# 德魯伊餵養（3.72.0 規則實作，2026-09-13）

- 狀態：**3.72.0 規則層完成；Claude 接餵食介面，數值待人工遊玩調整。**
- 取代：3.37「倒地、回收與自行歸隊」、收納機制、收納中用醫療包，以及德魯伊的兩個職業升級。
- 數值：**各階門檻、冷卻長度、每次行動吃多少燃料、重生生命等數字一律由 Codex 決定**，本規格只定規則形狀（使用者指示）。

## 1. 目的

使用者不希望德魯伊成為「一直讓寵物衝出去送死」的職業，而是**養寵物**：把資源投資進寵物，讓它長成不同的樣子。投資讓玩家自然會保護寵物，不需要用規則禁止魯莽。

兩層經濟：

- **成長資源**（玩家生命、裝甲板、武器、投擲物）比較稀缺，決定寵物長成什麼。
- **彈藥**是全遊戲最常見的資源，作為**燃料**，決定寵物能做多少事。

## 2. 移除的舊規則

- **收納**整個移除：沒有 `packed` 狀態、沒有收納中回血（`PET_REGEN`）、沒有收納中用醫療包、沒有回滿自動歸隊。醫療包治療寵物改由餵食介面進行，見 4.1。
- **倒地與回收**移除：沒有 `down` 狀態、沒有屍體、沒有「相鄰花一回合回收」。
- 伴生指揮的**位置指令與召回保留**。

## 3. 胃與燃料

- 寵物有**獨立的胃**。只有玩家在**技能分頁**主動餵的彈藥才會進胃。
- **每次餵食花 1 回合，而且寵物要與玩家相鄰**（使用者決定）。適用於所有餵食：彈藥、成長資源與醫療包。
- **寵物永遠不會自己從玩家的備彈拿**。這和追隨無人機在身邊自動換彈不同，是刻意的區別（使用者決定）。
- **不限彈種**，五種備彈都能餵。德魯伊起始帶步槍與霰彈槍，所以手槍彈、能量彈、重彈對他來說是純飼料，不與自己的槍競爭。
- **燃料換算沿用終端價格**，不另立一套經濟：10 廢料換手槍彈 36／步槍彈 24／霰彈 8，12 廢料換能量彈 12／重彈 3。以「1 份燃料 = 1 廢料的價值」為基準，實際份量由 Codex 定。
- **只有主動能力會吃燃料**：射擊（砲台線）與排出（排出線）。體質、裝甲是被動，**不吃燃料**。
- 胃空了，寵物只剩咬擊。

這條規則自然分出兩種玩法：只餵生命與裝甲板的寵物是**不需要彈藥的肉盾**；餵武器與投擲物的寵物**火力強但需要持續餵彈藥**。

## 4. 四條成長線（各三階，門檻由 Codex 定）

餵成長資源也在**技能分頁**逐項操作，每種資源各自累積該線的進度。

| 線 | 餵什麼 | 一階 | 二階 | 三階 |
| --- | --- | --- | --- | --- |
| 體質 | 玩家生命 | 生命上限提高 | 戰鬥中會回血 | 每層一次，致命傷害改為留 1 HP |
| 裝甲 | 裝甲板 | 裝甲提高 | 移除 `no_cover`，能利用掩體 | 直接傷害再減一段 |
| 砲台 | 武器 | 解鎖射擊，每發吃燃料 | 射程與傷害提高 | 一次行動兩發 |
| 排出 | 投擲物 | 每隔 N 個付費回合、胃裡燃料足夠時，排出一顆餵最多的那種投擲物 | 間隔縮短 | 可以指定排出種類 |

補充規則：

- **成長上限**：每條線最高三階。這和無盡模式等級 20 封頂的理念一致，寵物不能成為不受封頂限制的第二條成長線。
- **食物解鎖能力，時間產出資源**：排出線的產量只由時間與燃料決定，**與餵了多少投擲物無關**，避免「吃 X 吐 Y」的換錢迴圈。
- **排出的投擲物落在寵物腳下**，玩家走過去拾取。投擲物共用攜帶上限，滿了就留在地上。終端不賣投擲物，這條線是全遊戲唯一能製造投擲物的方法，數值應保守。
- **武器的飼料價值等於拆解的回收價值**，可以餵的武器等於可以拆解的武器（綁定武器不可）。避免「先拆再餵」與「直接餵」之間出現套利。
- **餵生命要有下限**，不能把玩家餵到瀕死。下限由 Codex 定。
- 砲台線的射擊方式可以之後跟著「吃最多的武器類型」變化（例如霰彈槍吃得多就變成近距散射），**第一版不做**。

## 4.1 治療：餵醫療包

- 餵食介面也可以選**醫療包**：**純治療寵物，不累積任何一條線的進度**（使用者決定）。
- 移除收納之後，這是體質二階以前寵物唯一的回血途徑。
- 治療量由 Codex 定。舊的收納中醫療包是回 50% 最大生命（`PET_MEDKIT_FRACTION`），可作參考。
- **餵生命只累積體質進度，不治療寵物。**

## 5. 死亡與重生

- 寵物生命歸零：**直接消失，沒有屍體。**
- 進入重生倒數，以**付費回合**計算，免費操作不倒數（與其他冷卻一致）。
- 倒數結束，**在德魯伊身邊重生**，在德魯伊當下所在的樓層。
- **重生時只有部分生命**（使用者決定，比例由 Codex 定），避免「讓重傷的寵物死掉」成為最佳策略。
- **重生之前不能餵任何東西**（使用者決定）。
- **成長階數保留**，記在羈絆上，不在身體上。
- **胃清空**（燃料灑了）。這是 Claude 的建議，死亡有代價但不會讓投資歸零。

## 6. 德魯伊三選一（暫定）

| 升級 | 狀態 | 效果 |
| --- | --- | --- |
| 飽食 | 取代「獵獸體質」 | 胃容量提高、每次行動吃的燃料減少。支援砲台與排出流派。 |
| 飢餓 | 取代「獵獸利爪」 | 胃空時咬擊傷害大幅提高。支援不餵彈藥的肉盾流派，讓「燃料用完」成為可利用的狀態。 |
| 共生 | 保留 | 寵物擊殺時玩家回血。 |

飽食與飢餓方向相反是刻意的：抽到哪個，就把玩家推向哪個流派。

## 7. 與既有系統的互動

- **共生不排除雜兵**（使用者決定）。`game.js:463` 目前對所有寵物擊殺都回血，包含 3.69 的雜兵與巢穴幼蟲，**維持現狀，請不要「修正」它**。理由是雜兵本來就被設計成讓職業延續增益的跳板。巢穴產出有上限，所以回血也有上限。
  - 例外：**若之後新增任何「擊殺回燃料」的能力，一定要排除雜兵**，否則巢穴會變成燃料農場。
- **換層一律同行**（使用者決定）：寵物換層時不受同行距離限制，永遠跟著德魯伊到新樓層。這是寵物對共用友軍換層規則的例外，工程師機體與召喚物照舊。重生倒數中的寵物也跟著德魯伊換層。
- **轉角規則**：寵物射擊沿用友軍的遠程路徑，`allies.js:193` 對非近戰攻擊呼叫 `recordExposure`，射擊會照常暴露探身方向。
- **存檔**：需要新增每條線的進度與階數、胃的內容、重生倒數；移除 `packed`／`down`。`allies.js:307` 的狀態驗證要一起改。**舊存檔遷移**：收納中的寵物改為在德魯伊身邊活動；倒地的寵物改為進入重生倒數。
- **職業介紹與說明文字**：`characters.js` 的德魯伊描述（「獵獸倒地後相鄰回收，收納中自行回血並歸隊」）、技能說明、說明頁都要改寫。
- **既有測試**：`tests/allies.test.mjs` 的倒地回收與收納回血測試（約 54、63 行）會被移除或改寫。

## 8. 不變條件（每條都應有測試）

1. 寵物不會從玩家備彈自動拿取彈藥；胃只因技能分頁的餵食而增加。
2. 重生倒數中無法餵任何資源。
3. 死亡後成長階數保留、胃清空，重生位置在德魯伊身邊且在德魯伊當下的樓層。
4. 體質與裝甲的效果不消耗燃料；射擊與排出消耗燃料。
5. 胃空時寵物只能咬擊。
6. 排出的產量只與時間、燃料有關，與餵了多少投擲物無關。
7. 每條線最高三階，超過門檻的餵食不再提升階數。
8. 武器飼料價值等於拆解價值；不可拆解的武器不可餵。
9. 餵生命不能讓玩家低於下限。
10. 共生對雜兵擊殺照常回血。
11. 舊存檔的收納／倒地寵物正確遷移，不遺失、不重複。
12. 每次餵食花 1 回合；寵物不相鄰時拒絕，且不耗回合。
13. 餵醫療包只治療，不增加任何線的進度；餵生命只增加體質進度，不治療。
14. 重生時的生命低於最大生命。
15. 換層時寵物一律同行，不論距離；倒數中的寵物也在德魯伊的新樓層重生。

## 9. 使用者決定紀錄（2026-09-13，原待決定三項）

1. 餵食花 1 回合，而且要與寵物相鄰。
2. 重生只有部分生命。治療改由餵食介面選醫療包，純治療、不累積進度。Claude 原本建議的「餵生命同時治療寵物」不採用。

### 模組與入口

`src/pet-growth.js` 集中成長、燃料、報價、重生、存檔驗證；所有暫定數值在 `PET_FEEDING_TUNING`。
`engine.js` 匯出 `petFeedingState`、`petFeedQuote` 供介面使用。沿用既有 action → 演出 → 存檔流程，不直接改 player 或 allies。

```js
const state = petFeedingState(game); // 無羈絆時 null
const quote = petFeedQuote(game, {optionId:'ammo:pistol'});
game.action('feedPet', {optionId:'ammo:pistol'}); // 每次 1 付費回合
game.action('feedPet', {optionId:'weapon', weaponSlot:1});
game.action('setPetOutput', {kind:'smoke'}); // 三階才可，免費
```

- `optionId`：`ammo:pistol/rifle/shell/energy/ordnance`（擇一）、`life`、`plates`、`weapon`、`grenade:frag/smoke/emp/stun`（擇一）、`medkit`。
- `state`：`actorId/status/hp/maxHp`；`fuel:{stored,capacity,scale,displayValue}`；`growth:{vitality,armor,turret,extrusion}`，各線含 `progress/rank/nextThreshold/capped`；`reviveRemaining`；`output:{kind,remaining,ready,fuelCost,selectableKinds}`；`options` 是所有資源與持有武器的報價。
- 每份報價包含 `action`（可直接傳給 feedPet）、`allowed/reason`、`resource/amount/cost/gain/overflow`；武器另有 `weaponSlot`，成長資源有 `line`。燃料 gain 以整數 ticks 表示，生命／板／武器／投擲物各自採該線單位。介面不要重算價格或合法性。
- `output.ready` 表示計時歸零；仍需足夠燃料才會產出。不要把它顯示成已經產出。選種類不是餵食，不扣資源。
- 相鄰採上下左右、不可隔關門／隔板。允許技能未預備時餵食，但玩家必須擁有伴生技能。失能、重生、待選升級或無法相鄰時拒絕。
- 成功動作提交前會再次驗證：快速敵人若改變局勢，回合仍付出，但飼料不扣。追擊代幣不能支付餵食。
- 保留 `commandPet`／伴生技能的免費召回；已移除寵物回收／收納路徑。`PET_REGEN`、`PET_MEDKIT_FRACTION` 暫留相容匯出，只供舊 controller 文字引用，沒有規則用途；Claude 更新該處後可移除。
- **待接 UI**：controller 技能頁目前尚未辨識 `reforming/arriving`，舊說明頁仍含收納文字；請改由上述 state 顯示，並刪除舊收納說明。角色／技能資料與升級名稱已更新。

### 初版數值與時間語意

| 項目 | 值 |
| --- | --- |
| 胃 | 30 燃料；1 燃料 = 72 ticks = 1 廢料購買力 |
| 每次餵彈 | 最多手槍18／步槍12／霰彈4／能量6／重彈1；資源或胃不足時縮小份量 |
| 體質累積門檻 | 20／50／90 生命；每次5；餵後至少 max(25, ceil(玩家最大生命 ×40%)) |
| 體質效果 | 最大生命90→150；戰鬥回血3；每個實際樓層一次致命留1HP |
| 裝甲門檻／效果 | 10／25／50 板；每次最多5；裝甲1→4、可用掩體、直接傷害再減20% |
| 砲台門檻 | 20／60／120 拆解價值；武器值20＋改裝階數×10 |
| 砲台效果 | 射程5／傷害14–18；二階7／20–24；三階兩發；命中修正−22；每發2燃料 |
| 排出門檻 | 1／3／6 顆投擲物 |
| 排出效果 | 每12付費回合；二階8；三階可選種類；每次12燃料 |
| 重生 | 死亡後8個完整付費回合；回復最大生命25%（向下取整） |
| 醫療包 | 治療最大生命50%（向上取整），走 healActor |
| 飽食／飢餓 | 每階胃+10、兩種消耗−10%；胃完全空時咬擊傷害每階+25% |

燃料使用整數避免浮點漂移；折扣後消耗向上取整。終端價格由 `TERMINAL_AMMO` 讀取；若日後調到無法以72整除的價格，需一併調整燃料刻度與遷移，不能直接引入小數存檔。
生命與裝甲是被動，不吃燃料；餵生命提高上限也不補當前 HP。武器彈匣退回玩家備彈，溢出走原有落地規則，不進胃、不給廢料。最後一份超過門檻的量以 overflow 揭露，滿三階後拒絕再餵。

射擊優先順序：相鄰可咬目標優先咬；否則有燃料的砲台射擊；否則依原有 combatStep 接近敵人。每發各自扣燃料、追蹤原目標、檢查射線；承諾後失去射線仍扣燃料。第一發擊殺不再發第二發。射擊照常 recordExposure，延用轉角／分流規則。此版沒有依飼料武器類別換射法。

戰鬥回血：最近2回合內自己攻擊或遭受攻擊（未命中也算）時，付費回合末回血；環境地板傷害不算交戰。裝甲三階額外減傷不套地板危害，但套直接爆炸。
排出倒數只在身體活動時推進；未準備技能也照常運作。燃料不足停在0，不累積欠帳；補燃料後當輪末可產一顆。投擲物落在寵物腳下，玩家滿載不影響產出。死亡重設排出時鐘；沒有收納與死亡中餵食。
死亡當輪不扣重生倒數。倒數歸零無相鄰空位就等待，騰出空位後再歸隊；出現當輪不行動。換層保留成長／胃／倒數，重新在玩家身邊放置；機體與召喚物規則不變。

# ASH PROTOCOL / 灰燼協定

直向手機瀏覽器的回合制戰術射擊 roguelike。目前版本見 `src/version.js`（3.114.0），遊玩：https://darkbearlab.github.io/ash_protocol/

文件導覽：現況手冊 [docs/HANDOFF.md](docs/HANDOFF.md)、規格索引 [docs/DESIGN.md](docs/DESIGN.md)、每版變更 [docs/CHANGELOG.md](docs/CHANGELOG.md)、驗收紙條 [給驗證者的紙條.md](給驗證者的紙條.md)。3.36 之後的版本摘要只記在 CHANGELOG；下方各版段落是 3.35 以前的歷史說明。

## 開始

需要 Node.js 20+，不用安裝套件。

```sh
npm start
```

電腦開啟 http://localhost:5173 。手機與電腦連上同一 Wi-Fi 後，輸入 `http://電腦的區域網路IP:5173`，必要時允許伺服器的防火牆提示。手機的 localhost 指向手機自己。

## 背景

兩個跨星系企業的戰爭已經結束。戰敗方散落各處、仍在運作的設施稱為「火種」；玩家是被勝方俘獲並重新洗腦的複製人幹員，只有編號，被投入一座座火種設施執行清除。詳見 [docs/STORY.md](docs/STORY.md)。

## 內容

- **八職業**：士兵、偵察兵、工程師起始可選；重裝兵、德魯伊、死靈法師、狂戰士、忍者以協定點數或無盡深處回收遺體解鎖。各有技能、被動與職業專屬升級。
- **任務**：六層核心撤離、指定殲滅、機密回收、三層原路回收、無盡深入；另有 Kill house 模擬訓練與街機。
- **派系設施**：忠誠者、叛軍、蟲族與早期混合設施；隱藏詞條、小菁英、平民與研究員、蟲潮與疊層中毒、叛軍詭雷箱、敵方浮游彈藥。
- **武器**：十三種（含拾獲近戰）、六種詞條、五種備彈、改裝與拆解；精準步槍要先瞄準、榴彈發射器瞄地板、霰彈槍錐形射擊。
- **投擲物與道具**：破片、煙霧、EMP、震撼；醫療包、修復噴劑、腎上腺素、夜視鏡（佩戴件）、摺疊掩體。
- **友軍**：工程師工坊生產的機體與藍圖、德魯伊的獵獸、死靈法師的召喚物。
- **戰場**：門與矮隔板、角度掩體與牆角探身、暗房與夜視／紅外線、可破壞家具與油桶、補給箱與器材箱、補給終端。
- **進度**：肅清績效評估、協定點數（陣亡保留）、職業與設施紀錄解鎖。

## 操作

| 操作 | 觸控 / 鍵盤 |
| --- | --- |
| 移動 | 方向鈕 / 點相鄰格 / WASD 或方向鍵 |
| 鎖定 | 點敵人、掩體或油桶；目標鈕 / Tab 輪換敵人 |
| 開火 | 開火 / Space（拿榴彈發射器時進入選點，右下確認） |
| 裝填 | 裝填 / R |
| 投擲物 | 投擲物鈕 / G → 點落點或方向鈕移動 → 右下確認；再按一次取消 |
| 道具 | 道具鈕 / H；佩戴件生效中會變灰，點一下打開背包 |
| 技能 | 技能鈕 |
| 背包 | 背包鈕 / B；長按投擲物、道具或技能鈕直接開對應分頁 |
| 瞄準顯示 | 瞄準鈕 / Q，不耗回合 |
| 等待 | 等待鈕 / F 或句點：本回合直接傷害減半、被射擊命中 −15，下次射擊命中 +15 |
| 互動 | 右下互動鍵 / E：開門、開箱、終端、電梯、回收、確認投擲 |
| 設定 | 右上選單 / Escape |

操作區有三種排版，設定裡的「操作區排版」「方向鍵大小」可以切換與調整，選格狀排版時還能用「編輯按鈕位置」自訂每顆按鈕。查看背包、瞄準和圖鑑不耗回合；換裝、改裝、拆解、補給、使用消耗品與穿脫佩戴件耗一回合。

## 存檔和離線

每步存於本機瀏覽器。舊版存檔會備份並自動遷移；既有樓層不重置。設定可匯出 JSON，換瀏覽器後再匯入。死亡會結束該任務。協定點數存在目前瀏覽器的全局紀錄；設定的「完整備份／還原備份」包含錢包、解鎖、歷史與目前任務。原本的「匯出任務」仍僅包含單局。還原會以快照替換，並先保存可下載的還原前備份。

Service Worker 需 HTTPS 或 localhost；區域網路 HTTP 可遊玩、存檔，但不能安裝離線快取。首次完整載入後核心資產可離線；Google Fonts 失聯時使用備用字型。

`npm test` 涵蓋地圖生成、戰鬥與道具規則、存檔相容與機器人遊玩；`qa/enemy-data-identity.mjs` 比對地圖生成、任務快照與機器人結果的基準線，規則改動必須逐筆證明差異來源。瀏覽器開發測試用 `http://localhost:5173/?test=1`，與正式存檔隔離。

部署到靜態網站根目錄時，包含 index.html、兩份 CSS、src/、assets/、manifest.webmanifest、sw.js。此版為獨立小型遊戲，沒有使用 Jupiter Hell 的程式碼或素材，也未達原作的完整製作規模。

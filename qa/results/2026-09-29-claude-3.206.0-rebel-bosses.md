## 需求

- 使用者（2026-09-29，docs/BOSSES.md 第 3 節）：叛軍「使用火焰發射器，覆蓋玩家位置，可以遮擋視線和壓迫走位」。
  - **第 3 層縱火者**：有裝甲、不怕火（燃燒地板與火的傷害），站在自己的煙裡（燃燒的格子是淡煙，雙方射擊減半）。三招各預告一回合再出手：
    - **火牆**：在你身後或側邊畫 3～5 格的線，下一回合整條點燃，切斷退路。
    - **圍困**：你周圍 2 格一圈留有缺口的火（至少一個你真的走得出去的缺口，絕不把你困死），下一回合整圈點燃。
    - **過熱**：噴 3 次後散熱 2 回合，不能噴火、裝甲降到 0，是反擊的時機，要顯示清楚。
    - 招式之間照常攻擊（主工作階段建議：像火焰兵詞條一樣朝你噴錐形，每次也算進過熱）。
    - 頭目的火和整層 30 格上限的關係要決定並寫下來；上限絕不能讓預告過的招式沒有任何戰報就失敗。
  - **第 6 層**（使用者：「沒抽到除名幹員時，叛軍版是忠誠方第 6 層的變體：一樣會標定，但壓制改成噴火」）：標定和標定官、火線官完全相同（躲不掉）；架槍改成架起噴火：同樣的 1 回合預告與扇形畫法，之後噴火的回合數同火線官的掃射（點燃地板、燒傷扇形裡的單位），再收起 2 回合（可以移動，不開火、不標定、不架設）。機體像核心守衛（280 血、裝甲 7），半血叫無人機不預告（不生人類），輪流的邏輯同火線官。中英名字照 GLOSSARY.md 提、標暫定。3.207.0 的除名幹員抽選這一版不做，但目錄要讓 3.207.0 能換掉第 6 層頭目。
  - 台詞：審稿頁定稿的 intro.rebel3、intro.rebel6（白鷺、鷦鷯，表情照審稿頁），照 intro.loyal3／loyal6 的方式接。
  - 預告的畫面：火牆的線、圍困的圈（要看得出缺口）、過熱狀態、噴火扇形（火線官扇形的畫法，火的顏色）。
- 同一版追加（使用者，主工作階段轉達）：母后的卵囊預告（3.205.0 是程式畫的會跳動的粉紅囊）改用蟲潮出口的地洞圖（`drawNestSprite(...,'burrow',...)`），程式畫的只在地洞圖讀不到時當備用；目標卡文字不變；規則與存檔不變。

## 做法

- 新模組 `src/rebel-bosses.js`（`sw.js` 與 `index.html` 的模組數 177），數字在 `REBEL_BOSS_TUNING`（使用者試玩後再調）：
  - `arsonist`：`reach` 6、`heat` 3、`vent` 2；火牆 `offset` 1、`half` 2、`min` 3；圍困 `radius` 2、`gaps` 2、`min` 4。
  - `burn`：`halfAngle` 30、`range` 5、`sweeps` 3、`packUp` 2、`damage` 12、`flank` 15。
- 卡片（`src/data.js`）：`arsonist` 以封鎖官為底（180 血、裝甲 5、射程改成火焰發射器的 5、`flameOnly` 沒有槍），`burnline` 以核心守衛為底（280 血、裝甲 7）；兩張都 `fireproof`、只有壓制抗性（沒有紅外線）、`barredAffixes:['fast','infrared']`，`specials` 分別是 `['wall','ring']` 與 `['mark','burn']`，`intro` 是 `introRebel3`、`introRebel6`。叛軍的 `bosses` 改成 `{3:'arsonist',6:'burnline'}`（`src/faction-catalog.js`），混合派系照舊。協定點數、工程師藍圖、有效距離（焚線官同核心守衛）照忠誠方的做法補上。SAVE 84。
- 不怕火：`src/enemy-data.js` 的 `fireproof`；環境回合對它們不扣燃燒地板與固定的火；`src/hazard-paths.js` 的 `hazardTile` 對它們不把火算危險格；`src/fire.js` 把噴火打單位的部分抽成 `burnUnits`（噴火與頭目的點燃共用），不怕火的單位跳過，你的噴火噴到時記「某某不怕火」。
- 縱火者：
  - `wallPlan`：先試你背後（離它最遠的方向；它在斜角時兩個方向都算，雜湊排序），再試兩側，不試朝它的方向；線的中間在你旁邊 1 格，沿火的邊（`edgeBlocks(...,'blast')`）往兩側各延伸最多 2 格，至少 3 格。
  - `ringTiles`／`ringPlan`：從你出發走 2 步、中間不過牆、門、隔板的地板（離你步數距離剛好 2）；缺口依「和它到你的線有多垂直」排序（一樣時雜湊），避開有人站的格子，先留 2 個；還會困住你就照同樣的順序再多開；點燃的少於 4 格就不用這招。
  - `sealsOff`：點燃的格子與頭目身體當牆（用 `reachable(...,{keys:true})`，上鎖的門算開著），你現在走得到的每一格都要仍走得到；已經在燒的火當牆、不當牆各查一次。
  - 行為樹：`rebelBossAction` 放在行為樹最上面（火焰兵標記之後、鉤舌與衝鋒之前，在命令、生存模式、誘餌、危險格之前），先處理預告過的火牆與圍困（`igniteFire`：頭目還在原位才點；逐格再查一次，不能燒或會封死你的格子不點，戰報寫格數）、預告過的噴火（`sprayCone`，同火焰兵）、焚線官架起的噴火器（`burnTurn`）。縱火者自己的回合是行為樹的 `special`（`arsonistTurn`：過熱中只走路並扣散熱；站在酸液或蒸氣上先走下來；熱度 0 或 2 時先試火牆與圍困，輪流；否則夠得到就預告噴火；都不行就往前走）。
  - 過熱：`heatUp` 在每次用火之後加一；到 3 設 `overheat` 為 2、清掉 `heat`；`vent` 在它自己的回合結束時扣一，扣完恢復。`src/enemy-affixes.js` 的 `enemyArmor` 在 `overheat` 時回 0，目標卡的裝甲欄同時消失。
  - 誘餌與地雷：`src/field-gear.js` 的 `decoyAct` 與 `canShootMines` 排除只會噴火的卡片，以及身上有 `fireIntent` 或 `burn` 的頭目。
- 焚線官：標定借 `src/loyalist-bosses.js`（匯出 `canPaint`、`paintMark`、`landedNow`；`validLoyalistBosses` 只檢查會架機槍的卡片的 `special`，其他卡片的 `special` 由 `validRebelBosses` 檢查）。`burn` 的 set／sweep／pack 同 `gun`；錐形 `burnCells` 是 `flameCells` 帶頭目的數字；`sweepBurn` 用 `burnUnits` 燒扇形裡每個單位（12 照深度放大），再點燃扇形；`burnFlank` 加在 `combat.js` 的 `gunFlankBonus` 與 `Game.meleeAccuracy`；收起用 enemy-behavior 的 `packWalk`。在自己的噴火裡倒下（燒到身旁的自爆機器人）就停，不再設收起。
- 頭目的火與 30 格：`src/fire.js` 的 `ignite(g,cells,{makeRoom:true})` 回傳 `{lit,displaced}`；滿 30 格時熄掉最舊的（燒最久、一樣時照閱讀順序），不熄這次要點的。火牆、圍困、縱火者的噴火與焚線官的噴火都用；戰報記熄了幾格。
- 自己人：`Game.hurt` 的 `ownKind` 從「有鉤舌的頭目」擴大到所有敵方頭目，頭目的火燒到自己人不算你的擊殺、經驗、廢料與傷害統計，戰報寫「某某傷到某某」。
- 打斷：`src/enemy-intents.js` 的 `interruptEnemyIntent` 呼叫 `interruptRebelBoss`：死亡、失能、被移開取消火牆與圍困（噴火標記照火焰兵的規則一起取消）、架起中的噴火器；噴火中改收起；看不到你與壓制不取消。`src/hazard-paths.js` 的 `COMMITTED` 加上 `fireIntent`。
- 畫面（`src/renderer.js`、`src/enemy-visuals.js` 的 `REBEL_FIRE_VISUAL`）：火牆與圍困是會閃的燃料橘格子，火牆格子中間一條線；圍困的缺口是綠色虛線框加指向圈外的箭頭（`fireIntent.center` 是你當時的位置）；焚線官的扇形照火線官的畫法換成火的顏色，旁邊是剩下的次數；過熱是頭上的淡色蒸氣、藍色虛線圈與剩下的散熱回合，還沒過熱時頭上 3 個小點；過熱那一刻噴一圈蒸氣，預告時頭目閃一下；點燃時每格播火舌（`flame` 效果）。目標卡新增「火牆預告」「圍困預告」「過熱：裝甲 0 · N 回合」「熱度 N/3」「架起火焰發射器：不能移動」「收起火焰發射器 N 回合」（扇形外 +15 沿用）。文字版工具（`tools/text-play.mjs`）把火牆、圍困與噴火扇形標 `!`，預告行與敵人表也列出來。
- 母后的卵囊：`eggSac` 先畫預告格，再用 `drawNestSprite(...,'burrow','active')` 畫蟲潮出口的洞，讀不到才畫原本的囊。
- 文字：中英兩張表各新增 26 條（出場台詞 4、名字與說明 4、戰報 12、目標卡 6）；`COMMS_LINES`／`COMMS_EXPRESSIONS` 的 `introRebel3`（白鷺 concerned、鷦鷯 alarmed）、`introRebel6`（白鷺 serious、鷦鷯 worried）。台詞從審稿頁的 final.json 逐字複製，測試逐字比對。GLOSSARY.md 加兩個名字（敵人 27）。

| 項目 | 決定 |
| --- | --- |
| 焚線官的名字 | 焚線官／Burnline Officer（暫定）：照火線官／Gunline Officer 造字；候選「叛變火線官／Rogue Gunline Officer」 |
| 機體 | 同忠誠方：封鎖官與核心守衛的血量、裝甲、機械、掉落、協定點數與藍圖；沒有紅外線；不抽快速與紅外線 |
| 焚線官也不怕火 | 架著時站在扇形頂點不能動、旁邊整片在燒，不怕火才不會燒到自己 |
| 縱火者的一般攻擊 | 照火焰兵：標出錐形一回合再噴，絕不開槍；每次算一次用火 |
| 輪流 | 火牆與圍困只在熱度 0 或 2 時開始，兩招輪流；所以兩招之間一定夾一次噴火或散熱 |
| 火牆的位置 | 你背後緊貼的一排（離它最遠的方向），放不下再放側邊，絕不放在朝它的那一邊 |
| 圍困 | 步數距離 2 的一圈、中間不過邊；2 個缺口，選和「它到你」垂直的兩側（出口在側邊，避開它噴火的方向）；有人站的不當缺口；少於 4 格不用 |
| 點燃 | 站在正在點燃的格子上的單位受一次噴火的傷害（同火焰兵），之後照一般燃燒地板 |
| 不困死你 | 點燃的格子當牆（審查後加一次不算頭目身體的檢查，見下面「獨立審查」），另外頭目身體也當牆，你走得到的每一格仍走得到；已燒的火算與不算各查一次；上鎖的門算開著（保險室、出口、任務目標不會被隔開）；點燃時逐格再查 |
| 火牆、圍困的格子 | 不放在起點、出口與有物件的格子上；需要看得到你才開始，點燃不需要 |
| 焚線官的錐形 | 火焰發射器的 5 格、半角 30°，不是機槍的 90°、7 格（火不看掩體、不擲命中，太大就走不出去） |
| 火打誰 | 錐形或點燃的格子上每一個單位，敵我不分；燒到自己人不算你的 |
| 30 格上限 | 頭目的火一定點得起來：熄掉最舊的讓位、戰報記一行；你的與火焰兵的火照舊 |
| 燃燒地板的擊殺 | 照舊不分是誰點的（同火焰兵的火） |
| 散熱與 EMP | 散熱算它自己的回合，被 EMP 失能的回合不算，EMP 會延長反擊時機 |
| 點燃中倒下 | 火照樣點（一瞬間），但不算用火；焚線官在自己的噴火裡倒下就不再收起 |
| 3.207.0 | 抽選在樓層要頭目的地方（`factionBoss` 的呼叫端）做，`bosses` 表維持派系自己的頭目 |

# 3.199.1 — 每日種子不再因語言而不同

2026-09-28，Claude。

## 需求

- 寫 itch.io 商品頁時，使用者想寫「每日遊戲，每位玩家同一個種子」。查程式時發現：
  - `src/daily.js` 用日期和 `t('daily.title')` 算種子；
  - 那段文字中英文不同，所以兩種語言的玩家同一天拿到不同的種子。
- 使用者：「語言不同種子不同的問題要修」。

## 做法

- `DAILY_PHRASE` 改成固定常數 `'ASH PROTOCOL // 灰燼協定 // DAILY OPERATION'`，也就是中文表原本的文字。
  - 中文玩家的種子不變，英文玩家改成跟中文相同。
  - 已經開始的每日遊戲存有自己的種子，不受影響。
- `daily.title` 只用來算種子、畫面上不顯示，所以從 `src/text-zh-tw.js` 與 `src/text-en.js` 移除，也拿掉 `daily.js` 對 i18n 的依賴。
- 新增 `tests/daily.test.mjs`：
  - 語言在模組載入時決定，所以中文和英文各開一個程序；
  - 算 2026-09-28 的種子與每日任務，兩者必須相同。

- **測試與檢查**：
  - 完整 `npm test`：1381 通過、0 失敗；

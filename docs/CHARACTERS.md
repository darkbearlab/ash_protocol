`src/actor-stats.js` 集中四個獨立修正：`rangedAccuracy`、`rangedEvasion`、`meleeAccuracy`、`meleeEvasion`。角色定義 `combat` 加上敵我單位可選 `combatModifiers`，同一欄相加。後者為後續裝備／狀態調整鉤子，缺欄 0，存檔僅接受已知欄位且整數 −100 至 100；未知欄位、陣列、null、字串、非整數拒絕。自然敵人本批不附額外數值。

射擊原公式增加「攻擊者射擊命中 − 目標射擊迴避」，其他掩體、明暗、移動、體型、等待及被動各自結算，最後仍限 10–99%。玩家攻擊物件也加天生命中，物件沒有迴避。近戰為「武器基礎命中（動力拳 99，敵近戰 97）＋近戰命中 − 近戰迴避」，限 10–99%，不混用射擊欄位。預估、卡片、實際擲骰使用同一數值；近戰其他傷害／掩體規則維持原狀。武器比較表也含當前角色命中修正。

`src/characters.js` 是角色資料入口；`new Game(seed, unlockedWeapons, carrying, character='soldier', portrait)` 在建立新局時選擇，非法 ID 拒絕。角色不是複合被動：各規則分別以 `{id, source:'character:soldier'}` 等來源掛上 `player.traits`。取得另一個獨立來源可疊加掛載，但同名規則不疊數值。

## 架槍 braced

射手相對於射擊目標受到牆角或箱體保護時，射擊命中 **+12 個百分點**。使用 `protectingCover(attacker,target)` 判斷，是射手的掩體；不是看目標有沒有掩體。背對敵人的牆不提供此加成。無法利用掩體會取消架槍條件，敵人的掩體懲罰仍正常扣除。

敵我共用判定。射擊可破壞物也可取得架槍加成；最終命中率仍限制 10–99%。浮卡在生效時標示「架槍 +12」。

## 著彈修正 correction

同一敵人連續回合受到自己的射擊時，後續射擊每次命中 **+8，最高 +24**。第一次 0、第二次 +8、第三次 +16、第四次起 +24。

- 以一次耗回合射擊為單位，SMG 同回合兩發使用同一加成，只累積一次；未命中仍累積。
- 因先手逃離視線／射程或死亡而向最後位置落空的承諾射擊，也算一次。仍耗彈，不能改打別人。
- 連續射擊另一敵人從 0 重算；移動、等待、一般裝填、耗回合換槍、醫療／投擲、交換等非射擊動作，以及換層會中斷。射擊箱體／油桶不累積並中斷舊目標。
- 查看或切換鎖定目標、免費預備、免費換手槍、快速裝填不耗回合，所以不會中斷；無效操作同樣不影響。
- 增益依原敵人 ID 判斷，不因轉身、目標移動或攻擊未命中清除。NPC 若被獨立賦予此規則，一般遠程攻擊也依相同連續回合判斷；移動、蓄勢等未射擊行動中斷。自然敵人這批沒有新增此被動。

`actor.fireChain={targetId,turn,count}` 保存上次射擊的回合與累積（1–3）。目前行動的全部子彈完成後才記錄，因此快照不會讓第二發提早多加一層。浮卡的「修正 +N」是當前可用加成，下一回合若敵人先改變掩體／距離／可見性，仍以實際局勢結算。

## 側身 sidestep

角色移動相對攻擊者的射線主要是橫向時，該次被射擊命中率額外 **−20**。暴露時，側身懲罰取 `max(20,42−移動懲罰)`，使移動＋側身至少 **−42 個百分點**，與牆角相當；此被動本身一般為 97−22−20＝55%，敏捷為 97−35−20＝42%；3.25 Recon 天生射擊迴避另減 10，分別為 45%／32%。追獵／笨拙降低移動懲罰時由側身補足此下限。有掩體時側身固定額外 −20，仍加上移動與掩體。敵我共用，不提供掩體減傷，近戰沿用原命中規則。

保存實際一格移動向量 `actor.moveDelta=[dx,dy]`。令射線向量為「移動後角色 → 攻擊者」，橫向分量絕對值大於縱向分量才生效；精確 45 度不算，前進或後退也不算。每個攻擊者各自判斷，因此一個方向的側身無法保證躲避交叉火力。

移動狀態維持至自己的下一次耗回合行動；免費操作不清除。快速敵人在玩家行動前使用上次移動狀態，之後的敵人使用這次行動狀態。舊存檔不知道上次方向時設為 [0,0]，不猜測免費給側身。戰場狀態「側身 N」表示目前射程內可見射手有 N 名受側身懲罰，不代表不會受傷。

## 快速裝填 quick_reload

武器 **ammoType === 'pistol'** 時，裝填成本為 0。與免費換手槍依 **weaponClass === 'pistol'** 判斷不同：SMG 可以快速裝填，但換裝仍需 1 回合。使用其他彈種的武器照常花 1 回合。

免費裝填仍遵守彈匣容量與現有手槍備彈，轉入 `min(缺彈,備彈)`，不憑空補彈。滿彈匣或備彈 0 為無效操作。經驗／敵人／轟炸／地形／被動期限／等待／移動／連射累積不推進；之後新增冷卻也只能在耗回合路徑計時。

`Game.reload()` 負責共用數量轉移，免費分支直接執行此方法，付費分支在玩家輪到時執行；不得用 `executePlayer()` 執行免費裝填，否則會提早清掉等待／移動。現有 NPC 沒有彈匣與裝填行為，因此此效果目前只供玩家。戰場顯示「快填」，按鈕說明標 0 回合。

## 保存、紀錄與接手

單局 v10 新增 portrait（v1–v9 固定雜湊補圖），保存 `player.character`，以及敵我 `moveDelta`／`fireChain`。接受 v1–v8 遷移：舊任務指定 Soldier，補其兩個獨立被動；原 HP、武器／彈匣／詞條、其他被動、預備欄、RNG、回合與點數保留，不套用新角色起始裝備。來源已存在不重複追加；若舊被動已占滿 64 筆，優先保留舊來源，只補尚有空間的角色來源。

首次本機讀取 v9 留 `ash-save-v9-backup` 原件，QA 有 `qa-` 前綴；更早版本沿用各自備份。新版未知角色、非法方向或未來回合／超限連射計數拒絕載入。profile 仍 v4、完整備份仍外層 v1；新任務歷史增加可選 character 欄，舊歷史無此欄則顯示 Soldier。

原有繼續任務、重整、完整備份還原皆採存檔角色；單局匯入亦直接進入匯入的角色與任務，不要求重新選角。重新部署的角色／種子輸入不會先更動當前 game，取消安全返回。

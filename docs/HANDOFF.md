## 關鍵約定

- +x 右、+y 下。project / unproject 必須互為反函式；移動只接受 Manhattan 距離 1。
- `Game.action(type,arg)` 是回合入口。無效操作不得消耗回合、彈藥或物資。
- 正常有效行動：玩家 → reveal → enemyTurn → environmentTurn → reveal → 死亡判定。
- 樓層切換與成功撤離另有分支；換層補血、補彈並清毒，不讓新房敵人立刻攻擊。
- UI 的瞄準 / 背包 / 圖鑑不推進時間。手榴彈先選落點，再確認。
- `target` 可指向敵人或可破壞物，並非只有 enemies。UI 應透過 `game.targeted` 查找。
- 玩家彈匣為索引陣列，WEAPONS 索引持久化；**不可重排現有武器，只能附加**。
- RNG 狀態跟隨存檔保存，讀檔不得重新抽傷害 / 命中。
- 視線：combatSight 可探身，嚴格 lineOfSight 用於爆炸。不可讓爆炸沿探身路徑繞牆。
- 命中公式 97 + 瞄準15 − 目標移動22 − 箱體35或牆角42 − 等待閃避15，最低10、最高99；敵我共用。
- p.moved 表示目前玩家行動是否移動；enemy.moved 保留至下一次敵人階段。
- reveal 重建 visibleTiles，renderer 使用該集合避免每幀大量重算探身視線；序列化排除該衍生狀態。
- 爆炸會傷害玩家，無視掩體但被牆擋住。油桶先標記摧毀再遞迴，以防無窮連鎖。
- 環境毒 / 火不被一般裝甲或防禦吸收；hazmat 控制環境傷害。
- 有 pendingPerks 或已陣亡 / 勝利時，不能 action。

## 存檔注意

正式鍵 `ash-save`，版本 3，支援 v1/v2 遷移。v1 會保留當前地圖 / 角色 / 擊殺進度，補上新欄位，並將舊第三層 boss 轉為 warden。**舊樓層不強制重新生成**，因此新增危險地形與新武器箱從下一個新生成樓層起出現。

首次遷移前存 `ash-save-v1-backup` 或 `ash-save-v2-backup`；匯入前存 `ash-save-before-import`。本機歷史為 `ash-profile`，最多十次。QA 對所有鍵加 `qa-` 前綴。

不要在未告知使用者的情況下清除存檔或改變武器索引。改 schema 時加版本遷移及測試。

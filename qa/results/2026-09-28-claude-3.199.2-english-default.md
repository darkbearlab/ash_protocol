# 3.199.2 — 第一次開啟一律英文

2026-09-28，Claude。

## 需求

- 使用者：「幫我重封裝一個預設是英文的版本」。
- itch.io 的商品頁、預告與日誌都是英文。原本中文瀏覽器第一次打開會是中文。

## 做法

- `src/i18n.js`：新增 `DEFAULT_LANGUAGE='en'`。
  - 沒有存過語言選擇時用它，不再看 `navigator.languages`。
  - 存過的選擇（`ash-language`，測試模式 `qa-ash-language`）照舊優先。
  - Node（測試、工具）照舊預設中文。
- 新增 `tests/language-default.test.mjs`：
  - 每個情況各開一個程序，模擬中文瀏覽器（`zh-TW`）；
  - 沒存過 → 英文，測試模式也是；
  - 存過中文 → 中文；測試模式只看 `qa-ash-language`；
  - 存了不認得的值 → 英文。
- 文件：CHANGELOG、HANDOFF（版本行與語言表那一列）、TEXT_INVENTORY 第十一節。

## 驗證（Claude 自己跑的）

- **開發伺服器**：瀏覽器語言 `zh-TW, zh-Hant-TW, en-US, ja`，`?test=1`，沒有 `qa-ash-language`：
  - 重新整理後 `<html lang="en">`，標題畫面是英文（No mission in progress）。
  - 存入 `qa-ash-language=zh-TW` 再重新整理：`zh-Hant`，「無進行中的任務」。
  - 驗完把 `qa-ash-language` 移除，回到原狀。
- **測試與檢查**：
  - 完整 `npm test`：1383 通過、0 失敗；
  - 敵人資料一致性與基準相同；
  - `node qa/english-scan.mjs` 乾淨；
  - 名詞表是最新的。
- **打包**：`npm run itch` 產生 `release/ash-protocol-3.199.2-itch.zip`，437 個檔案，解壓 13.2 MB。
  - zip 裡的 `src/version.js` 是 3.199.2，`src/i18n.js` 有 `DEFAULT_LANGUAGE='en'`。
  - 已複製到 ash-promo 資料夾的 itch-upload（C:/codex_projects/ash-promo/itch-upload/），給使用者上傳 itch.io。

# 武器實例與詞條（3.8.0）

3.14.0 追加 base 6 輕機槍與 base 7 動力拳，參見 [BULWARK.md](BULWARK.md)。另追加 base 8 雷鳴爆彈槍，三連發榴彈，彈匣 9、射程 6、每發 24–30、命中後半徑 1 爆炸；第 3 層起只能由軍械／敵人掉落拾取，不作起始裝備。原六把 ID 不變。動力拳 melee／locked／integrated，ammoType=null、mag=0，禁止套詞條／拆解／交換；UI 必須用 ammoName／magazineLabel，不可直接索引彈種。

第一批六種詞條，每把最多一種，不分稀有度。新軍械箱與敵人武器掉落約 65% 帶詞條；起始武器及舊檔既有武器維持標準型。詞條不是單純提高全部數值，應依彈種、備彈、戰鬥距離與敵人移動選擇。

| ID | 名稱 | 優勢 | 代價 |
| --- | --- | --- | --- |
| stable | 穩定 | 命中 +10 個百分點 | 基礎傷害 ×0.9 |
| piercing | 穿甲 | 穿透 +0.25，上限 0.95 | 彈匣 ×0.75 |
| extended | 擴容 | 彈匣 ×1.5 | 命中 −8 個百分點 |
| powerful | 強擊 | 基礎傷害 ×1.15 | 彈匣 ×0.75 |
| longbarrel | 長管 | 射程 +2 | 基礎傷害 ×0.9 |
| tracking | 追獵 | 目標移動懲罰從 22 減為 10 | 基礎傷害 ×0.9 |

傷害先對基礎 min/max 四捨五入，再加武器改裝每級 +5 及玩家模組 bonus。彈匣向下取整、最低 1。穿透影響命中後的護甲與掩體減傷，不減少掩體命中懲罰；榴彈發射器不抽穿甲。霰彈的相鄰散射也套用武器穿透。

敵我仍用相同基礎命中公式。玩家武器增加 accuracyBonus；追獵只減少「目標移動」的懲罰，不是玩家移動後獲得命中加成。最終命中仍限制 10–99%，等待效果不變。物件的命中經 Game.fireChance 統一，與目標浮卡一致。詞條不更改敵人能力、實際連射發數或演出彈道數量。

## 背包行為

- 三格可以放同一槍種的多把武器；走上武器，有空格就收下，滿格則留地，不自動拆解。
- 鄰近軍械的「比較／拾取／交換」可選任一持有武器作比較，並列每發傷害、實際射擊發數、裸露靜止／移動目標命中、射程、彈匣、彈種、穿透、改裝級。命中不計等待、掩體或閃避。
- 有空格可收進空格；交換則只耗一回合，放下指定武器，保留它的詞條、剩餘彈匣和改裝級。交換裝備中的武器會直接裝備新槍，交換備用槍則維持原裝備。當回合敵人仍可行動。
- 拆解仍需確認，回收彈匣與 20 + 改裝級×10 廢料，備彈超額留地。沒有詞條重抽或更換詞條功能；原有 +1～+3 增傷改裝保留。

## 資料與遷移

單局存檔 v5；profile 仍 v3、完整備份外層仍 v1。武器實例以本局永不重用的整數 slot 識別，**不再以槍種索引識別持有武器**。沿用現有數值陣列，形成同一個實例表：

| 欄位 | 意義 |
| --- | --- |
| player.weaponBases[slot] | WEAPONS 中的固定槍種索引 |
| player.affixes[slot] | null 或穩定詞條 ID |
| player.ammo[slot] | 此實例彈匣剩餘量 |
| player.upgrades[slot] | 此實例改裝級 0–3 |
| player.owned | 攜帶中的實例 slot，最多三個、不可重複 |
| player.weapon | 裝備中的 slot，必須在 owned 中 |
| 地面 item.slot | 指向同一個實例表；item.weapon 保留槍種索引供地圖資料相容 |

新局前六筆保留歷史槽位，起始持有 0、1。之後的武器一律追加，生成時就配置實例（Game.registerWeapon）；離層遺留／已拆解的記錄不重新使用，因此舊按鈕或存檔不會指向另一把槍。相同 slot 不得同時出現在背包及地面，地面間也不可重複。Game.weaponAt(slot) 取得實際能力；WEAPONS[slot] 在新程式中是錯的。

詞條採 seed／floor／slot／位置的固定 FNV-1a 雜湊；不增加戰鬥 RNG 抽樣，不因打開選單、拾取、交換或重載而重抽。敵人是否掉槍仍使用原本的戰鬥 RNG／掉落率。

支援 v1–v4 原地遷移：舊持有武器沿用原索引、彈匣與改裝；舊地面武器逐把配置無詞條的新 slot。v1–v3 先沿用 3.7 的備彈分類與溢出守恆；v4 的五彈種不再分類。地圖、回合、RNG、協定點數不重設。首次本機載入 v4 先另存 ash-save-v4-backup；QA 會加 qa- 前綴。v5 重載不再遷移。新格式拒絕非法詞條、陣列長度不符、重複實例與失效地面參照。

戰鬥演出快照以 structuredClone 複製實例表；存檔仍立即儲存已結算回合。完整備份與匯入走同一個 Game.restore。新 weapons.js 已列入離線快取。

# 近戰職業：狂戰士與忍者（規格）

- 狀態：使用者 2026-09-11 確認設計，**3.47.0 規則已實作，3.47.1 介面已接上，3.48.2 伏擊條件改為煙霧／未發現**。平衡模擬尚未做。
- 分工：**Codex 只負責把職業做出來**：角色與武器資料、被動與技能規則、存檔、測試。**介面由 Claude 接手**：按鈕、選目標、狀態顯示、說明文字。
- 標「暫定」的數字是起始值，實作後由 Claude 用模擬調整。
- 兩個職業和現有六個一樣免費，不接主選單的解鎖。

## 共同

- **兩把新近戰武器**：比照動力拳，綁定職業，不能拆解、丟棄或交換，切入切出不花回合；撞敵時自動用它近戰。圖示先沿用現有素材或簡單程式圖，美術另議。
- 武器、角色、被動、技能的 ID 都只能附加在清單尾端，不重排。
- 近戰規則沿用現有的：相鄰、不隔障礙、照常擲命中、吃近戰命中與迴避修正。

## 狂戰士 `berserker`

| 項目 | 內容 |
| --- | --- |
| 生命／裝甲 | 160／3（暫定） |
| 戰鬥修正 | 射擊命中 −10（暫定），讓他明確是近戰職業 |
| 速度 | 普通（不緩速、不笨拙） |
| 武器 | 斧頭（新，綁定）＋破門者霰彈槍 |
| 配給 | 基礎配給 |
| 技能 | 鉤鎖 |
| 被動 | 生物、嗜血、戰意、刃藏（名稱暫定） |

**斧頭**（暫定）：近戰、射程 1、傷害 44～54、命中 92%、穿透 30%。

### 被動

1. **嗜血**：自己的近戰攻擊造成生命傷害時，回復實際傷害的 20%（不含溢出，也就是以目標被扣的生命計），向下取整。必須走 3.46 的共用回血函式 `healActor`，之後的回血規則才會自動套用。
2. **戰意**（擊殺疊減傷）：
   - 自己的近戰攻擊擊殺敵人時 +1 層，最多 5 層。每層讓受到的直接傷害 −5%。
   - 消退：距離上次近戰擊殺滿 5 個付費回合後，每 2 個付費回合掉一層；新的近戰擊殺會重置計時。
   - 換層保留層數，計時照常進行。
   - 環境與中毒傷害不受影響（比照重裝防護）。
3. **刃藏**：背包裡每有一把近戰武器（斧頭也算），所有攻擊的傷害 +10%、受到的直接傷害 −10%。目前他拿不到其他近戰武器，平常就是一把、+10%；這是將來近戰武器掉落的伏筆。
4. **減傷怎麼疊**：戰意與刃藏的百分比彼此相乘，不相加；套在固定裝甲之後、護甲板吸收之前，最少仍扣 1。例如兩者全滿約 −47%。

### 技能：鉤鎖

- **目標**：目前鎖定的敵人。使用現有的技能按鈕，不需要新的選目標介面；介面之後由 Claude 加強。
- **射程**：比照手榴彈，曼哈頓距離 5 格內，而且看得到，可以斜向。
- **拉或衝**：
  - 目標是大型（`large`），或是封鎖官、核心守衛 → 狂戰士衝過去。
  - 其他 → 把目標拉過來。
  - 注意：目前只有破壞者是大型，頭目要另外判斷。不要為此給頭目掛上大型，那會讓頭目被射擊命中率 +15。
- **落點**：
  - 拉：狂戰士上下左右四格中，離目標目前位置最近的空格。
  - 衝：目標上下左右四格中，離狂戰士最近的空格。
  - 落點必須可以站、沒有人，而且和對方之間沒有阻擋近戰的隔板或門。
  - 落點是毒液或高熱格也可以。
- **沒有落點**：不能使用，不花回合，給出原因。
- **到位後**：用斧頭砍一刀，照常擲命中；嗜血、戰意、刃藏都照常生效。
- **花費**：1 回合，冷卻 4 回合（暫定）。
- **結算時重驗**：目標已死或已不在射程、視線內，就照付回合、沒有效果。目標移動過但仍合法，就以新位置結算。
- **被拉的敵人要不要中斷瞄準與蓄勢**：由 Codex 決定。建議中斷，因為位置已經改變。
- 移動與攻擊都要走 `presentStep`，演出才看得到拉或衝的過程。

## 忍者 `ninja`

偵察兵的近戰變體。

| 項目 | 內容 |
| --- | --- |
| 生命／裝甲 | 100／0 |
| 戰鬥修正 | 射擊迴避 +10 |
| 武器 | 刀（新，綁定）＋寂靜精準步槍（3.47.2 使用者調整，原為蜂群衝鋒槍） |
| 配給 | 破片 0、煙霧 4、震撼 1；投擲容量 +2，與偵察兵相同（3.47.2 使用者調整，原為煙霧 2、容量不加） |
| 技能 | 光學迷彩 |
| 被動 | 生物、側身、夜視、伏擊、單挑（名稱暫定） |

**刀**（暫定）：近戰、射程 1、傷害 30～36、命中 95%。

### 被動

1. **伏擊**：下列任一成立時，忍者的近戰傷害 ×1.5（暫定）：
   - 目標處於失能。
   - 目標或忍者站在煙霧格內（3.48.2 使用者決定，取代原本的「目標看不到忍者」）。
   - 目標還沒發現忍者（3.48.2 使用者決定）。
   - 忍者站在暗處。

   每次成立的近戰攻擊，讓光學迷彩的冷卻 −1。迷彩生效中不減冷卻。光學迷彩本身**不算**上面任何一條。
2. **單挑**：此刻只有一個已發現他的敵人看得到他時，射擊與近戰迴避都 +15（暫定）。在每次敵人攻擊時判斷。

命中率最低仍是 10%。迷彩、暗處、側身、單挑全部疊上去也不會完全打不中。

### 技能：光學迷彩

- **啟動**：免費（比照訊號斷層）。
- **持續**：忍者自己的 5 次付費行動。攻擊**不會**解除迷彩。
- **效果**：敵人對忍者的射擊與近戰命中率 −30（暫定）。
- **冷卻**：效果**結束後**才開始倒數 10 回合，也就是啟動後約 15 回合才能再用；伏擊可以縮短。
- **設計意圖**（使用者）：從進入交戰距離算起，迷彩大約只夠殺一個敵人。玩家要自己控制失能道具和交戰房間的節奏。

## 3.47.0 規則交付與補充判定

- 角色 ID 追加 berserker／ninja；武器索引9 axe／10 katana（舊0–8不動）。沿用 powerfist 素材，不另做介面／美術。CHARACTERS 可建角，但 controller 的 OPERATOR_ORDER／選角與其他UI由Claude加入，不宣稱目前已能從選角頁點選。
- 規則主模組 `src/melee-classes.js`，調整常數 MELEE_TUNING、GRAPPLE_RANGE／GRAPPLE_COOLDOWN、CAMO_DURATION／CAMO_COOLDOWN。鉤鎖技能 ID grapple，迷彩 ID camouflage。
- 鉤鎖：`game.target=enemy.id` 後 `game.action('usePrepared',{category:'skill'})`。也可 action('skill','grapple')；必須已學會並預備。`game.grapplePlan()` 回傳 reason 或 enemy／mover／point／dash／slot，供介面預覽，無 RNG／狀態變更。初始失敗 fail 回報且不耗回合；承諾後只追原ID，失效仍耗回合但不開始技能冷卻。
- 鉤鎖落點依距離最近，等距依上右下左。移動為直線掃掠，不繞路、不穿實牆、實心物件、完整阻路邊或單位；斜角至少一側可通行。目標已相鄰時可原地斬擊。允許毒／熱落點，按原環境時點結算；不自動拾取移動路上的物品。大型使用 activeTrait，另列 boss／warden，不變更其體型。
- 拉動後清敵人 charge／windup／aim／focusTarget／fireChain；若沒有實際移動則不清。移動和攻擊各自 presentStep，目標若活著仍保留本輪原速度行動機會，不額外失能。拉／衝設 moved，moveDelta=[0,0] 表示強制位移不取得側身方向加成，也符合既有存檔的單步記憶限制。
- 鉤鎖耗1回合，冷卻4含施放輪（完成顯示3），不增加普通攻擊回合。斧頭透過 strike 進行，保留已裝備槍械。嗜血／戰意／刃藏均可觸發。
- 嗜血以近戰命中後實際HP損失計，排除道具、射擊、友軍、物件、溢出。經healActor；如果擊殺爆破體的連鎖爆炸已殺死玩家，不用吸血把玩家救活。戰意僅自己近戰擊殺增加，最多5。
- 戰意資料 `player.battleSpirit={stacks,lastKill}`。lastKill 是世界付費回合號，擊殺當輪不算等待；第5個後續付費回合末掉一層，之後每2回合末掉一層。免費操作／選升級不消退，換層不重置。直接傷害在固定裝甲後乘刃藏與戰意，向上取整至少1，再沿原重裝防護／等待／護甲板流程；環境與中毒照舊。
- 刃藏依 owned 近戰槽數計，原始攻擊傷害乘 1+0.1×數量後四捨五入。射擊／近戰／破片／玩家爆炸武器都適用，只加一次；油桶連鎖與環境不是自己的攻擊，不乘。防禦乘 max(0,1−0.1×數量)；與戰意相乘，不相加。角色自帶斧頭算一把。weaponDamage 仍為基礎與武器升級範圍，介面如需最終加成，可用 bladeMultiplier／ambushReady 預覽，勿把乘數再寫回基礎值。
- 迷彩是命中減益、不隱藏感知；`game.defensiveEvasion(attacker,target)` 包含迷彩30／單挑15，實際射擊與近戰皆從最終命中公式扣除再夾10–99。單挑計算此刻存活、alert、敵人感知距離內且 sight 成立的敵人數，恰好1才有效；失能不自動等於失去視線。
- 迷彩用 `usePrepared` 技能免費啟動，remaining5／cooldown0。第五次付費行動的敵人階段仍受保護，回合末 remaining0／cooldown10；後續10次付費行動才倒完。失能消耗的付費回合也計入。換層保留迷彩並照常計入一次付費行動，不能藉換層重置或縮短。攻擊不解除。
- 伏擊三條件任一成立只乘一次1.5；在有效近戰嘗試開始時判定（無效目標／離開範圍不算）。即使擲失手仍縮短未生效迷彩的冷卻1，另有正常回合倒數；迷彩生效中不縮短。光學迷彩不會讓 sight 變false。倍率先於防禦扣算，仍擲命中。

### 3.48.2 伏擊條件改版（使用者決定，Claude 實作）

原本的「目標看不到你」在近戰距離不會成立：近戰只能打上下左右相鄰的格子，而相鄰的兩個單位一定互相看得到，戰術視線在距離 1 時會忽略煙霧。使用者決定改成「目標或忍者在煙霧中」以及「目標還沒發現你」，並要 Claude 直接改。

- `ambushReady` 現在是：目標失能、目標或忍者站在煙霧格內（`inSmoke`，照座標判斷，不看視線）、目標 `alert` 為 false、忍者站在暗處，任一成立。原本的視線條件移除。
- 判定時點、倍率、縮短冷卻、介面顯示都沒變；狀態列與目標卡直接讀這個函式。存檔格式不變。
- **限制**：「目標還沒發現你」目前幾乎不會在近戰時成立。敵人在每次行動後的視野更新時就會發現看得到的你；走到相鄰那一步就會被看到，而且敵人同一輪就會行動。沒發現你的敵人也不會移動，所以不會自己走到你旁邊。
- 要讓偷襲真的有用，得記下「你到它旁邊之前，它還沒發現你」這件事，例如在敵人身上加一個「被偷襲」標記，第一次近戰後清除。這是新的存檔欄位，要升存檔版本並寫遷移，等使用者決定。細節見 [qa/results/2026-09-11-claude-3.48-ambush-color.md](../qa/results/2026-09-11-claude-3.48-ambush-color.md)。

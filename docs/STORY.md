# 背景故事與敘事（大綱，2026-09-14）

- 狀態：**使用者口述的大綱，尚未實作任何敘事內容。** 派系與敵人設計見 [FACTIONS.md](FACTIONS.md)。
- 所有現有名稱與文字（敵人、樓層、任務、資料片段）都當成暫定，之後可以整批改寫。

## 1. 大綱

- **戰爭已經結束**：這個銀河系裡，兩個跨星系企業打了一場戰爭。其中一方戰敗，主力部隊被徹底擊潰。
- **戰敗的企業沒有消失**：
  - 勝方完全不知道敗方總部在哪裡；銀河又太大，敗方散落各處的資產仍在運作。
  - 這些資產被稱為**火種**，隨時準備被總部喚醒，或在新首腦接管後捲土重來。
- **玩家是被繳獲的「數字人」**：戰鬥中被勝方俘獲的敗方複製人兵團，只有編號、沒有名字。他們被重新洗腦，投入搜尋並消滅火種的戰鬥，並希望在這些戰鬥裡找到敗方總部的線索。
- **不只人類**：火種散落在茫茫宇宙中，也遭遇了各式各樣的東西，所以等待玩家的不只是人類。

## 2. 原則（使用者決定）

- **不做遠大的劇情推進。** 故事是背景，重點是用已經建立的系統做出更多內容。
- **企業名稱不重要。** 玩家是被洗腦的複製人，不知道、也不在乎。故事頂多透過終端互動、資料片段之類的方式側面得知，對玩法完全沒有影響。
- **現有名稱與文字都是暫定**，可以依這個故事整批替換。

## 4. 與現有系統的對應

以下是 Claude 的建議對應，待確認；內容都還沒寫。

- **陣亡與重新部署**：換下一個編號的複製人上場。這解釋了死亡循環，永久升級可視為兵團整體累積的資料。
- **一次任務**：深入一座火種設施；六層樓就是設施由外到內的區域。
- **無盡模式**：順著火種的訊號一路追到更深處。
- **資料片段**：敗方總部的線索，依設施派系與深度抽取。
- **終端**：目前只能買補給。可以加一個「讀取資料」選項，讀到火種殘留的紀錄。
- **任務簡報**：只有編號與冷冰冰的指令，不出現企業名稱。

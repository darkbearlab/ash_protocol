## 首批規則

| ID | 顯示 | 效果 | 反向 |
| --- | --- | --- | --- |
| large | 大型 | 作為目標時，被射擊命中率 +15 個百分點 | small |
| small | 小型 | 作為目標時，被射擊命中率 −15 個百分點 | large |
| agile | 敏捷 | 移動造成的射擊命中懲罰由 22 增至 35 | clumsy |
| clumsy | 笨拙 | 移動造成的射擊命中懲罰由 22 減至 9 | agile |
| no_cover | 無法利用掩體 | 牆角與箱體不提供命中保護或減傷，實體牆仍阻擋視線 | 無 |
| fast | 快速 | 快速階段行動 | slow |
| slow | 緩速 | 緩速階段行動 | fast |

射擊最終機率仍限制為 10–99%。武器追獵等修正在移動懲罰之後扣除，最低 0；敏捷／笨拙在靜止時沒有作用。近戰沿用原來固定命中率，爆炸不擲命中率，大小規則只影響射擊。無掩體不會取消自身裝甲或等待防護。

同一規則有多個來源也不疊數值。兩種相反規則只要都存在就抵銷，不按來源數量相減；UI 保留兩個名稱並標記「抵銷」。例如永久快速＋一回合緩速現在是普通，回合末緩速到期後恢復快速。

自然生成：無人機只有 no_cover，鐵殼破壞者只有 large，第 4 層起的裂隙獵犬只有 fast。早期裂隙獵犬與其他敵人維持原規則；新規則不增加生成 RNG 抽樣。尚未把所有動物／頭目一律標為無掩體，後續可逐種調整。

## 行動承諾與順序

玩家提交一個有效指令時固定當輪存活單位的順序：快速 → 普通 → 緩速。每階段玩家優先，其餘敵人維持陣列順序；每個單位至多執行一次原有行動，快速不增加攻擊次數。SMG 連發、頭目召喚等仍是一個行動內的原有效果。

| 玩家速度 | 結算順序 |
| --- | --- |
| 快速 | 玩家 → 快速敵人 → 普通敵人 → 緩速敵人 |
| 普通 | 快速敵人 → 玩家 → 普通敵人 → 緩速敵人 |
| 緩速 | 快速敵人 → 普通敵人 → 玩家 → 緩速敵人 |

無效指令（撞牆、空彈匣、補給已滿等）在承諾前拒絕，不推進回合、不讓快速敵人行動、不消耗等待或暫時規則。有效指令承諾後，回合立即計數；即使先被擊殺，或目標／目的地已改變，也不能重選。被快速敵人占住預定移動格會留在原地，回合仍消耗。

射擊記錄原目標 ID，輪到玩家時使用其新位置、當時射線／距離／掩體／移動狀態計算。原目標已死、逃出視線或射程時仍向提交指令時的最後確認位置射擊落空，照常消耗彈藥與已承諾回合；不轉打其他敵人。失去目標的承諾射擊依武器耗彈，SMG 兩發、殘彈一發仍射一發；不會對最後位置上的其他單位造成傷害，發射器落空沿用不爆炸規則。玩家若已先被擊殺則不執行尚未輪到的射擊。敵人的一般射擊也使用行動當時的玩家位置。狙擊手既有蓄勢狙擊是鎖定地格，刻意保留；手榴彈同樣維持提交時選定的落點。之後新增攻擊需明確選擇「追蹤單位」或「固定落點」。

隊列速度本輪不重排；途中增減速度下一輪生效。死亡敵人跳過，新召喚敵人下一輪才加入；未警戒的敵人不行動。玩家移動揭露後，尚未輪到的敵人可警戒並行動，已錯過階段的敵人等下輪。換層後不執行舊樓層剩餘敵人，也不立刻執行新樓層敵人。

## 防護、移動與回合末

敵我移動狀態從移動後保留到自己的下次行動。玩家等待的減傷／閃避也從自己等待後生效，維持到自己下次行動前；上一輪已等待時可抵擋本輪搶先的快速敵人，首次按等待不能保護尚未輪到自己前的攻擊。瞄準 +15 給下次有效行動的射擊，無效免費操作不消耗，已承諾但因局勢變化失敗的行動會消耗。

所有速度階段完成後才結算到期轟炸，再處理環境毒／火，最後減少暫時規則回合數。它們每輪各一次，沒有按速度多扣時間。玩家已被擊殺則停止後續攻擊及環境；新樓層不在進入當輪觸發環境傷害。

## 資料與擴充入口

`src/traits.js` 保存定義及共用 resolver，戰鬥不得另用敵人 type 猜測被動效果。

```js
actor.traits = [
  {id: 'fast', source: 'character:scout'},
  {id: 'slow', source: 'effect:cryo', turns: 2},
];
grantTrait(actor, 'slow', 'effect:cryo', 2); // 相同 id + source 更新期限
removeTraitSource(actor, 'effect:cryo'); // 只移除此來源
```

省略 turns 表示永久；暫時值只接受整數 1–999，每輪末減一，0 時移除。單位最多 64 筆，source 為 1–100 字元英數、底線、冒號或連字號；規則 ID 必須已註冊。新增有限期效果需約定施加當輪是否已算第一輪，目前一律在該輪末扣一次。

單局存檔 v7 保存所有敵我 traits；讀取 v1–v6 時玩家補空陣列，既有敵人依種類和當前樓層補自然被動，不重抽地圖、武器、掉落或 RNG。首次本機載入舊 v6 留 `ash-save-v6-backup` 原件，QA 為同名加 `qa-` 前綴；更早版本沿用各自原件備份。v7 缺欄位或不合法規則拒絕載入。profile v4、完整備份外層 v1 不變。

演出仍觀察一次同步規則結算的快照，不重跑 RNG；快速／緩速參與時，可見敵人的移動或蓄勢也加入短暫片段，使搶先移動發生在玩家開火畫面之前。子彈抵達再扣血／倒下，整輪演出完才顯示升級或結果。重整恢復已完成回合，不重複行動。

使用者確認數值並授權實作先前四項構想，先前「僅記錄」狀態由本節取代：

| ID | 名稱 | 效果 | 基礎角色 |
| --- | --- | --- | --- |

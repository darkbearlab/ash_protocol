# 目前掩體規則清點（3.22.3）

依實際程式清點；本次僅改物件血條，沒有調整以下戰鬥規則。主要來源：[game.js](../src/game.js) 的 protectingCover／hitTarget／damagePlayer、[combat.js](../src/combat.js) 的 wallCover／shotChance／combatSight，以及 [barriers.js](../src/barriers.js) 的 edgeCover。

## 取得條件

掩體是相對「這次攻擊者的位置」即時計算；站到合格位置便生效，不需等待、按防禦或額外花回合。移動後重算。只有上下左右相鄰格算貼靠，斜角不算。

| 來源 | 必要位置／狀態 | 攻擊者命中懲罰 |
| --- | --- | ---: |
| 可破壞掩體箱、家具 | type:cover、HP > 0，與受保護者曼哈頓距離 1，物件位於來火的那一側 | −35 個百分點 |
| 一般牆 | 四向相鄰非地板格；牆在來火側，或沿平行射線朝攻擊者方向有開口的牆端／轉角 | −42 個百分點 |
| 門／隔板 | 受保護者站在該邊界的一側，HP > 0、關閉，且位於來火側；平行射線只在朝攻擊者方向沒有連續封閉邊界的端點有效 | −42 個百分點 |

「來火側」的精確判定是 `(掩體位置−目標位置) · (攻擊者位置−目標位置) > 0`。因此箱體不是必須精確壓在射線上，只要相鄰且在同側半平面便合格。箱體平行射線時點積為零，不提供保護；背向為負也不提供保護。

牆的平行例外：相鄰牆格往攻擊者方向再一格必須是地板；長直牆中段不算。門／隔板的平行例外則只查下一段有沒有仍封閉的格間障礙物，沒有進一步檢查該端是否緊接實體牆；射線是否真的通暢仍由視線／射線系統另判。

同時合格時只取一個，不疊加。固定優先序：**門／隔板 → 一般牆 → props 陣列中第一個合格掩體箱／家具**，不是依耐久或剩餘減傷選最佳。

## 效果與損耗

- 一般命中後，掩體把原始直接傷害降到 55%（減傷 45%），之後才算裝甲等效果。牆與箱子的差別是命中懲罰，基礎減傷相同。
- 玩家武器穿透會削弱敵方掩體減傷：`45% × (1−穿透率)`。例如穿透 70% 的武器，敵方掩體只減傷 13.5%；**命中懲罰仍在**。
- 被保護的目標確實中彈時，可破壞掩體另受 `ceil(原始傷害 × 35%)`，不是扣它實際吸收的量，也不隨穿透變少。未命中不扣掩體 HP。
- 若該發擊毀掩體，該發仍得到原本的減傷；後續連發重新判定，已破壞物件不再提供掩體。一般牆不可破壞。
- 命中懲罰可與移動、等待的迴避等因素相加；最後射擊命中限制在 10–99%。大型／小型、敏捷／笨拙不直接取消掩體。

## 不提供與例外

- 油桶、補給容器、終端、地面掉落、屍體、血跡／彈殼、煙霧本身不提供上述掩體。油桶可擋移動且會爆炸，但不是 cover。
- 門開啟、門／隔板或箱體 HP ≤ 0，立刻失去掩體效果。傷過但尚未破壞不降低其掩體強度。
- 有效的 no_cover 被動會取消所有上述命中保護與減傷，也拿不到架槍所需的掩體。牆仍阻擋路徑／視線。目前只有 drone 預設掛 no_cover；crawler、brute、其他機械，以及 Bulwark 不會因獸類／大型／機械／重裝自動失去掩體。
- 玩家動力拳：固定 99% 命中，不算掩體命中懲罰，直接傷害也略過掩體減傷；仍不能隔著封閉門／牆打人。
- 敵方近戰：實際攻擊命中固定 97%，不走射擊命中懲罰；但命中後仍呼叫 damagePlayer，能成立的掩體仍可減傷。**目前玩家動力拳與敵方近戰不是同一套掩體例外**，這輪只列出現況。
- 爆炸傷害不套掩體命中／45% 減傷。實體牆、封閉門／隔板仍能從幾何上擋住爆炸；同一爆炸先依破壞前的阻隔決定受影響者。榴彈發射器先做一般射擊命中判定，命中後才進爆炸，因此「發射器命中率」仍可能受掩體影響。
- 霰彈槍的濺射傷害走 hitTarget，仍可能吃掩體減傷／穿透；不能把所有看似範圍的演出都當作 explode。

## 探身、架槍與畫面提示

- 鄰接牆或封閉門／隔板時，視線／射線可從原格向可走且未被邊界擋住的四向鄰格偏移 0.6 格，雙方都能探身。這是視線判定，不是移動，不花回合；也不代表每一條方向都受到掩體保護。
- 士兵「架槍」：**自己相對射擊目標**有合格掩體時，命中 +12；不是目標有掩體就加命中。
- 畫面角色附近的掩體線使用 game.cover，列出所有四向相鄰候選，沒有指定攻擊者，不能解讀成「對目前所有敵人都有掩體」。瞄準資訊卡的掩體數值才是針對該次攻防位置。
- 高牆的美術高度、實心頂板、遮住人物的渲染，都不改上面的格子／方向公式。未新增蹲伏、高低差或身高判定。

## 3.22.3 物件血條

可破壞箱、家具、油桶、門和隔板，地圖血條只在 `0 < HP < maxHP` 時顯示。滿血／已破壞不顯示；受傷的開門也顯示，缺圖繪圖回退遵守同一條件。人物血條與瞄準卡上的耐久文字不變。此顯示不影響掩體規則。

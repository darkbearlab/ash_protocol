## 2. 忠誠方：標定與壓制

使用者：「更專注機槍的壓制，以及讓玩家容易被命中和受到更多傷害（士兵主動技能的頭目化）」。

### 第 3 層：只會標定

- **標定**是士兵預警反過來用在玩家身上：
  - 預告一回合：一條雷射線指著你。
  - 之後 3 回合，所有敵人打你命中 +15、傷害 +20%。狀態列看得到。
  - 數字比士兵預警（+10 命中、+10% 傷害）強一點，因為是頭目。
- **躲不掉**（使用者 2026-09-29）：標定和士兵預警一樣，煙霧沒用，離開視線也不會提早結束，只能撐過 3 回合。解法是這 3 回合裡別讓其他敵人打得到你：找掩體、拉開距離、先處理會開槍的。
- 半血時叫無人機，照現在的做法，不用預告。

### 第 6 層：架槍與壓制

- **架槍**：
  - 預告一回合，畫出前方 90 度、射程 7 的扇形。
  - 之後連續 3 回合掃射扇形。扇形裡看得到的目標，每回合吃一串低傷害子彈；只要人在扇形裡，不管有沒有打中都加一層壓制。
  - 壓制 3 層以上不能移動（SUPPRESSION.md），所以重點是在被釘住之前離開扇形，或找到掩護。
- **架槍期間的破綻**：
  - 不能移動、不能轉向。
  - 從扇形外打它命中 +15。
  - 掃完收槍 2 回合，之後才能再架。收槍的時候可以移動（使用者 2026-09-29：「收槍的冷卻時間可以移動」，3.205.0）。
- 半血叫無人機，同第 3 層。
- **也會標定**（使用者確認）：和架槍輪流用。「被標定還待在扇形裡」最危險。

### 實作（3.204.0）

- 名字（Claude 提，使用者 2026-09-29 確認）：第 3 層 **標定官**（Designator，`designator`），第 6 層 **火線官**（Gunline Officer，`gunline`）。照忠誠方的命名說它做什麼；英文避開敵人詞條「壓制者」（Suppressor）。已列進 GLOSSARY.md。
- 程式：規則與可調數字在 `src/loyalist-bosses.js`（`BOSS_TUNING`），忠誠方的 `bosses` 在 `src/faction-catalog.js`。封鎖官與核心守衛完全不動：混合派系（舊存檔）與叛軍（到 3.206.0 為止）照用；已經生成的樓層保留原本的頭目，存檔不轉換。
- 兩隻沿用封鎖官與核心守衛的機體（使用者：數值像它們）：機械、同一張圖換色、同樣的掉落、協定點數與工程師藍圖（Claude 的判斷）。標定官 180 血、裝甲 5、傷害 19、射程 6；火線官 280 血、裝甲 7、傷害 22、射程 7。標定與架槍以外照原本的打法：蓄勢一回合再開一槍。半血叫兩台無人機，不預告。
- 標定官沒有封鎖官的紅外線（Claude 的判斷）：它要看得到你才能開始照，所以預告之前躲進煙裡有用；一旦開始照，就躲不掉。
- 兩隻都不會抽到「快速」與「紅外線」詞條（獨立審查後，主工作階段的平衡判斷，Claude's call）：快速會讓照射在你能反應之前落下、第一次掃射在你走出扇形之前打出來；紅外線會讓「照之前躲進煙裡」失效。卡片的 `barredAffixes` 擋掉，抽詞條時那一抽照樣用掉，所以其他單位與其他詞條的抽選完全不變（身分基準只變了一筆：無盡種子 3 第 12 層的火線官原本抽到快速）。其他詞條（夜視）照舊會抽到。
- 架起的機槍（預告、掃射、收槍）不會轉去打地雷或誘餌（獨立審查）；被誘餌騙到時照樣掃自己的扇形。

#### 標定（兩隻都會）

| 項目 | 規則與數字 |
| --- | --- |
| 開始 | 看得到你、手上沒有蓄勢中的一槍、沒站在危險格上、冷卻已過 |
| 預告 | 1 回合：一條紅色雷射從頭目指到你，跟著你移動 |
| 落下 | 下一回合輪到它時落下，不管你在哪、看不看得到、在不在煙裡；落下之後它照常行動（通常是蓄勢） |
| 效果 | 落下那回合剩下的時間，加上之後 3 回合：所有敵人打你命中 +15、傷害 +20%；狀態列是紅色準星加剩下的回合，你身邊有紅色框角 |
| 取消 | 預告中頭目被 EMP 失能（兩隻都是機械，震撼彈沒用）、被拉走、被擊倒；看不到你不會取消 |
| 冷卻 | 標定結束後空 2 回合，第 3 回合才能再預告；標定官一輪最短 7 回合，其中 4 回合你是被標定的 |

Claude 的判斷：
- +20% 只算要擲命中的攻擊（槍與近戰）；爆炸、火與毒不擲命中，照舊。
- 頭目被擊倒後，已經落下的標定照樣撐完；換樓層就消失（出口要頭目倒下才開）。
- 標定只落在你身上，不落在你的單位上（「只對你」）。

#### 架槍（火線官）

| 項目 | 規則與數字 |
| --- | --- |
| 開始 | 和標定輪流，先標定；輪到的那招還不能用、另一招可以就用另一招。目標在 7 格內、看得到、在扇形內；手上有蓄勢中的一槍先開；標定落下的那一回合不開始 |
| 預告 | 1 回合：朝目標畫出 90° 扇形（左右各 45°），射程 7（步數距離），只含子彈到得了的格子（牆、關著的門、隔板擋住；箱子與矮隔板不擋，掩體照樣算在命中裡）。地圖上是琥珀色 |
| 掃射 | 之後連續 3 回合，每回合對扇形內它看得到的每個目標（你與你的單位）打一串 5 發，共 12 傷害（照深度放大，被標定時再 +20%），每發各自擲命中；扇形內每個人每回合加 1 層壓制，打中再加輕機槍連射的 1 層。地圖上是紅色，頭目旁的數字是剩下的掃射次數 |
| 破綻 | 架槍中（預告與掃射）不能移動、不能轉向；從扇形外打它命中 +15（只看角度：正前方射程外仍算扇形內） |
| 收槍 | 第 3 次掃射後收槍 2 回合：可以移動（3.205.0 起，使用者決定；照一般敵人的走法，先離開危險格），但不開火、不標定、不架槍；之後才能再架 |
| 取消 | 預告中被失能、被拉走、被擊倒：取消；掃射中被失能或被拉走：直接收槍 |

使用者的決定（2026-09-29：「收槍的冷卻時間可以移動」，3.205.0 起；取代 3.204.0 Claude 判斷的「收槍什麼都不做」）：收槍的 2 回合照一般敵人的走法移動（站在危險格上先走下來、往自己的有效距離走；貼著你時不動，免得走進你變成盲射），仍然不開火、不標定、不架槍。

Claude 的判斷：
- 掃射不打自己人；扇形裡看不到的目標（煙、黑暗）只吃壓制，不吃子彈。
- 壓制在自己的回合結束後減半（SUPPRESSION.md），所以只靠扇形的 1 層不會被釘住；被打中就是 2 層，在空地上連兩回合被打中會被釘住。
- 典型的一輪：標定預告 → 落下並蓄勢 → 開槍 → 架槍預告 → 掃 3 回合（第 1 次掃射時你還被標定）→ 收 2 回合 → 再標定，約 10 回合。

## 3. 叛軍：用火驅趕走位（等火焰發射器）

使用者：「使用火焰發射器，覆蓋玩家位置，可以遮擋視線和壓迫走位」。燃燒地板與火焰發射器的規則見 [HAZARDS.md](HAZARDS.md) 第 2、4 節。

### 第 3 層：縱火者（使用者同意 Claude 的提議）

- 有裝甲，不怕火。站在自己的煙裡打你，淡煙讓雙方命中都減半。
- **火牆**：預告一回合，在你身後或側邊畫一條 3～5 格的線，下一回合整條點燃，切斷退路。
- **圍困**：在你周圍 2 格畫一圈留有缺口的火，逼你從缺口走。
- **過熱**：噴 3 次後散熱 2 回合。這段時間不能噴火、裝甲降到 0，是反擊的時機。
- 和一般火焰兵詞條的差別：詞條是朝你噴一錐，縱火者是畫線、圍圈，用火來趕你走位。

### 第 6 層

- 第 6 層有機率抽到除名幹員（第 5 節）。沒抽到時，叛軍版是忠誠方第 6 層的變體（使用者）：一樣會標定，但壓制改成**噴火**。

## 4. 蟲族：預告照舊，但被打中代價很大

### 兩隻共通：鉤舌

- **命中後直接咬一口**：拉過來和咬在同一個行動裡完成，傷害是牠的近戰傷害（巨獸 26、母后 30）。鉤舌本身已經預告一回合，所以公平。狂戰士的鉤鎖也是拉過來加一擊在同一個行動完成。
- **路徑上都可以被鉤到**（使用者）：鉤舌沿著預告的方向打出去，鉤到路上的第一個單位，不一定是玩家。擋在中間的友軍、寵物或敵人會被鉤走。
- **鉤到自己的蟲也照樣拉過來咬**（使用者）：敵我不分，和衝鋒一樣。

### 第 3 層巨獸：衝鋒（使用者同意 Claude 的提議，並加上失能）

- **預告**：一回合，畫出一條直線，到牆為止，最多 8 格。
- **路上的單位**：敵我不分，往旁邊撞開一格、受 15 傷害，並**失能**（使用者）。Claude 提：失能 1 回合，同震撼的效果。
  - 旁邊沒有空的地板（牆、坑洞或別的單位），就留在原地，受 30 傷害，照樣失能。
  - 不會把人撞進坑洞，坑洞當成牆（PITS.md：遊戲裡沒有推擠，也就沒有掉進坑洞這回事）。
- **撞牆**：衝鋒停下，巨獸自己暈一回合，這回合被打命中 +20。站在牆前引牠來撞，就是這隻頭目的解法。
- **冷卻**：3 回合。
- 這是遊戲裡第一個推擠規則（PITS.md、ALLIES.md 都寫明原本沒有推擠）。只給頭目用。

### 第 6 層母后：產蟲巢（使用者同意 Claude 的提議）

- **預告**：一回合，地上先冒出卵囊。位置在離你 3～4 格、你看得到的地板。
- 同時最多 2 個。蟲巢照現有規則（45 點血、每 2 回合生一隻小蟲），但產下的蟲巢只生 3 隻，不然蟲量會爆掉。
- 使用者審台詞時的備註：蟲巢血很多，理論上先打巢是壞點子。所以台詞不叫玩家先打巢，只提醒別被蟲淹沒。
- **冷卻**：6 回合。
- 半血以下也會衝鋒，同巨獸。
- 現在的蟲巢只在生成地圖時放（`src/runtime-enemies.js`）；這是第一個戰鬥中產生的蟲巢。

### 實作（3.205.0）

- 程式：規則在 `src/swarm-bosses.js`（衝鋒、產蟲巢、存檔）與 `src/swarm.js`（鉤舌），數字在 `src/swarm-tuning.js` 的 `SWARM_BOSS_TUNING`（使用者試玩後再調）。卡片（`src/data.js`）：巨獸 `specials:['charge','tongue']`，母后 `specials:['nest','tongue','charge']` 加 `chargeBelow`（半血以下才衝鋒）；每回合照這個順序試，能用的第一招用掉這回合。兩隻都有自己的出場台詞（`intro`：`introBeast`、`introMatriarch`，使用者定稿，白鷺、鷦鷯各一句，表情照審稿頁）。
- 預告在輪到牠時最先處理（行為樹最上面，命令、生存模式的走位、誘餌與危險格都在後面）：預告過的鉤舌或衝鋒一定從預告的位置出去；誘餌騙不走、看過的地雷也不會讓牠先開槍、站在火上也不會先走開。
- 圖：鉤舌畫出整條會飛過的線（粉紅，淡色的格子加虛線，被瞄準的格子與落點照舊）；衝鋒是鏽紅色的車道，格子裡有指向衝鋒方向的箭頭，會撞牆時車道盡頭有一條紅槓；卵囊是地上一顆會跳動的淡粉色囊。衝的時候沿路揚塵、撞牆處有撞擊，被撞開的人身邊一團灰，孵化時卵囊裂開。目標卡寫「衝鋒蓄勢」「產卵中」「撞牆暈眩 +20」。

#### 鉤舌（兩隻）

| 項目 | 規則與數字 |
| --- | --- |
| 預告 | 照舊一回合、射程 5（步數距離）、要看得到而且射得到牠正在打的對象（你或你的單位） |
| 路線 | 從頭目穿過瞄準的格子一直延伸到射程 5；牆、關著的門、隔板與實體物件（箱子、油桶、蟲巢）擋住，矮隔板不擋，坑洞飛得過去 |
| 鉤到 | 路線上的第一個單位，不分敵我：你、友軍、寵物、平民、蟲族自己的蟲都算；路線上沒人就撲空 |
| 拉與咬 | 拉到頭目旁邊的空地板（預告的落點還空著就用它，否則離那個單位最近的一格），同一個行動咬一口：牠的近戰（卡片 26／30，和所有敵人的攻擊一樣隨樓層加，標準難度第 3 層 29、第 6 層 36），照一般近戰擲命中。本來就在旁邊的直接咬 |
| 冷卻 | 照舊 4 回合，出手、撲空或被打斷都算 |

Claude 的判斷：
- 路線延伸到射程，所以沿著線往後退一格還是會被鉤到，要往旁邊離開那條線（原本只要離開那一格就好）。
- 鉤舌瞄準牠正在打的對象，不只是你（原本只拉你）。
- 頭目旁邊沒有空的地板可以拉（例如被坑洞圍住）就不預告；出手時沒有就撲空。
- 已經在頭目旁邊、但中間隔著一般攻擊跨不過的邊（例如矮隔板）的單位，照遠處的一樣拉過去（越過那道邊，落在旁邊的空地板）再咬；沒有地方拉就撲空（獨立審查）。
- 咬死自己的蟲不算你的擊殺：沒有擊殺數、經驗與廢料，也不算進你的傷害統計，戰報寫成「巨獸傷到某某」；掉落照一般死亡（同執法者處決）。

#### 衝鋒（巨獸；母后半血以下）

| 項目 | 規則與數字 |
| --- | --- |
| 開始 | 看得到牠正在打的對象，對方和牠在同一橫排或直排、相距 2～8 格，而且車道碰得到對方。貼身時照舊咬 |
| 預告 | 1 回合：車道從頭目往對方的方向，到第一個牆、坑洞、關著的門、隔板、矮隔板或實體物件為止，最多 8 格；單位不擋車道 |

| 冷卻 | 3 回合（第 3 回合起才能再預告） |
| 取消 | 預告中被失能、壓制到不能動、被移開、被擊倒：取消，冷卻照算 |

Claude 的判斷：
- 兩側都空時用雜湊決定往哪邊撞（種子、樓層、回合、頭目與那個單位），不用戰鬥骰：重播與重新讀檔都撞同一邊。
- 失能 1 回合同震撼彈的效果，但不看機械或生物（是撞擊，不是手榴彈的關鍵字），之前被震撼後的免疫擋不住；結束後照震撼的規則有 2 次免疫。頭目也只失能 1 回合。
- 15／30 是撞擊前的數字：護甲照扣，防禦待機照樣減半，不算掩體；和頭目的其他數字一樣到了無盡的深層才放大，不隨每層加。
- 撞開一格可以撞到燃燒的地板上（那也是地板）；不會撞進坑洞，也不會撞過關著的門或隔板。
- 留在原地的單位，巨獸從它身上衝過去；車道盡頭有人留著時，巨獸停在它前面最後一格空地。
- 衝鋒途中巨獸自己倒下（例如撞到的自爆體炸死牠），衝鋒就停在那裡：不再撞後面的人、屍體不往前走、不算撞牆（獨立審查）。
- 撞牆的 +20 用翻越破綻的 +20（槍），近戰也加；撞牆時牠站著不動，不算移動中的目標。車道剛好 8 格、後面才是牆，不算撞牆。

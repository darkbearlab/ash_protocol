# 背包四分頁與預備欄（3.11.0 起）

3.12.0 已接上 Soldier／Recon 與快速裝填，保存版本升為 v9，詳見 CHARACTERS.md。下方為預備系統基礎；快速裝填現在也有專用免費執行分支。

背包分為武器／手榴彈／道具／技能。手榴彈是獨立投擲物分類，之後收納破片、煙霧、EMP；不能與醫療等道具合併成一格。三類各有自己的戰場使用按鈕。

本批只接入現有破片手榴彈、醫療包。技能頁顯示尚無主動技能，並列出本局被動；被動自動生效，不需要預備。煙霧、EMP、主動技能、手槍與玩家角色是後續內容，本批不加入假道具或測試技能到正式遊戲。

## 操作

- 武器頁保留分類備彈、三把武器、地面比較／拾取／交換、拆解與改裝。裝備鈕標示行動成本，現有六類武器皆為 1 回合。
- 另外三頁提供預備與取消預備，這兩種操作都免費，背包保持開啟。預備欄互不影響，切頁也不耗回合。一般開啟背包記住本次頁籤；由地面武器互動進入時直接開武器頁。頁籤偏好不存入任務。
- 戰場使用預備道具（H）、預備投擲物（G）與預備技能。醫療包立即提出使用指令；投擲物先選落點，以右下互動鍵確認，按原投擲物鈕取消。選點與取消不消耗數量／回合。
- 沒有預備或庫存 0 時使用鈕停用。數量用完保留原選擇，後續拾取同類補給即可再使用；不自動切換其他道具。可在庫存 0 時預先選好該品項。
- 新任務／舊檔預設預備破片與醫療包。玩家自行取消後，讀檔／換層／備份還原保持空欄，不強制補回。

## 資料與擴充

`src/prepared.js` 定義 `PREPARED_CATEGORIES`、`PREPARED_CATALOG` 與驗證／查詢 helpers。每個已實作品項有穩定 ID、名稱／短名／圖示／說明、資源欄位 resource、實際引擎指令 action。現有數量沿用 `player.grenades`／`player.meds`，不另建重複庫存；後續新品項需補資源、掉落、容量及實際指令的驗證／結算，不能只加 UI 字串。

```js
player.prepared = {grenade:'frag', item:'medkit', skill:null};
player.skills = []; // 已學會的主動技能 ID；目前 catalog.skill 是空的
game.action('prepare', {category:'grenade', id:'frag'});
game.action('prepare', {category:'item', id:null}); // 取消預備
game.action('usePrepared', {category:'grenade', target:{x:12,y:10}});
```

`prepare` 先驗證分類、ID 與技能是否已學會，然後只改指定欄位；重複選取視為無變動。未知 ID、跨類別、未學會技能、任務結束或待選升級時拒絕。存檔驗證同樣拒絕未知品項；未來實作技能時註冊完整定義後再加入 skills。

`usePrepared` 在行動承諾前固定預備品項與目標參數，再交給既有指令驗證／速度隊列。舊 `heal`／`grenade` 入口仍保留，但也要求對應品項已預備，不能繞過預備欄。終端醫療是付費補給，與醫療包預備無關。實際使用仍受先手致命攻擊、等待消耗、彈道演出與存檔同步規則約束。

## 免費換手槍的接口

`Game.actionCost(type,arg)` 是成本入口，於驗證成功後、建立速度隊列之前查詢。免費預備和免費換裝只修改相應欄位，不推進回合、RNG、敵人、環境、轟炸、被動期限，也不清除等待／移動狀態。日後冷卻亦應只在耗回合路徑推進。

`weaponSwitchTurns(weapon)` 按**目的武器**的 `weaponClass === 'pistol'` 回傳 0，其餘 1。武器定義已有獨立 weaponClass，詞條沿用類別。之後新增手槍只需標註此類別即可使用免費換裝；現在尚無手槍，所以正式武器都維持原成本。

這不是依 `ammoType` 判定：SMG 雖使用手槍彈仍需 1 回合。切離手槍至步槍也需 1 回合；地面拾取／交換、拆解與裝填不因手槍接口變免費。「快速裝填」於 3.12.0 實作，依手槍彈種判斷，見 CHARACTERS.md。

目前免費動作執行分支支援預備、換裝與快速裝填。未來新增免費道具／技能時需實作對應執行與冷卻限制，不能只把 actionCost 改 0 而省略實際效果。

`node qa/create-3.11-fixtures.mjs` 產生三個外部驗證用單局檔。手機四分頁、按鈕、鍵盤 H／G、縮放及模態視窗等交 Claude／使用者驗證，步驟見根目錄紙條；不要把自動測試等同真機驗證。

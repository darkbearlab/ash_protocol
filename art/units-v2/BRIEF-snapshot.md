# 專用單位精靈圖：給 Codex 的規格

2026-10-04，Claude 撰寫。使用者：「現在我們有沒有哪些 sprite 是沒有專用的 請幫我列出來 我來請 codex 生成專用的」。

- **現況**：遊戲 3.222.3 有 38 種敵人，只有 11 種有自己的圖。其他 27 種借用別人的圖格，用放大、縮小或染色勉強區分（`src/enemy-data.js` 每張卡的 `sprite:{key,corpse,size,tint}`）。友軍也一樣：工程師的無人機全部用同一張無人機，德魯伊的伴生獵獸用敵人的裂隙獵犬。
- **用途**：這份規格只換外觀，規則、數值、預告、存檔都不動。
- **撤退**：哪一張還沒交，遊戲就繼續用現在借用的圖。所以可以分批交，交一批 Claude 接一批。
- **分工**：Codex 交圖與製程，Claude 接入遊戲、升版、推送。Codex 不改遊戲程式、不改正式圖集 `assets/pixel/atlas.png`／`aftermath.png`。

## 1. 共同格式

照 [PIXEL_ART.md](PIXEL_ART.md) 的真點陣規則，和現有角色圖同一套：

- 每張 **32×32**，內容最多 28×28，四周留透明邊。
- PNG 索引色、**4-bit**，每張最多 16 色（含透明，palette index 0 是透明）。色值落在 RGB5 階（0–31 轉回 0–255）。不抖色，alpha 只有全透明與不透明兩種。
- **深色外框**：3.122.0 起所有角色在透明處補一圈深色外框 `(12,14,18)`（[SPRITE_OUTLINE_HANDOFF.md](SPRITE_OUTLINE_HANDOFF.md)）。新圖要有同樣的外框，和舊圖放在一起才不會突兀。
- **視角**：俯視四分之三角度，面向鏡頭（往下），單一靜止站姿，和 `assets/pixel/preview-4x.png` 裡的角色一致。
- **每個單位交兩張**：站姿，加上倒地的屍體（同一個單位倒在地上，看得出是誰；血跡適量）。屍體圖會進 `aftermath.png`。
- **顏色畫進圖裡**：接上專用圖之後，Claude 會拿掉原本的染色。
- **大型單位**：遊戲會把圖放大畫，例如巢穴巨獸 1.55 倍、母后 1.7 倍、重裝火焰兵 1.25 倍。圖本身仍是 32×32，輪廓請填滿格子。
- **不要畫在圖上的**：預告範圍、火焰錐形、鉤舌、雷射標定線、過熱的蒸氣、精英的金色外框、派系徽記、文字。這些都由程式另外畫。
- **參考既有做法**：`art/swarm-v1/README.md`（毒液噴吐蟲，3.84.0）是最近一次新增單位的例子。一次生成「左站姿、右屍體」兩格的來源圖，再用 `tools/pixelize.py` 同一套流程轉成 32px；它的提示詞可以當範本。

### 不用畫的

- **精英**（`raider_elite`、`gunner_elite`）：故意沿用原圖，加金色外框。

## 3. 可選的第二部分：地上物品

和上面無關，可以另外排。格式照 [LOOT_ICONS_HANDOFF.md](LOOT_ICONS_HANDOFF.md)（16×16、角框、半透明光暈、配色烘在圖裡）。2026-09-20 使用者決定投擲物與道具各用一張共用圖，所以這部分是升級，不是錯誤，要不要做請先問使用者。

- 四種投擲物共用一張：破片、煙霧、EMP、震撼。
- 十四種道具共用一張：醫療包、護甲、噴劑、腎上腺素、摺疊掩體、照明彈、脫離索、重新部署索、熱視鏡、夜視鏡、誘餌、地雷、外骨骼、螢光棒。
- 近戰武器：用手槍輪廓染色。
- 三種終端（醫療、軍械、裝備）用同一張終端圖。

## 4. 交件

照 [FX_SPRITES_HANDOFF.md](FX_SPRITES_HANDOFF.md) 與 [LOOT_ICONS_HANDOFF.md](LOOT_ICONS_HANDOFF.md) 的做法：

- **來源**：`art/units-v2/`。放來源圖（含透明）、`PROMPT.md`（每張的實際提示詞）、`README.md`（處理步驟，可重跑），做法和 `tools/pixelize.py` 一致。候選放 `art/units-v2/candidates/`，使用者選定或親手修過的要註明。
- **成品**：`assets/pixel/units-v2/`。每個單位 `<圖檔名>.png` 與 `dead-<圖檔名>.png`（32×32、4-bit 索引），加 `sprites.json`（每張的色盤與 SHA-256，格式同 `assets/pixel/swarm-v1/sprites.json`）和 4 倍預覽圖。
- **交接說明**：寫一份 `docs/UNIT_SPRITES_HANDOFF.md`，寫明交了哪幾批、採用哪一版、使用者改過哪些、已知取捨。
- **Claude 接入**：
  - 把新圖格依序**追加**到 `atlas.png` 與 `aftermath.png` 的最後，不重排舊格；
  - 改各卡的 `sprite.key`、拿掉染色；
  - 軍犬需要讓派系覆寫也能換圖，伴生獵獸與工程師友軍要另外指定圖格，這些程式由 Claude 做；
  - 補 `sw.js` 與測試，升版。

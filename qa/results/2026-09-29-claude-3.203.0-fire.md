# 3.203.0 — 燃燒地板、火焰發射器與火焰兵

2026-09-29，Claude（子代理實作；主工作階段審閱後才提交與推送）。

## 需求

- 使用者（2026-09-29，docs/HAZARDS.md 第 2、4 節）：火只從火焰發射器來，燃燒地板、火焰發射器與火焰兵放同一版。
  - 燃燒地板：每回合開始擲骰熄滅、延續、延續並蔓延；旁邊有火時往延續移（Claude 的數字：40／40／20、每個鄰居挪 10%、熄滅最低 10%、每格最多 5 回合、整層最多 30 格）；骰子由種子、樓層、回合與格子算出。可以走進去，回合結束扣 10（敵我相同，飛行不受影響），AI 繞開；火是光源，燒著的格子算淡煙。第 5、6 層固定的火也要發光，但不蔓延、不冒煙。
  - 火焰發射器：射程 5、錐形，點燃地板並直接傷害；一罐 8 發、不能裝填；只從火焰兵掉落與未識別貨櫃取得。
  - 火焰兵：邏輯同擲彈兵，武器整把換成火焰發射器、只會噴火、有裝甲；預告一回合再噴；被擊敗 30% 燃料罐爆炸，否則掉火焰發射器。
  - 圖像：Codex 的 `fire.png`（依狀態選列）、`flame-burst.png`（四格、朝東、轉向、播一次）、`loot-flamer.png`；沒有圖時退回程式繪製；火的煙走現有的煙霧場，不另做逐格煙。

## Claude 的判斷（規格沒寫到的，都寫進 HAZARDS.md）

| 項目 | 決定 |
| --- | --- |
| 相鄰 | 只算四邊，只算燃燒地板；固定的火不算鄰居，火也不會蔓延到它上面 |
| 蔓延落點 | 四邊的地板：不是坑洞、沒有箱子油桶巢穴、回合開始時沒在燒、這回合還沒被燒到；牆、關著的門、隔板擋得住，矮隔板擋不住 |
| 重新噴到正在燒的格子 | 從第 1 回合重新算 |
| 火的光 | 1 格內亮、2 格暗 |
| 燃燒地板上的閒置敵人 | 先退一步（同蒸氣） |
| 火焰發射器傷害 | 每個單位 20–26，不擲命中、無視掩體、護甲直接扣；友軍也燒 |
| 錐形 | 半角 30°（霰彈槍的），5 格內，空地上 8～12 格 |
| 火焰兵機率 | 標準第 3 層起每層 2%、上限 12%；40 個種子平均第 3～6 層每層 0.2／0.6／0.9／0.9 個，第 7、8 層 1.4 |
| 誰會是火焰兵 | 沒有自己行為的武裝士兵，不含感染者；不和壓制者、擲彈兵、投放並存 |
| 火焰兵裝甲 | 2 |
| 標出的錐形 | 從原地照標出的範圍噴，目標走掉也照噴；被拉走、失能、擊倒就取消 |
| 火焰兵的燃料 | 不計（敵人的槍本來就不算子彈）；掉下的火焰發射器一律滿罐 |
| 燃料罐爆炸 | 自爆體的爆炸（半徑 1、30 照深度放大），爆炸範圍的地板著火，不掉武器 |
| 貨櫃機率 | 每個未識別貨櫃 1/28（等於清單多一項），用自己的雜湊 |
| 擊殺屋整備區 | 照 KILLHOUSE.md 擺出每一把非綁定武器，所以也有火焰發射器（模擬） |

# 補給容器：3.17.0

3.18.0 接手註：生活模組與兩座補給站分布已完成，詳見 [LIVING_MODULES.md](LIVING_MODULES.md)。本檔保留此子系統規則；門／箱／模組改採最新紙條統一驗收。

使用者授權接續補給容器。目標是讓探索先找到箱子，再開箱取得地面補給；本批不調整物資總量、補給站密度或 Recon 主動技能。

## 玩家操作

- 新樓層的分類備彈、投擲物、醫療包、護甲板與廢料裝箱。獎勵房的 cache 物品合併到一個箱內，其餘同格補給一起裝箱。武器、資料片、敵人掉落、終端溢出物資維持地面物品。
- 箱子是低矮地面箱，可走過、不提供掩體，不擋視線／射擊／爆炸；不具有耐久、不可鎖定射擊，爆炸不會毀掉箱內物資。這是初版選擇，不與可破壞掩體箱共用規則。
- 靠近上下左右相鄰格或站在箱上，用右下統一互動開啟，一回合。多箱、門、終端與武器共用原互動選單。點箱子只顯示簡短操作提示，不直接耗回合、不另加確認彈窗；方向鍵仍可走上箱格。
- 開箱不等於拾取，人物與庫存不變；物品落在地上，再走過拾取。走過未開箱也不自動開啟。空箱保留、無法再開；箱內物資不再保留副本。
- 箱子分彈藥／醫療／護甲／投擲物／廢料／綜合，以顏色與符號區別；地圖只標記已發現且未開的箱，不展示詳細內容或數量。背包只顯示真正取得的物品。

## 落點與回合

優先使用玩家面前的箱子格；玩家站在箱上時，優先使用面向的鄰格。接著按北、東、南、西檢查箱旁格。候選須為地板，與箱子之間無關門／隔板、不被活敵人、其他物件、危險地形或玩家占用；先找沒有地面物品的候選，再允許與現有物品疊放。箱子本身不算阻擋。

若全部候選都不適合，補給留在玩家腳下並明確提示移開再走回拾取。這個退路不跨門、不刪物品、不免費自動收入。箱內多項一起落在同格，沿用原本拾取與攜行容量規則。

先驗證是否相鄰且可接觸，再承諾箱 ID。開箱遵循快速／普通／緩速；若敵人先使箱子不可接觸，玩家仍花已承諾的回合，但不開箱／不掉物。失能時跳過、不開箱；免費預備不開箱、不前進時間。開箱打斷等待／連射，不取得移動與等待加成。

## 生成與保存

`src/containers.js` 的 packSupplies 在原本地形、門、物品生成後包裝現有物資，不呼叫 RNG、不重抽內容。用已保留的補給地板放箱；同格不建立兩箱。軍械註冊、詞條亂數和物資總量不變，只改空間集中程度與取得回合成本。

箱子保存在 props：`{id,type:'container',kind,x,y,opened,indestructible:true,contents}`。contents 只接受已知補給 type、可選正整數 amount、可選 cache:true；未開至少一項、最多 32 項，已開必須空。沒有武器實例，避免重複所有權。openContainer 清空箱內陣列後將內容複製至 items，開箱不重抽亂數。

單局 save v14，相容 v1–v13；舊存檔當前樓層不把地面物資改裝箱，下樓的新地圖才適用。v13 本機首讀留原件。profile v4／backup v1 不變，完整備份驗證接受 container，Game.restore 同時驗證 ID 唯一、種類、地板位置、開箱狀態與內容。放棄、重置、復原沿用既有交易保護。

allSupplies 是數量守恆測試用的展開視圖，不用於玩家畫面。自動通關玩家可規劃走近含所需物資的箱，透過合法開箱行動與移動取得；該測試玩家本來就知道地圖，不能當作真實玩家的探索／勝率證據。

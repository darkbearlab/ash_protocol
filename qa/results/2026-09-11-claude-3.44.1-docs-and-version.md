## 22. 版本號單一來源（提交 1）

- `src/version.js`：`VERSION` 是唯一來源。說明頁與設定的 BUILD 字樣改讀它，不再手打數字。
- `npm run bump -- x.y.z`（`tools/bump-version.mjs`）：一次改 `package.json`、`src/version.js`、`sw.js` 的快取名稱。本版就是用它從 3.44.0 改成 3.44.1。
- `tests/release.test.mjs`：三處版本不一致，或 BUILD 字樣又寫死數字，測試就失敗。
- `src/version.js` 已加進 `sw.js` 的離線清單；build 產物會匯入 `version.js?v=<雜湊>`，並回報 3.44.1。
- `docs/RELEASE.md` 發版步驟改寫。

# 頭像第二輪：4×4 像素構圖預覽

更新 3.14.0：使用者認可風格，16 張已採用。加 --install 可將成品寫入正式池，保留前四舊 ID；不加仍只產預覽。比較圖始終從第一輪原圖重建上排，不讀已替換的正式素材。下方為生成當時的預覽紀錄。

2026-09-09。使用者認為上一輪高解析度畫作硬縮像素會留下不適合小尺寸的細節，要求用圖集方法再產一輪看看。

此輪由內建 GPT Image 一次產出 16 名原創日系正面行動員；提示要求直接以 64×64 思考五官、髮束、輪廓和有限色塊，避免髮絲、細機械線、漸層及紋理。生成圖仍是高解析度近似像素構圖，不能直接宣稱為真正 64×64。原圖保留於 source-atlas.png，完整提示見 PROMPT.md。

`python tools/pixelize_portrait_atlas.py` 依 4×4 等分切割；alpha ≥224 硬化後合成深色背景，最近鄰取樣至 64×64，median-cut 限 16 色，再量化 RGB555 色階，無抖色，保存為 4-bit 索引 PNG。使用者已授權額外像素化與顏色處理。

- preview.png：16 張編號預覽，每張最近鄰 3 倍顯示。
- comparison.png：上排上一輪四張，下排新圖集前四張；每張皆 64×64，3 倍顯示。不是同一人物的精確重繪。
- cells/01.png–16.png：真正 64×64／最多 16 色候選成品。
- manifest.json：裁切格、色數、SHA-256、Pillow 版本與處理參數。

已檢視原圖／切割成品及對照，並檢查尺寸、色數、索引深度、RGB555 和重建雜湊一致。本輪只供使用者評估，不接入遊戲，不替換現有四張圖、不改存檔或版本。來源／候選／工具／提示均提交 main；遊戲仍 3.13.0。待使用者選定風格後再決定採用與擴充。

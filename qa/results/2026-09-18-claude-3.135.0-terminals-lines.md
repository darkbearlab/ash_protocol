# 3.135.0 三類終端、夜視鏡改為掉落、繩索 — 驗證報告（使用者決定，Claude 實作，2026-09-18）

## 使用者決定（依據）

- 起因：平衡中發現夜視鏡可以在終端買，讓難度驟降。
- 夜視鏡從終端拿掉，只從掉落或寶箱取得；「未識別倒是可以有夜視鏡的機率」。
- 學習資料：拿掉沒代價的夜視被動（Claude 建議連同紅外線）；重裝防護保留，但學了會像重裝兵一樣緩速。
- 位移：「不花回合的掉 1 個，花回合掉 3 個，一個是逃命繩索，一個是重部署利器的概念」；6 格；一個只用一次；持槍敵人掉落（使用者同意）；不成為 build 的一部分。
- 終端：「拆這三類，每一層都只有其中兩種，放在各自主題的房間中」；每層仍兩台。
- 使用者：「已經決定的就做出來後一起推上去吧」。

## Claude 暫定的數字

- 繩索：持槍敵人 4% 掉落，兩種各半（逃命繩索 ×1、重部署鉤索 ×3）。
- 夜視鏡：狙擊手 25% 掉落；未識別貨櫃內容池加入夜視鏡（池子 20 → 19：拿掉夜視、紅外線，加入夜視鏡）。
- 缺哪一類終端由種子與樓層決定，三類機會相同。額度維持 60。

## 改動

見 docs/ITEMS.md〈道具與終端第二次改版〉的「實作」。

- 新模組：
  - `src/terminal-kinds.js`：三類、主題房間、每層缺哪一類；
  - `src/lines.js`：繩索規則、繩索與夜視鏡的固定掉落骰。
- `world.js`：`themeTerminals` 在生成完成後把終端搬進主題房間。會擋路就不搬。
- 終端畫面：標題寫種類，只列這一類；修復噴劑從「道具」移到「醫療」分組。
- 道具欄：兩種繩索，瞄準方式和照明彈一樣。預覽線綠色表示可以拉，紅色表示不行。方向鍵可以移動落點。
- text-play：新增 `rope escape|redeploy <落點>`；終端標題與販售項目跟著種類。
- 遊戲內說明：終端段落補上三類終端、夜視鏡來源與繩索。
- SAVE 62：舊存檔的繩索數量為 0；舊終端沒有種類，照舊什麼都賣。

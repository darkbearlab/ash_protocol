# 原路回收與樓層保存（3.28.0）

## 遊玩流程

新增第六份合約 roundtrip「原路回收」，深度三層。其他五份合約仍為原六層流程，不更換既有任務或重置存檔。

1. 去程 1 → 2 → 3；前兩次下樓沿用原生命 +25／分類備彈補給。
2. 第 3 層回收一份資料，依舊耗一回合、不占背包容量；第 3 層封鎖官也必須擊敗。先取件或先殺封鎖官都可，兩個條件完成前不能離開。
3. 取件立即切換回程，綠色出口移到本層原入口，提示「上樓」。第 3 層舊出口不再是有效出口。路線 3 → 2 → 1，到第 1 層原入口互動才勝利。
4. 回到上一層時從其舊下樓電梯附近出現；占格時選可達且沒有活敵人／地板危險的最近空位。不位移、傷害或移除占位敵人；沒有安全空位則拒絕換層。
5. 回程不重建地圖、不回血、不發彈藥／道具、不重複結算樓層點數。每層 floor:N 仍只發一次，撤離成功點數只發一次；最深紀錄保留 3，不因最後回到 1 而倒退。

只允許去程往下、取件後往上，不增加自由往返刷樓選單。離開後不再可訪的高層可以丟棄，最多保存兩層，不建立無限樓層快取。

## 樓層資料與計時

src/retreat.js 的 FLOOR_FIELDS 明列地圖、明暗、房間與路線、入口／出口、敵人、物資、家具／箱子／補給站、門／隔板、危險格、轟炸、已探索、煙霧、痕跡及傳送預告。archiveFloor 深拷貝保存到 floorStates[floor]，savedTurn 保存離開時的全局回合。

角色、武器登錄表、任務、點數事件與戰鬥 RNG 屬於整局，不跟樓層拷貝。地面武器沿用同一 slot 與詞條／彈匣，回程不再 registerWeapon、不重抽掉落。存檔驗證會檢查目前與所有已存樓層的武器 slot 不重複。

離開樓層後，敵人不移動／補血、控制狀態保留，重新進場才依正常感知更新警戒與最後目擊。煙霧與轟炸在非目前樓層暫停，回來按離開時的剩餘回合接續；離開當輪已過期的煙霧不保存，當輪已到期但因換層未落下的轟炸留到返回後第一次行動。回程不清角色毒／失能來換取免費恢復；等待／連射與訊號斷層效果在換層結束，技能冷卻仍照全局耗回合動作倒數。

## 同一波撤退增援

取件開始整個撤退增援事件；第 3 層立即預告，回到第 2／1 層時各預告一次。每層最多兩名（rifleman、raider），全局最多六名，不重複追加。

- 決定落點不使用戰鬥 RNG：可達、距玩家至少 5 格、避開入口／出口／活敵人／物件／物資／危險與任務點，兩落點至少相距 3 格；無足夠合格位置可以少於兩名。
- 可見落點在地板顯示青色 +2／+1 預告，兩次耗回合行動後傳送。背包／預備／免費裝填不推進；視野外不洩露落點，只保留增援日誌。
- 出現於敵人階段之後，不插入當輪 initiative queue，下一輪才可能行動。觀察使用正常感知，因此煙霧／訊號斷層仍有效，不強制知道玩家位置。
- 玩家、活敵人或新障礙物占位時原地延後一回合，不擠人、不傷人、不另抽位置。讀檔保留同一 id／落點／倒數，不能重複生怪。
- 增援死亡仍有一般 XP／廢料，有限六名；不掉裝備、彈藥、醫療或護甲，不當成替玩家補滿道具。原地圖敵人的正常掉落保持。
- 此批只做科技傳送的既有 pulse／地板預告，未做鑽地、異界關鍵字或地獄傳送美術；頭目低血召喚不受影響。

# 主選單音樂規格（2026-09-17，Claude 撰寫，交給外部製作）

這份文件可以直接交給作曲的人或 AI。遊戲本體的程式由 Claude 接，製作方只需要交出下面「交付物」一節列的檔案。

## 1. 用途

- 遊戲：ASH PROTOCOL／灰燼協定，直向手機瀏覽器上的回合制科幻射擊 roguelike，點陣美術加 VHS 濾鏡。
- **只用在出擊前的畫面**：標題畫面、部署（選任務、選幹員）、設定、解鎖與紀錄頁。進入戰場後不播音樂，戰場只用環境音。
- 玩家可能在選單停留幾分鐘，所以要能**無縫循環**、聽久了不煩。

## 2. 氣氛

- 背景：兩個跨星系企業的戰爭已經結束。玩家是被勝方俘獲、洗腦、只有編號的複製人幹員，被一批批投入敗方殘存設施（「火種」）執行清除。介面語氣是機構在歸檔，不安慰任何人。
- 要的感覺：**冷、壓抑、機械式的待命**。像作戰簡報室裡的待機訊號，或深夜終端機上反覆送出的呼叫。帶一點疲憊與哀傷，但不煽情。
- 不要：英雄式、熱血、勝利感、歡樂、可愛、恐怖片式的突然驚嚇、舞曲節奏。
- 必須是原創，不引用、不改編任何現有遊戲或電影的旋律。

## 3. 聲音硬體限制：紅白機 2A03（NTSC）

整首曲子必須能在真正的紅白機音源上演奏，只用內建四個聲部，不用擴充晶片（VRC6、FDS、N163 等都不用），不用 DPCM 取樣聲部。

| 聲部 | 能做的事 | 建議用途 |
| --- | --- | --- |
| Pulse 1（方波） | 佔空比 12.5%／25%／50%（75% 聽起來同 25%），音量 0–15 | 主旋律 |
| Pulse 2（方波） | 同上 | 分解和弦、回聲（主旋律延遲 1/8 拍、音量降低重複） |
| Triangle（三角波） | 沒有音量控制，只能開或關；音域偏低 | 低音線、偶爾當大鼓（快速下滑的短音） |
| Noise（噪音） | 16 種音高；一般模式（嘶聲）或短循環模式（金屬聲）；音量 0–15 | 打擊、無線電雜訊、訊號干擾 |

- **每個聲部同一時間只能發一個音。** 和弦一律用快速分解和弦表現。
- 音量與音高變化以每秒 60 次的步進為單位，滑音和顫音要短而克制。
- 單聲道，沒有殘響或延遲效果器；空間感只能用 Pulse 2 手動做回聲。

## 4. 音樂內容

- 速度：**80–92 BPM**，4/4 拍。
- 調性：小調。建議自然小調帶一點降二級音（弗里吉亞色彩），製造冷硬感；避免落在大三和弦上解決。
- 音量：主旋律 6–10、分解和弦 3–6、噪音 2–7。**不要整首都開到 15**，這是背景音樂。
- 打擊：稀疏。以噪音聲部做短促的「嗒」與偶爾的長雜訊，不要四拍大鼓那種穩定節奏。
- 動機：寫一個 **3～4 個音的短動機**，貫穿全曲。之後遊戲的升級通訊音效和其他提示音可能會沿用它。
- 參考結構（可以調整，但要有起伏）：

| 段落 | 長度 | 內容 |
| --- | --- | --- |
| 前奏（只播一次） | 2–4 小節 | 無線電雜訊短爆發加三角波持續低音，像訊號接通 |
| A | 8 小節 | 三角波低音反覆型；Pulse 2 低音量分解和弦；零星噪音 |
| B | 8 小節 | Pulse 1 主旋律進入，陳述動機 |
| C | 4–8 小節 | 抽掉主旋律；Pulse 2 用 12.5% 佔空比的短音做「資料傳輸」嗶聲；噪音做訊號干擾 |
| A′ | 8 小節 | 主旋律回來，Pulse 2 改做回聲 |
| → 回到 A | | 循環點 |

## 5. 長度與循環

- 循環段總長 **60–90 秒**。
- 循環必須無縫：循環段結尾接回循環段開頭時，節拍、音量與餘音都不能有斷點或爆音。結尾**不要淡出**。
- 前奏只播一次，循環從 A 開始。請標出兩個時間點：**前奏結束／循環開始**，以及**循環結束**，用秒數與 44.1 kHz 取樣點數表示。

## 6. 混音與輸出

- 單聲道，44.1 kHz。
- 峰值不超過 **−1 dBFS**；整體響度約 **−18 LUFS**（比音效小聲，手機喇叭聽得清楚但不吵）。
- 低頻不要依賴 100 Hz 以下，手機喇叭放不出來。

## 7. 交付物

1. `menu-theme.ogg`：Ogg Vorbis、單聲道、約 96 kbps，整首（前奏加一次循環段），檔案大小最好在 1.2 MB 以下。
2. `menu-theme.wav`：同內容的 16-bit WAV 母帶。
3. `menu-theme-loop.txt`：前奏結束／循環開始、循環結束的秒數與取樣點數。
4. 原始工程檔，依優先順序擇一：
   - FamiStudio 專案（`.fms`），最好；
   - Furnace（`.fur`，系統選 NES）或 FamiTracker／Dn-FamiTracker（`.ftm`）；
   - 如果沒有上述工具：**四軌 MIDI**，軌道名稱依序是 `Pulse1`、`Pulse2`、`Triangle`、`Noise`，每軌同時只有一個音，另附一份文字說明每段的佔空比、音量與噪音模式。
5. 一段簡短說明：動機是哪幾個音、各段在做什麼。

## 8. 遊戲端怎麼用（製作方不需要處理，僅供參考）

- 瀏覽器要求使用者先點一下才能出聲，所以第一次點擊標題畫面後才開始播。
- 按下出擊進入戰場時約 0.8 秒淡出；回到標題或陣亡結算後的選單再淡入。
- 設定裡會有音樂音量，與音效分開。
- 檔案會放進離線快取，所以大小有限制（見交付物第 1 項）。

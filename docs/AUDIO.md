# 聲音與音樂

更新：2026-09-17，**3.118.0：第四輪 P1 六項已接入，另試做訊號雜訊**（3.117.0 首次接進遊戲）。素材的採用紀錄見下方各節；先前每輪完整回饋保存於 [製作歷史](archive/audio-production-2026-09-17.md)，若歷史文字衝突，以本檔為準。

## 遊戲內現況（3.118.0）

- **程式**：`src/audio.js`（Web Audio 播放器）、`src/sound-cues.js`（演出事件對應音效，純函式）、`src/music-state.js`（選曲與交戰狀態，純函式）、`src/audio-grit.js`（訊號雜訊，純函式），由 `src/controller.js` 接上。
- **檔案**：音效 `assets/audio/sfx/*.wav`（採用檔逐位元組複製，進離線快取）；音樂 `assets/audio/music/*.flac`（無損，循環點精確），瀏覽器解不開 FLAC 時改用同名 `.m4a`（AAC）。音樂不預先快取，第一次播放後由 Service Worker 存起來。
- **啟動**：瀏覽器規定要先有使用者手勢，第一次點擊或按鍵後才建立音訊；頁面切到背景時暫停、回來繼續。任何播放錯誤都被吞掉，不影響回合。
- **設定**：「聲音」段有總開關（沿用舊的 `ash-sound`）、音樂音量（`ash-music-volume`，預設 60%）、音效音量（`ash-sfx-volume`，預設 80%）、訊號雜訊（`ash-audio-grit`，關閉／輕／重，預設關閉）。
- **同時發聲**：最多 10 個音效，同一個音效最多 3 個，超過時停掉最舊的；音效經過壓縮器，蟲潮時不會爆音。

### 音樂規則（使用者決定）

| 情況 | 播放 |
| --- | --- |
| 出擊前：標題、部署、從標題打開的設定與紀錄、結算畫面 | 〈待命〉，前奏一次後循環 |
| 設施內 | 當層派系的探索配樂；無盡模式換層時跟著換 |
| 敵人喊出交戰台詞（看得到或聽得到的「開火、衝鋒、瞄準、投彈、轟炸」類喊話；平民尖叫與「發現目標」不算） | 切到該派系的交戰配樂 |
| 交戰中，視野內連續十回合沒有敵人 | 切回探索 |
| Kill house、沒有專屬配樂的混合設施 | 算人類設施，用忠誠者配樂 |
| 陣亡或撤離後關掉結算、回看戰場 | 無音樂 |

換曲時 1.2 秒交叉淡化；同一首不會重新開始。交戰狀態不存檔，重新載入後從探索開始。

| 音效 | 何時播 |

| 擊殺 | 演出中有敵人倒下（優先於命中） |
| 命中 | 演出中打中玩家以外的單位 |
| 敵彈落空 | 敵人用子彈類武器（步槍、衝鋒槍、霰彈槍、精準步槍）打玩家沒打中；**玩家自己沒打中不出聲** |

| 爆炸 | 爆炸演出（手榴彈、油桶等） |
| 氣動門 | 門開或關 |
| 開箱 | 打開補給箱、器材箱、未識別貨櫃（3.118.0） |

| 升級通訊 | 升級卡片出現時 |
| 選單確認 | 按下選單（對話框）裡的按鈕 |

「演出中按指令直接執行」跳過的演出不播音效，但喊話仍會觸發交戰配樂。

### 訊號雜訊（3.118.0 試做，預設關閉）

使用者提議「隨機爆音或偏移加入演出中」。設定「聲音」段的「訊號雜訊」切換 關閉／輕／重。`src/audio-grit.js` 每次播放抽一份計畫，`src/audio.js` 照計畫播；用 `Math.random`，不碰遊戲亂數，也不影響回合。

| 效果 | 輕 | 重 |
| --- | --- | --- |
| 音高偏移 | ±25 音分 | ±70 音分 |
| 時間偏移（延後） | 0～6 ms | 0～20 ms |
| 爆音（2～7 ms 的喀聲，六種形狀） | 30% 機率 1 個，強度 0.12～0.3 | 75% 機率 1～3 個，0.25～0.6 |
| 靜電（1.2～4.2 kHz 帶通雜訊，30～120 ms） | 12% 機率，0.03～0.08 | 40% 機率，0.06～0.16 |
| 訊號斷一下（15～60 ms） | 8% 機率，剩 35～60% 音量 | 30% 機率，剩 10～40% |
| 配樂抖音（0.6 Hz 與 6.1 Hz） | 5 與 1.5 音分 | 14 與 4 音分 |

試聽：Claude 用同一份 `audio-grit.js` 離線渲染「戰鬥片段（配樂＋音效）」與「同一聲連播」各三版（原版／輕／重），傳到 Telegram；試聽檔與渲染程式不進版本控制。強度與預設值等使用者聽完決定。

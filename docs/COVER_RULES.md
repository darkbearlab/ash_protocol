# 目前掩體規則（3.23.0）

3.24 補充：角度掩體數值不變。目標暗區另有 −40 百分點射擊懲罰，可疊加；夜視只消除暗區項，不能忽略掩體。暗區本身不提供減傷或架槍資格；詳見 [LIGHTING.md](LIGHTING.md)。

3.23 改為三段角度效率，取代 3.22.3 的同側半平面／平行端點例外與固定地形優先序。共用公式在 [cover.js](../src/cover.js)，由 combat、barriers、game 與瞄準提示使用。

## 取得條件與角度

掩體相對這次攻擊者的實際位置即時計算，不需等待或額外花回合。箱體／家具必須 type:cover、HP > 0，與受保護者四向相鄰；一般牆是四向相鄰非地板格；門／隔板必須 HP > 0、關閉，受保護者站在該邊界任一側。斜角物件不算貼靠。

角度以「受保護者指向掩體」為 0°，攻擊者在掩體正後方是正面來火，側面是 90°。

| 來火角度 | 效率 | 箱／家具命中懲罰 | 牆／門／隔板命中懲罰 | 直接傷害減免 |
| --- | --- | ---: | ---: | ---: |
| 小於 45° | 完整 | −35 百分點 | −42 百分點 | 45% |
| 45° 起、小於 atan(2) ≈ 63.435° | 半效 | −18 百分點 | −21 百分點 | 22.5% |
| 63.435° 起，含側後方 | 無效 | 0 | 0 | 0 |

例：掩體在右側，攻擊者相對受保護者偏移 (3,1) 完整、(1,1) 半效、(2,3) 半效、(1,2) 無效。上下鏡射／四向旋轉相同。「騎士方向」指前進 1、橫移 2；前進 2、橫移 1 仍是完整保護。

程式不用四捨五入的角度：n = 掩體−受保護者，d = 攻擊者−受保護者，forward = n·d，lateral = abs(n.x*d.y−n.y*d.x)。forward ≤ 0 或 lateral ≥ 2*forward 無效；lateral < forward 完整；其餘半效。門的半格中心同樣適用。

多個候選只取實際命中懲罰最高的一個，絕不疊加：完整牆 42 > 完整箱 35 > 半效牆 21 > 半效箱 18；此排序的減傷也不會更差。同分保留候選順序（邊界、牆、物件）；耐久不作排序。保留原物件身分，只有選中的可破壞掩體承受損耗。

平行牆端／隔板端點不再額外給掩體，但探身視線不變。能看到、能開火與是否受保護分開判定；封閉實體仍可能擋住射線。

## 效果與損耗

- 一般命中後，完整掩體把原始直接傷害降到 55%（減傷 45%），半效降到 77.5%（減傷 22.5%），之後才算裝甲等效果。牆與箱子的差別是命中懲罰，基礎減傷相同。
- 玩家武器穿透會削弱敵方掩體減傷：`45% × 效率 × (1−穿透率)`。例如穿透 70% 的武器，完整敵方掩體只減傷 13.5%，半效為 6.75%；**命中懲罰仍在**。
- 被保護的目標確實中彈時，可破壞掩體另受 `ceil(原始傷害 × 35%)`，不是扣它實際吸收的量，也不隨穿透或角度效率變少。未命中不扣掩體 HP。
- 若該發擊毀掩體，該發仍得到原本的減傷；後續連發重新判定，已破壞物件不再提供掩體。一般牆不可破壞。
- 命中懲罰可與移動、等待的迴避等因素相加；最後射擊命中限制在 10–99%。大型／小型、敏捷／笨拙不直接取消掩體。

## 不提供與例外

- 油桶、補給容器、終端、地面掉落、屍體、血跡／彈殼、煙霧本身不提供上述掩體。油桶可擋移動且會爆炸，但不是 cover。
- 門開啟、門／隔板或箱體 HP ≤ 0，立刻失去掩體效果。傷過但尚未破壞不降低其掩體強度。
- 有效的 no_cover 被動會取消所有上述命中保護與減傷，也拿不到架槍所需的掩體。牆仍阻擋路徑／視線。目前只有 drone 預設掛 no_cover；crawler、brute、其他機械，以及 Bulwark 不會因獸類／大型／機械／重裝自動失去掩體。
- 玩家動力拳：固定 99% 命中，不算掩體命中懲罰，直接傷害也略過掩體減傷；仍不能隔著封閉門／牆打人。
- 敵方近戰：實際攻擊命中固定 97%，不走射擊命中懲罰；但命中後仍呼叫 damagePlayer，能成立的掩體仍可減傷。**目前玩家動力拳與敵方近戰不是同一套掩體例外**，這輪維持此例外。
- 爆炸傷害不套掩體命中／角度減傷。實體牆、封閉門／隔板仍能從幾何上擋住爆炸；同一爆炸先依破壞前的阻隔決定受影響者。榴彈發射器先做一般射擊命中判定，命中後才進爆炸，因此「發射器命中率」仍可能受掩體影響。
- 霰彈槍的濺射傷害走 hitTarget，仍可能吃掩體減傷／穿透；不能把所有看似範圍的演出都當作 explode。

## 探身、架槍與畫面提示

- 鄰接牆或封閉門／隔板時，視線／射線可從原格向可走且未被邊界擋住的四向鄰格偏移 0.6 格，雙方都能探身。這是視線判定，不是移動，不花回合；也不代表每一條方向都受到掩體保護。
- 士兵「架槍」：**自己相對射擊目標**有合格掩體時，命中 +12（半效也成立，無效不成立）；不是目標有掩體就加命中。
- 畫面角色附近的掩體線使用 game.cover，列出所有四向相鄰候選，沒有指定攻擊者，不能解讀成「對目前所有敵人都有掩體」。瞄準資訊卡針對該次攻防位置；半效時加「半效」標籤。玩家 HUD 在沒有暴露敵人、但有半效來火方向時顯示「半效掩護」。
- 高牆的美術高度、實心頂板、遮住人物的渲染，都不改上面的格子／方向公式。未新增蹲伏、高低差或身高判定。

## 3.22.3 物件血條

可破壞箱、家具、油桶、門和隔板，地圖血條只在 `0 < HP < maxHP` 時顯示。滿血／已破壞不顯示；受傷的開門也顯示，缺圖繪圖回退遵守同一條件。人物血條與瞄準卡上的耐久文字不變。此顯示不影響掩體規則。

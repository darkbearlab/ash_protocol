# Kill house 3.87.0 規則與素材交付

基底 main `8eaff9c`（3.86.0）。依 KILLHOUSE 全文與 PURGE_REVIEW，首次入口／提示／全息色調／死亡畫面／分數權重留 Claude。

## 完成

- `KillhouseGame` 子類共用既有戰鬥與技能，固定六房教學／超小整備／兩份街機戰鬥配方。敵人都是人類卡與 civilian，simulation 標記、每房一次進入事件、踏入電梯即結算。戰鬥無三選一與掉落、無頭目或敵方增援來源。
- 肅清名單、比率直接使用 purgeReview；僅從它的 turns 減去 battleStartTurn。整備轉層不額外補給。教學兩個研究員算進同一份名單。
- 模擬記憶體限定；saveGame 不寫 campaign，abandonRun 不清 campaign，recordResult／creditProtocol 不發點數。完整備份從 storage 匯出保留中的原戰役，低層 makeBackup 拒絕模擬；永久購買／重置／還原需先退出模擬。
- profile **6**：v5 及更舊紀錄保留原資料、增加空教學／最高分欄位；備份嚴格驗證同步。save **44**、backup **1** 不變。完成／跳過與分數由明確 storage API 保存，不自動修改戰役統計。
- 地圖風格登錄：原 facility 的主題、選材、PNG 與繪製順序保留。killhouse 八種類各一張、真 32px、每格16色上限、RGB555。內建 image_gen 產生單張圖集，原圖與提示在 art/killhouse-v1，確定性加工 tools/pixelize-killhouse.py。新模組與圖集已加入 SW。
- mapStyle 可選欄位跟著樓層封存／回復；換新樓層重選，原生成器不新增風格資料。

## 待決與邊界

- 暫定 restart／shared／all／教學不升級不掉落，集中 KILLHOUSE_OPTIONS。all 指完整可拾取武器；三種綁定原件維持職業原配給，不把不可卸除的動力拳發給其他人。class 依起始 weaponClass 篩選。
- 不新增戰役資源掉落，但自身庫存拆解、職業本身的友軍／寵物能力照常使用；沒有偷偷調整那些職業數值。
- 最高分權重／公式 ID 交 Claude，API 只接受完成的街機局。陣亡去向由結果提供，待死亡演出後處理。
- 首次強制教學與跳過畫面尚待 Claude 接 tutorialGate；本輪沒有改主選單，所以發布後一般玩家不會自行被轉進模擬。
- 人類／手機驗收尚未執行；請測房間順序、難度、門素材、離線、整備取捨與保留原戰役的全部流程。

# 3.1 規則與內容索引

## 命中率、牆角與交叉火力

射擊使用敵我完全相同的公式：`clamp(97 + 瞄準15 - 移動22 - 箱體35或牆角42 - 等待閃避15, 10, 99)`。未加成時：暴露靜止 97%；移動 75%；靜止箱後 62%；移動箱後 40%；靜止牆角 55%；移動牆角 33%。命中後再計算裝甲和掩體減傷。手榴彈與爆炸區域不另擲命中率。

牆角探身最多延伸 0.6 格到相鄰可行走空間。兩端使用相同採樣，保持可見 / 可射的對稱性。禁止穿牆移動，完全封閉牆體仍不可見。爆炸不使用探身射線，以免彎過牆傷害。

移動狀態：玩家當次移動降低隨後敵人射擊命中率；敵人的上次移動降低玩家這次射擊命中率，直到敵人再次行動。UI 顯示目標當前命中率及無掩護敵方射線數。

斷訊槍兵基礎生命 22、傷害 17、射程 7；破口突擊兵生命 18、傷害 21、射程 5。兩者首次蓄勢後連續射擊，並會移到相鄰掩體；每層普通房間約 3–4 個守軍。地圖加入門側掩體、內牆轉角與交叉射擊位置。

## 等待與手機視野

等待消耗一次行動。本次敵人阶段射擊命中率 −15；下次有效行動的射擊命中 +15（最高 99%），之後消耗。無效操作與查看選單不消耗，連續等待只更新、不疊加。近戰、爆炸不受這個槍擊閃避加成影響。換層清除加成。

正方形戰場以角色為中心；鏡頭自動縮小以包含鎖定目標及手榴彈落點，不改變 LOS 或射程。所有 HUD / 提示在戰場外，地圖另開選單。首頁是任務簡介，進場後移除裝飾性標題。

## 一局流程

六層固定主題、種子決定房間尺寸与敵人組合。每層九個相連房間、補給、終端、掩體、軍械箱與一份資料。綠色電梯通往下一層；第三 / 六層頭目存活時鎖定。第六層頭目死後搭乘電梯成功撤離。

行動按鈕：射擊 / 裝填 / 手榴彈 / 醫療 / 防禦 / 等待。快捷列：目標切換 / 換槍 / 背包。所有相關資料也可從右上設定取得。

## 戰術數值

- 手榴彈：射程 5、半徑 Manhattan 2、中心傷害 55，每遠一格 −10；爆破模組另加傷害。
- 油桶：生命 18、爆炸半徑 2、中心傷害 45。連鎖各自造成傷害。
- 掩體：生命 65，位於攻擊方向與受擊者鄰格時吸收 45% 槍擊；本體受到原傷害的 35%。不擋視線。
- 醫療：45 生命並清毒。防禦：本次敵人階段槍擊、近戰或爆炸傷害減半。
- 毒液：8 傷害並中毒 3 回合；離開後每回合 4。高熱：12 傷害。密封防護每次升級 −5 環境 / 毒傷。
- 換層：生命 +25、子彈 +20、電池 +10、榴彈 +2，清除中毒。
- 終端：一次交易。15 廢料恢復 60 生命；15 廢料買 24 子彈 /12 電池 /3 榴彈；12 廢料買 2 手榴彈。

## AI

只有玩家有效行動後才執行。斷訊槍兵與破口突擊兵的持續火力在首次蓄勢後每回合射擊；其他敵人仍保留蓄勢節奏。目標進入視線會警戒並尋路；一般攻擊先蓄勢一回合。狙擊手蓄勢兩回合，瞄準舊位置，移動即可閃避。無人機越過掩體和地形傷害，但不能穿牆。自爆體近身蓄勢後或死亡時爆炸。

頭目半血時召喚兩架可用位置的無人機。核心守衛交替射擊與延遲兩回合轟炸。紅色中心与一格鄰近區域都危險。

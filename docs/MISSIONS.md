## 世界與回合

src/missions.js 提供內容 catalog、配置、進度、出口條件及驗證。Game 第六參數為合約 ID，預設 extraction；mission={id,targets:[]} 在第六層生成時配置，不消耗戰鬥或物資 RNG。按種子輪轉非起始房順序；每房一個，既有 reachable（門視為可開）確認可達。

殲滅指定既有非 boss／warden 敵人，保留原能力、掉落、AI。只保存敵人 ID，不以擊殺計數或位置替代；進度直接查該 ID 的 hp，爆炸、環境、自爆等死亡均計入，移動／失去視線不換目標。不新增精英數值或敵人數量。

回收目標保存 {id:'objective-N',x,y,done}，初始位置避開物件、掉落、敵人、危險格與電梯鄰格。獨立任務資料，不塞進一般 props/items 或玩家容量。資料匣可走過、不供掩體、不擋射線，不受爆炸破壞。靠近或站上後，右下互動 recoverObjective(id) 花一回合，直接登記回收；不自動拾取、不加一般物資、不重複回收。關門阻擋相鄰互動；遵循快速／普通／緩速隊列，先手致死取消，失能跳過時不回收；有效回收清除等待／連射等狀態。

## 顯示

原本頂部標題位置改為任務標題按鈕，保持同一列、44px 高，不新增 HUD 高度。顯示樓層、合約與最後一層進度；點擊顯示樓層名稱、簡報及目標完成狀態。背包、繼續、結果與任務紀錄均顯示合約。

青色 D 是資料匣，青色菱形標示指定敵人，敵人浮卡名稱亦有菱形。資料只在探索後顯示在地圖，敵人只在目前可見時標記；未定位不透露座標。資料匣回收後圖標消失。頂部進度由 renderer 的演出快照更新，不能先於子彈命中／敵人倒下。原地圖／人物外觀不更換，無新增點陣素材。

後續：不同層數／原路返回需持久化各樓層，限制增援與補給重生；不在本批。Recon 技能、頭像接入、房間主題與交戰痕跡仍延期。自然難度／流程長度是否合適交外部驗收，不以人工高血 fixture 或舊核心合約通關 bot 代替。

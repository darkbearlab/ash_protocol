# 橫向介面提案：鍵盤滑鼠與手把（純設計，未實作）

2026-09-17，使用者要求「如果要改橫向介面且鍵盤滑鼠／控制器操控，會怎麼調整版面，做一版純設計」。這份是 Claude 的提案紀錄，**遊戲程式完全沒有改**。背景是討論過將來可能出電腦版（例如 Steam），見本檔最後一節。

## 在哪裡看

- **設計稿**（五張 1280×720 畫板，可縮放、可在上面留言）：https://claude.ai/artifact/LBfgS5sczbPTTovPuyd2pU
  - 私人頁面，要用使用者自己的 Claude 帳號開；也可以從 claude.ai 的 Artifacts 列表（claude.ai/code/artifacts）找「灰燼協定 橫向介面」。
- 戰場是用遊戲本身的繪圖程式實際畫出來的（3.119.0，種子 4242 第 1 層，玩家在 13,13），不是示意圖。
- 敵人名稱、升級文字、武器數值、樓層名稱取自遊戲資料；命中率、回合數等戰況數字只是範例。

## 原則

1. **戰場滿版，介面縮成四周的窄面板**。直向是上下堆疊，橫向左右有空間，改成像戰術遊戲那樣疊在畫面邊緣。
2. **鎖定目標資訊固定在右側欄**，不再是浮在戰場上的小卡，不會擋住戰場。
3. **鍵盤滑鼠與手把共用同一套版面**，只換按鍵提示，不用維護兩套介面。
4. **選單改成側邊抽屜或置中**，不再是手機的底部抽屜；開背包時左邊仍看得到戰場。
5. Steam Deck 是 1280×800，多出的 80px 只影響下方行動列與右側欄的高度，版面不用重做。

## 真的要做時

- 瀏覽器內的電腦版就能用這套版面；上 Steam 則要包成執行檔（例如 Electron 加 steamworks.js），才能用雲端存檔、成就、排行榜、手把支援等 Steamworks 功能。
- 橫向要另寫一套版面規則；目前的排版是為直向手機設計。
- 新增的按鍵要避開既有的：目前 Q 是瞄準資訊、Tab 是切換目標。
- 手把輪盤與游標查看是新的互動，需要設計焦點移動規則（選單內的手把導覽目前完全沒有）。

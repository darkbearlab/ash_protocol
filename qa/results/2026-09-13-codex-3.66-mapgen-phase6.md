# 3.66.0：隔板接角、門素材、外部骨架配方池

日期 2026-09-13，Codex。基底 main c19c130（3.65.0）。使用者要求改善隔板接角、試做門素材並繼續原定階段。

## 交付

- L／T／十字交界共用接柱，依活邊界更新；直線不加柱，毀壞後不留下接角。一般／矮隔板仍獨立耐久與原掩體／翻越規則。
- 門改為與隔板一致的半格高面／窄頂，兩軸獨立投影；開門只留兩端門框。門框參與接角，中央不補蓋；點擊依面／門框，原綠線／雙綠點提示保持。
- 內建 GPT Image 產生 2×2 門材質表；tools/pixelize_doors.py 輸出四片 32px indexed RGB555 圖，nearest、不抖色、24 色共用色盤。來源／完整提示詞與製程在 art/doors-v1，正式素材在 assets/pixel/doors-v1。
- maps/recipes/*.json 可定義 layout、floors、weight、openings、doorRatio、annex、theme。提供雙翼工坊、機庫、碼頭側線三份；start／build 自動驗證及編譯，也有 npm run recipes。
- 同層可有多組雙格房，最多一間 2×2。入口出口單格；三種補給分配到不同最終房間，三房合格敵人／任務槽位先保障。門比例在決定開口數後處理，每條連線留空路。
- 指定附屬區全部成功才接受該配方；不安全時整份丟棄，依獨立加權順序試下一份，全失敗回退完整第五階段。無適用樓層也是第五階段，池完全為空才走 v1 相容基準。
- 生成世代 7 保存配方副本，不靠目前池驗證舊圖；save v32／profile v5／backup v1 不變。MAP_FIELDS 原已納入封存清單，沒有新增需遷移的角色欄位。
- 本機 server 靜態白名單補 scenery-v1／doors-v1；SW 快取新圖集及配方模組。

## 過程發現與修正

1. 多組房間合併會讓兩種補給 metadata 落在同一個房間，雖然物資未消失，分類不完整。改為合併前依最終群組選三間不同獎勵房，保留 exploration 原斷言，新增至 60 層的檢查。
2. 舊第五階段形狀測試固定 SLOT_RECIPES，舊附屬區往返固定 ANNEX_RECIPES，仍驗原圖與破壞後保存。世代 2→當前版往返改選仍生成世代 7 的種子，另有世代 6→7 的專項。
3. Recon 側身測試的手工平地沿用了原種子的照明；明確設成全亮。先手致死測試原依賴某個地圖 RNG 剛好命中，改明確命中。保留 45%／32% 與玩家死亡、補品不消耗的斷言，未改規則或數值。
4. 門材質共用製程會把第 0 色當透明色，因此顏色索引從 1 起編，確保面板不意外透空。

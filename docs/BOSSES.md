## 2. 忠誠方：標定與壓制

使用者：「更專注機槍的壓制，以及讓玩家容易被命中和受到更多傷害（士兵主動技能的頭目化）」。

### 第 3 層：只會標定

- **標定**是士兵預警反過來用在玩家身上：
  - 預告一回合：一條雷射線指著你。
  - 之後 3 回合，所有敵人打你命中 +15、傷害 +20%。狀態列看得到。
  - 數字比士兵預警（+10 命中、+10% 傷害）強一點，因為是頭目。
- **躲不掉**（使用者 2026-09-29）：標定和士兵預警一樣，煙霧沒用，離開視線也不會提早結束，只能撐過 3 回合。解法是這 3 回合裡別讓其他敵人打得到你：找掩體、拉開距離、先處理會開槍的。
- 半血時叫無人機，照現在的做法，不用預告。

### 第 6 層：架槍與壓制

- **架槍**：
  - 預告一回合，畫出前方 90 度、射程 7 的扇形。
  - 之後連續 3 回合掃射扇形。扇形裡看得到的目標，每回合吃一串低傷害子彈；只要人在扇形裡，不管有沒有打中都加一層壓制。
  - 壓制 3 層以上不能移動（SUPPRESSION.md），所以重點是在被釘住之前離開扇形，或找到掩護。
- **架槍期間的破綻**：
  - 不能移動、不能轉向。
  - 從扇形外打它命中 +15。
  - 掃完收槍 2 回合，之後才能再架。收槍的時候可以移動（使用者 2026-09-29：「收槍的冷卻時間可以移動」，3.205.0）。
- 半血叫無人機，同第 3 層。
- **也會標定**（使用者確認）：和架槍輪流用。「被標定還待在扇形裡」最危險。

## 3. 叛軍：用火驅趕走位（3.206.0 已實作）

使用者：「使用火焰發射器，覆蓋玩家位置，可以遮擋視線和壓迫走位」。燃燒地板與火焰發射器的規則見 [HAZARDS.md](HAZARDS.md) 第 2、4 節。

### 第 3 層：縱火者（使用者同意 Claude 的提議）

- 有裝甲，不怕火。站在自己的煙裡打你，淡煙讓雙方命中都減半。
- **火牆**：預告一回合，在你身後或側邊畫一條 3～5 格的線，下一回合整條點燃，切斷退路。
- **圍困**：在你周圍 2 格畫一圈留有缺口的火，逼你從缺口走。
- **過熱**：噴 3 次後散熱 2 回合。這段時間不能噴火、裝甲降到 0，是反擊的時機。
- 和一般火焰兵詞條的差別：詞條是朝你噴一錐，縱火者是畫線、圍圈，用火來趕你走位。

| 噴火 | 兩招之間照火焰兵的方式噴：朝它正在打的對象標出錐形（5 格、半角 30°）預告一回合，下一回合從原點噴出去；夠不到就往前走，絕不開槍（不打誘餌也不打地雷） |
| 過熱 | 噴火、火牆、圍困各算一次用火；第 3 次後過熱，接下來它自己的 2 個回合只走路：不噴火、不畫火牆圍困，裝甲降到 0。第 2 個回合結束時散熱完畢，裝甲恢復 |
| 輪流 | 火牆與圍困只在用火次數是 0 或 2 時開始（所以兩招之間一定夾一次噴火或散熱），兩招輪流，輪到的那招放不下就用另一招，兩招都放不下就噴火。典型的一輪：火牆預告 → 點燃 → 噴火預告 → 噴 → 圍困預告 → 點燃（過熱）→ 散熱 2 回合，約 8 回合 |
| 取消 | 預告中被 EMP 失能、被拉走或擊倒：火牆、圍困與噴火都取消，不算用火；看不到你、被壓制都不取消（預告出去就一定會點，不需要看得到你） |

#### 焚線官

| 項目 | 規則與數字 |
| --- | --- |
| 標定 | 和標定官、火線官完全相同（`src/loyalist-bosses.js`：預告 1 回合，落下後 3 回合所有敵人打你命中 +15、傷害 +20%，躲不掉，冷卻 2） |
| 架火焰發射器 | 和標定輪流（同火線官的順序與條件：先標定；標定落下的那一回合、手上有蓄勢中的一槍時、站在危險格上時不開始）。預告一回合，畫出朝目標的錐形：射程 5（步數距離）、半角 30°，照火的線（牆、關著的門、隔板擋；矮隔板與箱子不擋；坑洞上方的單位照樣燒得到，但坑洞不會著火） |
| 噴火 | 之後連續 3 回合，扇形內每個單位（任何一方，不怕火的除外）受 12（照深度放大，同火線官的掃射），不擲命中、不算掩體、護甲照扣；扇形裡的地板每回合點燃 |
| 破綻 | 同火線官：架著時不能移動、不能轉向；從扇形外打它命中 +15（只看角度：正前方射程外仍算扇形內；槍與近戰都算） |
| 收起 | 第 3 次噴火後收 2 回合：可以移動（同火線官收槍，使用者的決定），不噴火、不標定、不再架 |
| 取消 | 預告中被失能、被拉走、被擊倒：取消；噴火中被失能或被拉走：直接收起 |

Claude 的判斷：
- 錐形用火焰發射器的（5 格、半角 30°），不是機槍的 90°、7 格：火不擲命中、不看掩體，還每回合把地板燒起來，扇形太大就走不出去；窄一點才有「走出扇形、繞到側面打」的解法。數字在 `REBEL_BOSS_TUNING.burn`，使用者可以放寬。
- 噴火打到扇形內的每一個人，敵我不分（火不挑人，同火焰發射器）；燒到自己人不算你的擊殺與傷害統計，戰報寫「焚線官傷到某某」（同蟲族頭目，`Game.hurt` 的 `ownKind` 現在涵蓋所有敵方頭目）。縱火者的噴火與點燃也一樣。
- 焚線官也不怕火：架著時站在扇形頂點不能動，旁邊整片在燒，不怕火才不會燒到自己。

#### 火與整層 30 格的上限（Claude 的判斷）

- 頭目的火一定點得起來：整層已經有 30 格在燒時，最早燒起的格子（燒得最久的，一樣久時照閱讀順序）先熄掉讓位，不會熄掉這次正要點的格子；整層仍然最多 30 格。有格子因此熄滅時戰報記一行「這層的火已經太多：最早燒起的 N 格熄滅，讓給某某的火」。火牆、圍困、縱火者的噴火與焚線官的噴火都是（`src/fire.js` 的 `ignite` 的 `makeRoom`）。
- 你的火焰發射器、火焰兵與燃料罐照舊：滿 30 格就不再點新的。
- 點燃之後的燃燒地板照舊不分是誰點的：回合結束站在上面的敵人被燒傷、燒死，照 3.203.0 的規則算（和火焰兵點的火一樣）。

#### 其他 Claude 的判斷

- 火牆、圍困與噴火的預告要看得到你（沒有紅外線，所以預告之前躲進煙裡有用）；點燃不需要（預告出去就是承諾）。
- 火牆與圍困的格子不放在起點、出口與有物件（終端、貨櫃、箱子、油桶）的格子上；地上的物品可以被火蓋住（同一般的火）。
- 過熱期間被 EMP 失能，那幾回合不算散熱（散熱算它自己的回合），EMP 會延長反擊的時機。
- 點燃是一瞬間：點燃途中縱火者被炸死（例如燒到身旁的自爆機器人），火照樣點起來，但不算用火、不會過熱；焚線官在自己的噴火裡倒下，就停在那裡，不會再收起噴火器。
- 預告過的火在輪到它時最先處理（行為樹最上面，命令、生存模式的走位、誘餌、看過的地雷與危險格都在後面），一定從預告時站的地方出去；架著火焰發射器與收起的時候都不打誘餌與地雷。

#### 畫面

- 火牆與圍困：預告的格子是會閃的燃料橘，火牆的格子中間畫一條線；圍困的缺口是綠色虛線框，框裡的箭頭指向圈外（從這裡出去）。預告的那一刻頭目身上閃一下。點燃時每格播火舌。
- 焚線官的扇形：照火線官的畫法，架起時琥珀橘、噴火時紅橘，頭目旁的數字是剩下的次數。
- 過熱：頭上冒淡色蒸氣、藍色虛線圈，旁邊的藍色數字是剩下的散熱回合；還沒過熱時頭上一排 3 個小點，亮橘色的是用了幾次火。過熱的那一刻身上噴出一圈蒸氣。
- 目標卡：「火牆預告」「圍困預告」「過熱：裝甲 0 · N 回合」（裝甲欄同時不顯示）「熱度 N/3」「架起火焰發射器：不能移動」「收起火焰發射器 N 回合」「扇形外 +15」。文字版工具把火牆、圍困與焚線官的扇形標 `!`，預告行列出火牆、圍困（含缺口）與噴火器，敵人表列出熱度與過熱。

#### 出場台詞

- 使用者定稿的 intro.rebel3、intro.rebel6（白鷺、鷦鷯各一句，表情照審稿頁：白鷺 concerned／serious，鷦鷯 alarmed／worried），卡片的 `intro`：`introRebel3`、`introRebel6`，走 3.204.0 的出場演出。擊殺台詞用通用的。

- 3.206.2：小隊、伏擊的看守與督戰官的處決也把縱火者當成沒有槍（以前只有火焰兵詞條），不會替它架槍、讓它掩護射擊或提前開火。縱火者的噴火、火牆與圍困，焚線官的噴火，出手後都不留下別人幫它架好的一槍。

#### 存檔（SAVE 84）

- 縱火者的 `fireIntent`（`kind` 為 `wall` 或 `ring`、`origin`、`cells`；圍困另有你當時的位置 `center` 與缺口 `gaps`）、`heat`（1～2）、`overheat`（剩下的散熱回合）、`special`（下一招先試哪個）與噴火的 `flameIntent`（同火焰兵，現在也准只會噴火的卡片帶）；焚線官的 `burn`（`set`／`sweep`／`pack`，同火線官的 `gun`）、`special`，標定的 `markIntent`／`markReady` 照忠誠方的檢查。舊存檔沒有這些，不需要轉換；已經生成的叛軍樓層保留封鎖官與核心守衛。
- 讀檔時丟掉已經失效的預告（火牆、圍困與架起的火焰發射器：頭目倒下、失能或不在原位；散熱中的縱火者身上的噴火標記），不拒收存檔。比現在的數字長的值（熱度、散熱、剩下的噴火次數、收起的回合）截成現在的上限；火牆與圍困的格子數不照現在的數字檢查（最多 30 格）。使用者之後調數字時，進行中的存檔照樣讀得進來。其他不合法的值照樣拒收；往返任務封存的樓層也一起檢查。

## 4. 蟲族：預告照舊，但被打中代價很大

### 兩隻共通：鉤舌

- **命中後直接咬一口**：拉過來和咬在同一個行動裡完成，傷害是牠的近戰傷害（巨獸 26、母后 30）。鉤舌本身已經預告一回合，所以公平。狂戰士的鉤鎖也是拉過來加一擊在同一個行動完成。
- **路徑上都可以被鉤到**（使用者）：鉤舌沿著預告的方向打出去，鉤到路上的第一個單位，不一定是玩家。擋在中間的友軍、寵物或敵人會被鉤走。
- **鉤到自己的蟲也照樣拉過來咬**（使用者）：敵我不分，和衝鋒一樣。

### 第 3 層巨獸：衝鋒（使用者同意 Claude 的提議，並加上失能）

- **預告**：一回合，畫出一條直線，到牆為止，最多 8 格。
- **路上的單位**：敵我不分，往旁邊撞開一格、受 15 傷害，並**失能**（使用者）。Claude 提：失能 1 回合，同震撼的效果。
  - 旁邊沒有空的地板（牆、坑洞或別的單位），就留在原地，受 30 傷害，照樣失能。
  - 不會把人撞進坑洞，坑洞當成牆（PITS.md：遊戲裡沒有推擠，也就沒有掉進坑洞這回事）。
- **撞牆**：衝鋒停下，巨獸自己暈一回合，這回合被打命中 +20。站在牆前引牠來撞，就是這隻頭目的解法。
- **冷卻**：3 回合。
- 這是遊戲裡第一個推擠規則（PITS.md、ALLIES.md 都寫明原本沒有推擠）。只給頭目用。

### 第 6 層母后：產蟲巢（使用者同意 Claude 的提議）

- **預告**：一回合，地上先冒出卵囊。位置在離你 3～4 格、你看得到的地板。
- 同時最多 2 個。蟲巢照現有規則（45 點血、每 2 回合生一隻小蟲），但產下的蟲巢只生 3 隻，不然蟲量會爆掉。
- 使用者審台詞時的備註：蟲巢血很多，理論上先打巢是壞點子。所以台詞不叫玩家先打巢，只提醒別被蟲淹沒。
- **冷卻**：6 回合。
- 半血以下也會衝鋒，同巨獸。
- 現在的蟲巢只在生成地圖時放（`src/runtime-enemies.js`）；這是第一個戰鬥中產生的蟲巢。

### 實作（3.205.0）

- 程式：規則在 `src/swarm-bosses.js`（衝鋒、產蟲巢、存檔）與 `src/swarm.js`（鉤舌），數字在 `src/swarm-tuning.js` 的 `SWARM_BOSS_TUNING`（使用者試玩後再調）。卡片（`src/data.js`）：巨獸 `specials:['charge','tongue']`，母后 `specials:['nest','tongue','charge']` 加 `chargeBelow`（半血以下才衝鋒）；每回合照這個順序試，能用的第一招用掉這回合。兩隻都有自己的出場台詞（`intro`：`introBeast`、`introMatriarch`，使用者定稿，白鷺、鷦鷯各一句，表情照審稿頁）。
- 預告在輪到牠時最先處理（行為樹最上面，命令、生存模式的走位、誘餌與危險格都在後面）：預告過的鉤舌或衝鋒一定從預告的位置出去；誘餌騙不走、看過的地雷也不會讓牠先開槍、站在火上也不會先走開。
- 圖：鉤舌畫出整條會飛過的線（粉紅，淡色的格子加虛線，被瞄準的格子與落點照舊）；衝鋒是鏽紅色的車道，格子裡有指向衝鋒方向的箭頭，會撞牆時車道盡頭有一條紅槓；卵囊是淡粉色的預告格上一個蟲潮出口的洞（3.206.0 使用者：沿用蟲潮出口的地洞圖 `burrow`，3.205.0 是程式畫的會跳動的淡粉色囊，現在只在地洞圖讀不到時才畫）。衝的時候沿路揚塵、撞牆處有撞擊，被撞開的人身邊一團灰，孵化時卵囊裂開。目標卡寫「衝鋒蓄勢」「產卵中」「撞牆暈眩 +20」。

#### 鉤舌（兩隻）

| 項目 | 規則與數字 |
| --- | --- |
| 預告 | 照舊一回合、射程 5（步數距離）、要看得到而且射得到牠正在打的對象（你或你的單位） |
| 路線 | 從頭目穿過瞄準的格子一直延伸到射程 5；牆、關著的門、隔板與實體物件（箱子、油桶、蟲巢）擋住，矮隔板不擋，坑洞飛得過去 |
| 鉤到 | 路線上的第一個單位，不分敵我：你、友軍、寵物、平民、蟲族自己的蟲都算；路線上沒人就撲空 |
| 拉與咬 | 拉到頭目旁邊的空地板（預告的落點還空著就用它，否則離那個單位最近的一格），同一個行動咬一口：牠的近戰（卡片 26／30，和所有敵人的攻擊一樣隨樓層加，標準難度第 3 層 29、第 6 層 36），照一般近戰擲命中。本來就在旁邊的直接咬 |
| 冷卻 | 照舊 4 回合，出手、撲空或被打斷都算 |

Claude 的判斷：
- 路線延伸到射程，所以沿著線往後退一格還是會被鉤到，要往旁邊離開那條線（原本只要離開那一格就好）。
- 鉤舌瞄準牠正在打的對象，不只是你（原本只拉你）。
- 頭目旁邊沒有空的地板可以拉（例如被坑洞圍住）就不預告；出手時沒有就撲空。
- 已經在頭目旁邊、但中間隔著一般攻擊跨不過的邊（例如矮隔板）的單位，照遠處的一樣拉過去（越過那道邊，落在旁邊的空地板）再咬；沒有地方拉就撲空（獨立審查）。
- 咬死自己的蟲不算你的擊殺：沒有擊殺數、經驗與廢料，也不算進你的傷害統計，戰報寫成「巨獸傷到某某」；掉落照一般死亡（同執法者處決）。

#### 衝鋒（巨獸；母后半血以下）

| 項目 | 規則與數字 |
| --- | --- |
| 開始 | 看得到牠正在打的對象，對方和牠在同一橫排或直排、相距 2～8 格，而且車道碰得到對方。貼身時照舊咬 |
| 預告 | 1 回合：車道從頭目往對方的方向，到第一個牆、坑洞、關著的門、隔板、矮隔板或實體物件為止，最多 8 格；單位不擋車道 |
| 衝 | 下一回合輪到牠時沿車道衝到底，車道上的每個單位（不分敵我）往車道兩側撞開一格、受 15 傷害；兩側都不是空地板（牆、坑洞、別的單位、擋路的邊）就留在原地受 30。兩種都失能 1 回合 |
| 撞牆 | 車道不到 8 格就被擋住，算撞牆：牠停在車道盡頭，暈 1 回合，到牠下一次輪到之前打牠命中 +20 |
| 冷卻 | 3 回合（第 3 回合起才能再預告） |
| 取消 | 預告中被失能、壓制到不能動、被移開、被擊倒：取消，冷卻照算 |

Claude 的判斷：
- 兩側都空時用雜湊決定往哪邊撞（種子、樓層、回合、頭目與那個單位），不用戰鬥骰：重播與重新讀檔都撞同一邊。
- 失能 1 回合同震撼彈的效果，但不看機械或生物（是撞擊，不是手榴彈的關鍵字），之前被震撼後的免疫擋不住；結束後照震撼的規則有 2 次免疫。頭目也只失能 1 回合。
- 15／30 是撞擊前的數字：護甲照扣，防禦待機照樣減半，不算掩體；和頭目的其他數字一樣到了無盡的深層才放大，不隨每層加。
- 撞開一格可以撞到燃燒的地板上（那也是地板）；不會撞進坑洞，也不會撞過關著的門或隔板。
- 留在原地的單位，巨獸從它身上衝過去；車道盡頭有人留著時，巨獸停在它前面最後一格空地。
- 衝鋒途中巨獸自己倒下（例如撞到的自爆體炸死牠），衝鋒就停在那裡：不再撞後面的人、屍體不往前走、不算撞牆（獨立審查）。
- 撞牆的 +20 用翻越破綻的 +20（槍），近戰也加；撞牆時牠站著不動，不算移動中的目標。車道剛好 8 格、後面才是牆，不算撞牆。
- 撞死自己的蟲不算你的擊殺（同鉤舌）。

#### 產蟲巢（母后）

#### 忍者的光學迷彩

- 看不到它（地圖不畫、不能鎖定、不算在視線內的敵人裡），除非：它站在淡煙裡（排煙口的淡煙與蒸氣、燃燒的地板）、和看的人在同一團濃煙裡、就在看的人旁邊、剛出手（它出手的那一回合到它下一個回合開始）、被你的預警標到（`exposed`），或看的人有紅外線（偵察兵、忍者、熱視鏡：使用者「對偵察兵沒用」）。你的單位各自照同樣的規則看。
- 看得到時畫成它的職業剪影填滿很密的灰色雜訊（每 70 毫秒換一次，減少動態時不動）。

#### 登錄表與存檔（SAVE 85）

- 招式（CHECKLIST 第 2 節）：`scan`（士兵的預警冷卻，回合開頭倒數；預警本身在 `ORDER.start`）、`toss`（士兵的手榴彈冷卻；手榴彈本身是擲彈兵的 `grenade`，現在卡片的 `grenades` 也可以帶）、`smoke`（偵察兵：預告放在 `ORDER.top`，打斷的原因同噴吐者的拋射但不含看不到你；預告中不打誘餌、不打地雷、不離開腳下、被釘住就取消；取消時冷卻重設成 7）、`drones`（工程師的無人機冷卻；放無人機是新的 `ORDER.end`：`Game.enemyAct` 在單位的回合之後，不管回合是被行為樹、誘餌還是地雷拿走）、`cloak`（忍者剛出手的 `decloaked`；`ORDER.start` 在它自己的回合開頭清掉）。
- 存檔的新欄位：單位上的 `code`、`scanCooldown`、`grenadeCooldown`、`smokeIntent`、`smokeCooldown`、`droneCooldown`、`decloaked`，你與你的單位身上的 `scanned` 狀態，工程師的無人機（`<它的編號>-drone-<n>`，一般的敵人）。舊存檔沒有這些（已經生成的樓層保留自己的頭目），遷移不必轉換。

#### 其他 Claude 的判斷

- 預警的加成只給它自己的槍（同玩家版：你的預警只幫你自己），不是全體敵人；和標定的區別照第 5 節原本的說法（標定要預告、效果強、只對你；預警不預告、效果弱、範圍大、隔牆藏不住）。
- 偵察兵丟煙只對你（不對你的單位），貼得太近（3 步內）不丟；它站在危險格上時先走開再說。
- 工程師的無人機放在它身旁的空地（不放在危險格上）；浮游彈藥照它自己的規則：只在它的鉤掛範圍 3 格內才看得到。
- 狂戰士回血只算砍中你（使用者：砍中玩家時回血），砍你的寵物或無人機不算。
- 忍者的迷彩對你的單位一樣有效：它們各自照同樣的條件看，看不到就不會挑它當目標（友軍、寵物與工坊單位的挑目標也問 `Game.cloakedFrom`）；它貼到你身旁、在你的煙裡，或你有紅外線時，它躲不掉。

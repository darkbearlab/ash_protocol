## 獨立複查（子代理人）

- **沒有高嚴重度問題**：901 個測試都通過；新介面沒有自動測試，只有 release 與 bump-boundaries 兩個測試讀 controller 原始碼，仍通過。
- **中：長按後的點擊攔截只驗過模擬事件**（已修正）。
  - 原本只攔「點在原按鈕上」的點擊，而且攔截維持 1 秒。實機上選單會蓋住按鈕，放開時的點擊可能落在選單的主按鈕或某一列上。
  - 也可能根本沒有點擊，這時 1 秒內下一次真正的點擊會被吃掉。
  - 修正：長按觸發後記下這根手指，放開後 0.4 秒內的任何點擊都丟掉；放開一直沒來時 1.5 秒自動失效。
- **中：自動固定的底部按鈕會固定「返回／取消」，主要動作卻留在捲動區**（已修正）。
  - 發生在武器比較、擊殺屋的教學入口與結算畫面，以及各種確認對話框。
  - 修正：最後一顆是次要的返回／取消時，連同它前面那顆動作按鈕一起固定，返回在左、動作在右。
- **低（已修正）**：
  - 多指同時按兩顆按鈕會留下沒清掉的計時器：改成每顆按鈕各自計時。
  - 計時器觸發時沒有再檢查狀態，可能在播放中或結算時打開背包：觸發時再檢查一次。
  - 仍然能按的按鈕標了 `aria-disabled="true"`：拿掉，只保留變暗外觀。
  - 背包移除的備彈上限、護甲板與回合成本說明沒有搬走：補進作戰指南的「背包」段落；工坊提示補回技能分頁。
  - 從主選單設定打開「資料與紀錄」時，會顯示佔位行動員的狀態：只在任務進行中顯示。
- **保留**：
  - 戰鬥畫面外（選單以外）不能雙指縮放，這是使用者要的「實體遊戲機」手感。
  - 視窗高度變化（鍵盤、Safari 工具列）時鎖定會跟著切換，只能在真手機確認。
- **子代理人確認沒問題的項目**：
  - 無法使用時照樣可以按的技能，規則層都會拒絕並給理由，失能時的付費技能等同等待。
  - 播放中與局結束時按鈕仍停用。
  - 滑鼠右鍵與中鍵不觸發長按。
  - 戰鬥介面全部在 `.battle-panel` 裡，放不下時會解除鎖定。
  - 地圖畫布原本就是 `touch-action:none`；選單內捲動與設定的滑桿不受 `touchmove` 攔截影響。
  - 背包的預備／取消、學習資料使用與拆解、餵養、裝備／改裝／拆解、比較都還在。
  - 說明段落的 id 不會互撞，也沒有新增未跳脫的文字。
  - 開發伺服器只多開放 `qa/*.js`。

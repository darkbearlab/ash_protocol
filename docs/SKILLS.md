# 主動技能（3.27.0）

## 訊號斷層 signal_break

Recon 新局直接學會並預備；Soldier／Bulwark 沒有。使用原戰場技能按鈕，免費啟動，不選目標、不花道具；技能與被動是不同系統。背包技能頁可免費預備／取消，效果與冷卻不因取消預備而改變。

- 持續 **3 次耗回合行動**，冷卻 **6 次耗回合行動，從啟動同時起算**。啟動瞬間 remaining=3 / cooldown=6；每次整輪結束各減 1，因此第三輪後 0/3，第六輪後 0/0 可再用。
- 效果保護完整的三輪快速／正常／緩速敵人行動；第三輪全部結束後才失效並重新觀察。技能不提供額外命中、減傷或迴避。
- 敵人無法看見玩家、不能更新 lastKnown，涵蓋生物、機械、夜視、紅外線。玩家自己的視野與射線不變。射擊或投擲不取消技能。
- 已警戒敵人保留最後目擊位置並搜索；未警戒者不因玩家看到它而警戒。技能期間搜索以已知位置計距，尋路不與玩家重疊，不清除記憶或瞬移敵人。已到舊目擊格而沒看見玩家就留在附近，不另加巡邏 AI。
- **不是無敵**：已承諾落點的狙擊、已標記轟炸、爆炸及地板／中毒傷害照常。一般敵人未形成落點承諾的瞄準因失去視線而中止，沿用原失去視線行為。移開狙擊原落點仍可躲避，站著可能被打中。
- 免費裝填、免費換裝、預備、開背包、無效指令不倒數；有效耗回合行動即使被失能跳過仍倒數。失能、待選升級、死亡／結束時不能啟動。效果中或冷卻未完不能重複啟動。
- 下樓結束效果、保留冷卻；下樓本身耗一回合，剩餘冷卻減 1。讀檔／備份還原保持計數，不能用重整或換層刷新技能。

## 資料與保存

src/skills.js 定義 SKILLS、計時／可用性／狀態驗證，prepared catalog 共用它。角色 skills 是學會清單，prepared.skill 是選擇，skillState 是各技能的 {remaining,cooldown}；天生被動 traits 不占技能欄。後續技能要補實際執行分支及測試，不能只加 catalog。當前僅有一種免費技能，不承諾尚未實作的付費技能通用執行器。

Game.action 在進入 initiative 前免費啟動；付費 action 的全輪結尾 tickSkills 一次。Game.sight 攔截敵方對實際 player 的感知；shotClear 幾何獨立，承諾射擊不被消除。技能的 pulse 經現有 presentation 快照播放，不新增圖檔或隨機數。

save v20；profile v4／backup v1 不變。v1–19 按原遷移鏈讀取，舊 Recon 追加技能並在空技能欄預備，舊 HP、彈藥、道具、其他預備欄、地圖與 RNG 保持。當前 v20 刻意取消預備的空欄維持空白。舊局第一次本機讀取保留 ash-save-v19-backup（QA 加 qa-）；舊版本各自保留對應備份。狀態只接受已學會技能、整數與定義上限，拒絕缺欄、額外狀態及非法計數。

## 驗證與限制

16 項專項涵蓋回合數、免費操作、三種先後手、感知、搜索、既有攻擊、換層、保存、v19 遷移與 QA 原件備份；沿用其他 323 項回歸。七份場景由 node qa/create-3.27-fixtures.mjs 生成至 qa/fixtures/3.27/。Codex 不做瀏覽器驗收，手機按鈕／讀秒／播放與 Recon 自然難度交使用者或 Claude。

現有 balance 代理沒有使用此技能，通關測試只保留既有回歸門檻，不能證明 Recon 的可玩性已改善。自然手測後再決定強度、冷卻或配給；僚機、額外技能、敵人道具 AI 未加入。

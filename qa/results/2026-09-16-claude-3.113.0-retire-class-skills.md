# 3.113.0 職業技能不再能用學習資料學 — 驗證報告（Claude，2026-09-16）

## 需求

使用者請 Claude 確認職業專屬技能是否已從學習道具拿掉，並表示「當初我認為為了測試技能系統可以單獨掛載所以決定加入 但我認為是時候拔掉了」。

## 確認時的現況

學習資料共 25 種：9 種主動（其中 8 種是職業原生，只有壓制射擊不屬於任何職業）、16 種被動（其中 15 種是某職業原生，只有連射不是）。**都還在內容池裡。**

## 這批做了什麼

- 移除 8 種職業原生主動技能學習資料。保留壓制射擊。
- **被動全部保留**：使用者先前說過學習資料應擴充為「大部分正面、非敵方專用的詞條」，其中單挑本來就是忍者原生的，一併移除會與那個方向衝突。使用者決定（2026-09-17）：**被動暫時保留**，等之後內容更多再刪，暫且當作等級滿了之後的成長來源之一。
- `RETIRED_LEARNING` 留下 8 個 ID 供舊存檔遷移，`validLearningId` 不再接受它們。
- 未識別貨櫃內容池 28 → 20。

## 舊存檔（SAVE 55）

`retireLearning(data)` 在學習資料驗證之前執行：

| 位置 | 處理 |
| --- | --- |
| 背包 `learningItems` | 每份換成 15 廢料加進玩家廢料，刪除該鍵 |
| 當層地上 | 換成同位置的 `{type:'scrap',amount:15}` |
| 當層未開箱子 | 內容換成 `{type:'scrap',amount:15}` |
| 所有封存樓層（`floorStates`） | 同上兩項 |
| 已學會的技能 | **保留**，引擎仍支援非原生職業使用 |

# 轉角暴露與分流繞路（3.70.0）

使用者於 2026-09-13 授權轉角規則、敵人分流／繞路，並要求我方召喚物也能繞過前排交戰者。不加入更多地磚預告攻擊，不調生命、傷害、命中或繩索等兵種數值。

## 幾何與行動

- sight 保持既有對稱探身觀察，以及煙霧／紅外線／訊號斷層。alert 不衰減，不新增面向、聲音或巡邏。
- shotClear 改用 cornerRay：攻擊者可用自身探身點；目標若是玩家、敵人或友軍，只能射其中心或尚未到期的已暴露探身點。地磚、可破壞物與已承諾狙擊落點沿用幾何判定。
- 遠程武器實際射出時（包含敵人、召喚物、無人機、未命中、免費追擊）記錄實際使用的探身方向。中心直接可射不必記探身；四方向分別保留，朝另一邊開火不抹掉先前暴露。
- 當下立刻暴露，同回合晚行動者可還擊。期限為開火 turn + CORNER_TURNS，目前 2：開火當輪與之後兩個付費世界回合有效，第二個後續回合結束時即清除，避免下次輸入仍提供到期射擊。免費動作不推時鐘，免費射擊刷新。
- 換格清除舊探身暴露；新位置仍判斷遮擋，沒有全身無敵。關門／破牆依即時幾何，暴露不能穿牆、穿關門或繞過煙霧感知。
- 近戰／徒手／手投投擲物不產生槍口暴露。鉤鎖不產生暴露，但鎖定時須有可接觸目標的射線，不能鉤住假想的安靜探頭位置。
- 行動承諾保持：執行時目標躲回轉角仍扣彈落空。狙擊／轟炸固定地磚的承諾保持。沒有新增盲射按鈕。
- 掩體角度、減命中／減傷、伏擊的 !alert、單挑、偵察兵無形射手的視線條件不變；不能射擊不等於看不到。

## 共用位置規劃

src/tactics.js 的 combatStep(g, actor, target, options) 用於敵人及可追擊友軍。只接受已見目標或最後位置，不自己查隱藏目標的即時座標。

- 最多 320 搜尋節點、24 步內找可交戰空格；門／翻越額外成本，危害與其他單位目的地也有成本。現存單位阻擋通行，不擠走前排。
- 目的地預約是軟性成本；有選擇時分流，只有一條路仍可排隊。同成本優先沿主要距離方向接近，再用固定座標打破同分，不抽戰鬥亂數。
- 保留目的地減少搖擺。計畫／最後位置最多保存 24 世界回合；失效重找，有效射擊優先。超出搜尋／繩索或全部封住時，保留舊接近／讓路回退，不保證能解開所有堵點。
- 敵人優先選射程內可攻擊目標；蓄勢承諾保持。
- 附近同伴正在朝同一已知位置繞行時，無有效射線的遠程敵人可牽制等待兩個世界回合；連續無法射擊期間至少六個世界回合才可再次牽制；搜尋失敗仍保留重試限制，失能同伴不能作為牽制理由。可以直接射擊的同伴照常留位射擊。
- 緊鄰玩家、隔著矮隔板的近戰敵人保留攻擊隔板的規則。
- 友軍按原繩索搜索；主動命令、召回集結、失聯回歸、自動換彈優先。失去視線仍調查最後位置，到達或逾時放棄，不隔牆追蹤。
- 固定哨兵不動，追隨無人機不主動追擊。召喚物、寵物與倖存友軍可用交戰繞路；前排可射擊就維持射擊，後排找其他位置。

## 保存與 Claude 介面交接

save v34，profile v5／backup v1 不變。舊檔預設未暴露／沒有計畫。生成亂數、地圖世代、v1 快照不變。

每個單位可有以下可選欄位（未開始時 null 或省略）：

```js
cornerExposure: {
  origin: {x: 9, y: 10},
  until: {south: 104} // north/east/south/west，各自的到期回合（含）
}
tactics: {
  target: {x: 12, y: 11}, // 最後已知座標
  goal: {x: 9, y: 11}, // 牽制時 null
  until: 126,
  holdUntil: 0,
  retryAfter: 0
}
```

敵人欄位隨 enemies 封存，返回時計時與樓層一起平移；玩家與隨行友軍換層清除。有單局／完整備份／封存驗證，演出沿用快照。

game.attackStatus(observer, target) 不耗亂數，回傳：

```js
{visible, attackable, reason, targetExposed, exposureRemaining, peekDirection}
```

- reason：null、not_visible、target_corner_hidden、blocked。
- attackable 是這個觀察者自身視線與轉角幾何結果，**不包含武器射程、彈藥、冷卻、近戰跨邊界限制**；UI 仍需併用既有檢查。玩家原有的友軍共享觀測選敵保持；共享觀測時以既有 targetDetails.withinRange／Game.action 驗證為準，不能用這個單位自身的 visible=false 禁用共享觀測射擊。
- targetExposed 指這條射線是否用到目標暴露探身點，非全方向標記。exposureRemaining 為 until-turn；0 表示演出中的當輪仍有效，回合結束清除。peekDirection 是攻擊者將使用的方向。
- targetDetails.attack 同步提供結果。原卡片只補「轉角未暴露／轉角暴露」避免誤認故障；完整方向／狀態標示交 Claude。
- 不要把未知敵人的 tactics.target/goal 畫給玩家；只能在已知資訊範圍顯示。

# 聲音與音樂

更新：2026-09-17，**3.117.0 已接進遊戲**。素材的採用紀錄見下方各節；先前每輪完整回饋保存於 [製作歷史](archive/audio-production-2026-09-17.md)，若歷史文字衝突，以本檔為準。

## 遊戲內現況（3.117.0）

- **程式**：`src/audio.js`（Web Audio 播放器）、`src/sound-cues.js`（演出事件對應音效，純函式）、`src/music-state.js`（選曲與交戰狀態，純函式），由 `src/controller.js` 接上。
- **檔案**：音效 `assets/audio/sfx/*.wav`（採用檔逐位元組複製，進離線快取）；音樂 `assets/audio/music/*.flac`（無損，循環點精確），瀏覽器解不開 FLAC 時改用同名 `.m4a`（AAC）。音樂不預先快取，第一次播放後由 Service Worker 存起來。
- **啟動**：瀏覽器規定要先有使用者手勢，第一次點擊或按鍵後才建立音訊；頁面切到背景時暫停、回來繼續。任何播放錯誤都被吞掉，不影響回合。
- **設定**：「聲音」段有總開關（沿用舊的 `ash-sound`）、音樂音量（`ash-music-volume`，預設 60%）、音效音量（`ash-sfx-volume`，預設 80%）。
- **同時發聲**：最多 10 個音效，同一個音效最多 3 個，超過時停掉最舊的；音效經過壓縮器，蟲潮時不會爆音。

### 音樂規則（使用者決定）

| 情況 | 播放 |
| --- | --- |
| 出擊前：標題、部署、從標題打開的設定與紀錄、結算畫面 | 〈待命〉，前奏一次後循環 |
| 設施內 | 當層派系的探索配樂；無盡模式換層時跟著換 |
| 敵人喊出交戰台詞（看得到或聽得到的「開火、衝鋒、瞄準、投彈、轟炸」類喊話；平民尖叫與「發現目標」不算） | 切到該派系的交戰配樂 |
| 交戰中，視野內連續十回合沒有敵人 | 切回探索 |
| Kill house、沒有專屬配樂的混合設施 | 算人類設施，用忠誠者配樂 |
| 陣亡或撤離後關掉結算、回看戰場 | 無音樂 |

換曲時 1.2 秒交叉淡化；同一首不會重新開始。交戰狀態不存檔，重新載入後從探索開始。

### 音效對應

| 音效 | 何時播 |
| --- | --- |
| 步槍、霰彈槍、衝鋒槍、精準步槍、電漿 | 玩家、友軍或敵人用對應武器開槍；每個實際射擊演出一次（霰彈槍錐形一發只算一聲，衝鋒槍連發每發一聲） |
| 擊殺 | 演出中有敵人倒下（優先於命中） |
| 命中 | 演出中有命中 |
| 敵彈落空 | 敵人用子彈類武器（步槍、衝鋒槍、霰彈槍、精準步槍）打玩家沒打中；**玩家自己沒打中不出聲** |
| 爆炸 | 爆炸演出（手榴彈、油桶等） |
| 氣動門 | 門開或關 |
| 腳步、裝填、治療 | 玩家移動、裝填、使用醫療包成功時 |
| 升級通訊 | 升級卡片出現時 |
| 選單確認 | 按下選單（對話框）裡的按鈕 |

「演出中按指令直接執行」跳過的演出不播音效，但喊話仍會觸發交戰配樂。

## 已決定的方向

- 全部使用 Mega Drive 風格；既有合成器是近似音源，不宣稱逐暫存器實機相容。
- 出擊前選單播放〈待命〉。戰場探索播放不安、稀疏的氛圍配樂，交戰改播當層派系戰鬥音樂。
- 忠誠者、叛軍、蟲族六段配樂均採用。這不是寫實通風／機械底噪；vent/reactor 舊草稿不採用。
- 玩家試聽使用 Telegram。音檔、製作來源、數值檢查已留存；遊戲內混音與切換尚未驗收。

> **2026-09-17 整理（使用者：只留採用的）**：Codex 的四筆素材提交合成一筆，只保留採用的檔案。試聽合輯、比較檔、MP3 預覽、草稿、沒採用的環境音與電漿 B、三發衝鋒槍試聽檔、獨立循環母帶都沒有進版本控制；電漿 A 移到 `adopted/md3-03-plasma-a.wav`，六段派系配樂與 `faction-loops.json`（原 manifest）移到 `music/`。每個採用檔與產生輸出的對應與雜湊見 `art/audio/audio-checksums.json`。下文若提到已不存在的預覽或比較檔，只是製作歷史。

## 最新交付：3.76.5 — 真實模式／喊話（3.76.0 Codex 規則，3.76.1 修正，3.76.2 部署開關，3.76.3 顯示過濾，3.76.4 泡泡與音效，3.76.5 泡泡不疊加）

- **3.76.4–3.76.5 喊話泡泡與音效**（兩種模式都有）：
  - 敵人狀態改變、預告、受傷時，頭上出現短句泡泡，幾秒後淡出；危險預告是橘框，停留較久。
  - 牆後只聽得到的敵人：泡泡半透明，貼在畫面邊緣並帶方向箭頭，不會標出位置或種類。
  - 泡泡不應出現「×N」。同一個敵人重複同一句只會延長顯示；幾名敵人在 1.5 秒內喊同一句時只顯示第一個（危險預告除外）。畫面上最多 4 個泡泡。
  - 開槍命中、落空、擊殺的聲音應該聽得出差別，擊殺最明顯。
  - 切到背景再回來，泡泡不應該在離開期間消失。
- **3.76.2 部署開關**：
  - 路徑：新任務 → NORMAL 或 DAILY → 選任務 → 選行動員 → 第三步「選擇難度」。
  - 難度只有「標準」，這一格是預留給之後的難度旋鈕。
  - 勾「真實模式」再開始任務。結算畫面上方有 REAL，點數分開寫基礎與真實加成；最近任務紀錄會標「真實模式」。
  - 在第三步按返回再回來，勾選與行動員應該保留。
  - QUICK GAME 不經過這一步，一律標準。
- **3.76.3 顯示過濾**：勾真實模式進入任務後，檢查以下幾點。
  - 瞄準卡只剩名稱與距離。
  - 敵人頭上沒有血條與壓制點；油桶、隔板、門、巢穴沒有耐久條。
  - 命中時不飄傷害數字，落空的 MISS 仍在。
  - 「!」與狙擊手倒數仍在。
  - 標準模式應該和以前完全一樣。

`node qa/create-real-mode-scenes.mjs` 產生五份 real-mode-*.json，只在 `?test=1` 匯入。

- **standard / real**：
  - 兩個場景是同一個戰場，傷害與預告相同；real 的紀錄不含傷害或命中數值。
  - 模式在存檔、讀檔後保持不變。
  - 3.76.1：real 模式下打隔板，紀錄寫「受損」，不寫剩餘耐久。
- **3.76.1**：喊話完全不寫進戰鬥紀錄。每次行動後的提示條應該是自己的行動結果或規則訊息，不會出現「…：準備攻擊。」這類喊話。
- **heard／distant**：
  - heard：等待後，畫面邊緣應出現半透明、帶方向箭頭的泡泡，不標出牆後敵人的位置。
  - distant：敵人進入 8 格內之前，不應出現泡泡。
- **settlement**：基礎 29 點，放棄後多 2 點；重複匯入不能再領一次。
- 部署時選模式、目標卡與地圖的顯示過濾、泡泡的節流與讀秒、音效，全部留給 Claude。
- 以上只有規則測試，不代表手機或介面驗收；尚未人工驗收。
